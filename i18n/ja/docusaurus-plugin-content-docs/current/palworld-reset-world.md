## はじめに

Palworldはアクティブなワールドを設定可能なワールド設定ではなく、サーバーのセーブデータに保存します。このガイドでは、ZAP-HostingでPalworldゲームサーバーのワールドをリセットするために、既存のセーブフォルダーを削除して次回起動時に新しいワールドを生成させる方法を説明します。

:::danger 永続的なデータ削除について
Palworldのワールドをリセットすると、プレイヤーの進行状況、建造物、Pals、その他そのワールドに保存されているデータを含む現在のワールドが完全に削除されます。
:::

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

## 準備

開始する前に、Palworldゲームサーバーの管理権限を持っていること、そしてセーブファイルを削除する前にサーバーがオフラインであることを確認してください。

:::tip まずはバックアップを作成しよう
後で現在のワールドが必要になる可能性がある場合は、続行する前にバックアップを作成してください。利用可能な場合は、サーバーのバックアップ機能を使うか、手動でセーブフォルダーをダウンロードしてから削除しましょう。
:::

## Palworldのワールドリセットの仕組みを理解する

Palworldのワールドリセットは通常、設定ファイル内のゲームプレイ値を変更する必要はありません。アクティブなワールドはサーバーのセーブディレクトリに保存されています。

現在公開されているPalworld専用サーバーの構造に基づくと、ワールドセーブは通常以下のパスにあります：

```text
Pal/Saved/SaveGames/0/
```

このディレクトリ内には、通常ランダムな16進数の長い名前のフォルダーがあります。例：

```text
84B5E2264EC387DEDB43179D666031A1
```

このフォルダーが現在のワールドセーブを含んでいます。これを削除してサーバーを再起動すると、Palworldは自動的に新しいワールドを作成します。

:::note 設定値は不要
標準的なワールドリセットでは、追加の設定エントリ、コンソールコマンド、または起動パラメーターは通常必要ありません。既存のセーブデータを削除することでリセットが行われます。
:::

## サーバーを停止する

ワールドファイルを削除する前に、ZAP-Hostingのゲームサーバー管理画面からPalworldサーバーを停止してください。

サーバーが稼働中にセーブデータを削除すると、ファイルの破損やワールドデータの不完全な削除が発生する可能性があります。

:::caution サーバーは必ず停止させること
続行する前にサーバーが完全に停止していることを確認してください。サーバーが稼働中だと、編集中にファイルが再作成されたりロックされたりする可能性があります。
:::

## セーブディレクトリを開く

ZAP-HostingのPalworldサーバー管理画面でファイル管理エリアを開き、以下のパスに移動します：

```text
Pal/Saved/SaveGames/0/
```

製品の構成によっては、ファイルマネージャーやウェブインターフェースの類似のファイルアクセスセクションからアクセスできます。

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

### パスの参照

| 項目 | 値 |
| --- | --- |
| ベースセーブパス | `Pal/Saved/SaveGames/0/` |
| ワールドフォルダー名 | ランダムな16進数のフォルダー |
| 例のフォルダー名 | `84B5E2264EC387DEDB43179D666031A1` |
| 必要な操作 | ワールドフォルダーを削除 |

## 現在のワールドセーブを削除する

`Pal/Saved/SaveGames/0/`内にあるランダムな16進数名のフォルダーを見つけて、そのフォルダーを完全に削除してください。

### 削除すべきもの

| フォルダーの種類 | 必要な操作 |
| --- | --- |
| `Pal/Saved/SaveGames/0/`内の現在のワールドセーブフォルダー | 削除する |
| `PalworldSettings.ini`やその他の設定ファイル | サーバー設定も変更したい場合を除き、このリセットでは編集不要 |

`Pal/Saved/SaveGames/0/`に16進数フォルダーが1つだけある場合、それが通常アクティブなワールドセーブです。複数ある場合でどれが使用中か不明な場合は、推測せずに現在のサーバーファイルをよく確認するか、削除前にサポートに問い合わせてください。

:::info 設定セクションの補足
多くのPalworld設定は**Configs**エリアで管理できますが、ワールドリセット自体は通常設定ファイルの編集で完了しません。必要な操作はサーバーファイルからワールドセーブフォルダーを削除することです。
:::

## サーバーを再起動する

セーブフォルダーを削除したら、Palworldサーバーを再起動してください。

起動時に、サーバーは期待されるセーブ場所に以前のワールドセーブがないため、自動的に新しいワールドを生成します。

### 追加のコマンドや変更

| タスク | 必要か |
| --- | --- |
| 設定ファイルの編集 | いいえ |
| ゲーム内コマンドの実行 | いいえ |
| コンソールコマンドの実行 | いいえ |
| 削除後のサーバー再起動または起動 | はい |

:::tip 初回起動は少し時間がかかるかも
ワールドセーブ削除後の初回起動は、Palworldが新しいワールドを生成するため、通常より少し時間がかかる場合があります。
:::

## リセットを確認する

サーバーが再びオンラインになったら接続し、新しいワールドが作成されていることを確認してください。

通常、以下の点で確認できます：

- 新しいスポーン状態
- 以前のプレイヤー建造物がない
- 以前の進行状況がない
- `Pal/Saved/SaveGames/0/`に新しく生成されたセーブフォルダーがある

もし古いワールドがまだ表示される場合は、再度サーバーを停止し、正しい16進数のセーブフォルダーが削除されたか確認してください。
