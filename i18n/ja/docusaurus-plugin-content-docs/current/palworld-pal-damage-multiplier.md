## はじめに

Palworldでは、サーバーのダメージ倍率設定を変更することで、Palが与えるダメージや受けるダメージの量を調整できます。このガイドでは、ZAP-Hostingのゲームサーバー管理画面で編集する設定ファイルや変更すべき値、正しい適用方法を解説します。



## 準備

始める前に、ZAP-Hostingのゲームサーバー管理パネルからPalworldゲームサーバーにアクセスできることを確認してください。

:::info 手動設定が必要です
この設定はPalworldの設定ファイルを手動で編集して行います。ゲーム内のコマンドでの変更は不要です。
:::

## 正しい設定ファイルを開く

Palダメージ倍率を変更するには、`PalWorldSettings.ini`ファイルを編集します。

ZAP-Hostingのゲームサーバー管理画面で「Configs」セクションを開き、`PalWorldSettings.ini`ファイルを探してください。このファイルにはPalworldサーバーの主要なワールドおよびゲームプレイ設定が含まれています。

:::note 設定ファイルの場所
本ガイドで扱うファイルは`PalWorldSettings.ini`で、ゲームサーバー管理画面の「Configs」からアクセス可能です。
:::

## Palダメージ倍率の値を編集する

`PalWorldSettings.ini`内の`OptionSettings`セクションを探してください。Palダメージ倍率の設定はこのセクション内のキーとして保存されています。

以下のエントリを調整します：

| 設定キー | デフォルト値 | 説明 |
| --- | --- | --- |
| `PalDamageRateAttack` | `1.000000` | Palが与えるダメージの倍率を制御 |
| `PalDamageRateDefense` | `1.000000` | Palが受けるダメージの倍率を制御 |

### 設定例

キーが既に存在する場合は、倍率に応じて値を変更してください。存在しない場合は`OptionSettings`内に追加します。

```ini
PalDamageRateAttack=1.500000
PalDamageRateDefense=0.800000
```

### 値の意味

倍率値を選ぶ際の参考として、以下の挙動を理解してください：

| 値の変化 | 効果 |
| --- | --- |
| `PalDamageRateAttack`が高い | Palがより多くのダメージを与える |
| `PalDamageRateAttack`が低い | Palが与えるダメージが減る |
| `PalDamageRateDefense`が高い | Palが受けるダメージが倍率に応じて増加（防御バランスが不利になる） |
| `PalDamageRateDefense`が低い | Palがより多くのダメージを受ける |

:::caution 倍率値は正確に入力してください
Palworldのサーバー設定は数値の倍率を使用します。`0.500000`、`1.000000`、`2.000000`のような有効な小数点数のみを入力してください。不正な書式は設定の読み込み失敗につながります。
:::

## 変更を保存する

`PalWorldSettings.ini`の編集が終わったら、ZAP-Hostingの設定エディターでファイルを保存してください。

PvEや協力プレイのバランス調整の場合は、倍率を一度に一つずつ変更することをおすすめします。これにより、ダメージの増減をテストしやすくなります。

:::tip 小さな調整から始めよう
`PalDamageRateAttack`を`1.200000`のように少しだけ上げる方が、`3.000000`のような大幅な変更よりバランスを取りやすいです。
:::

## サーバーを再起動する

設定を保存したら、Palworldサーバーを再起動して新しいダメージ倍率設定を反映させます。

ファイル編集後に追加のコンソールコマンドは不要です。サーバーの完全再起動だけで変更が適用されます。

| 操作 | 必要か |
| --- | --- |
| `PalWorldSettings.ini`の保存 | はい |
| 追加コマンドの実行 | いいえ |
| サーバーの再起動 | はい |

## 新しいダメージ設定を確認する

サーバー再起動後、Palworldサーバーに参加してPalとの戦闘をテストしてください。以下を確認しましょう：

- Palが期待通りのダメージを与えているか
- Palが期待通りのダメージを受けているか
- ゲームプレイのバランスがサーバー設定に合っているか

強すぎる、または弱すぎる場合は、再度`PalWorldSettings.ini`を編集し倍率を調整、保存してサーバーを再起動してください。
