## Introduction

Palworldでは、メインのワールド設定を通じてサーバー上のPal捕獲率を調整できます。このガイドでは、ZAP-Hostingのインターフェースで正しい設定ファイルの場所、変更すべき値、そして新しい捕獲率の適用方法を学びます。



## Preparation

始める前に、ZAP-HostingのウェブインターフェースからPalworldゲームサーバーにアクセスでき、サーバーがセットアップされて稼働中であることを確認してください。

:::info 設定ファイルへのアクセス
ZAP-HostingのPalworldサーバーでは、関連設定はゲームサーバー管理の`Configs`から編集可能です。
:::

## Palworld設定ファイルの場所を特定する

Pal捕獲率を変更するには、`PalWorldSettings.ini`ファイルを編集する必要があります。

### Configsセクションを開く

まず、ZAP-Hostingのウェブインターフェースにログインし、Palworldゲームサーバーを開きます。ゲームサーバー管理の中の`Configs`に移動してください。

そこで以下のファイルを探します：

```ini
PalWorldSettings.ini
```

### 正しい設定を見つける

`PalWorldSettings.ini`内では、Palworldの多くのゲームプレイ設定が`OptionSettings`セクションに保存されています。Pal捕獲に関係する設定は以下です：

```ini
PalCaptureRate=[your_value]
```

デフォルト値は通常：

```ini
PalCaptureRate=1.000000
```

値が高いほどPalの捕獲が簡単になり、低いほど捕獲が難しくなります。

## Pal捕獲率を編集する

正しいファイルを開いたので、好みのゲームバランスに合わせて捕獲率を調整できます。

### 設定値を変更する

`PalWorldSettings.ini`内で`PalCaptureRate`のエントリを探し、希望の倍率に値を置き換えます。

例：

```ini
PalCaptureRate=2.000000
```

これはデフォルト設定の2倍の捕獲率になります。

### 例示値

以下の表は一般的な参考値です：

| 値 | 効果 |
| --- | --- |
| `1.000000` | デフォルトのPal捕獲率 |
| `1.500000` | 少し簡単な捕獲 |
| `2.000000` | 明らかに簡単な捕獲 |
| `3.000000` | かなり簡単な捕獲 |

:::tip バランスの良い設定
捕獲を簡単にしたいが確実すぎないようにしたい場合、`1.500000`から`2.000000`の間の値が一般的に良い出発点です。
:::

## 変更を保存して適用する

`PalCaptureRate`の値を編集したら、ZAP-Hostingの設定エディタで変更を保存してください。

### サーバーを再起動する

Palworldはこの設定をライブで適用しません。ファイルを保存した後、ZAP-Hostingのサーバー管理からゲームサーバーを再起動して新しい捕獲率を読み込ませる必要があります。

:::caution 再起動が必要です
`PalWorldSettings.ini`を編集後にサーバーを再起動しないと、新しい捕獲率は反映されません。
:::

## 設定リファレンス

以下の表は今回の変更に使う設定の概要です：

| ファイル | 設定キー | デフォルト値 | 目的 | 再起動必要 |
| --- | --- | --- | --- | --- |
| `PalWorldSettings.ini` | `PalCaptureRate` | `1.000000` | Pal捕獲率の倍率を制御 | はい |

## トラブルシューティング

新しい捕獲率が反映されない場合は、以下を確認してください。

### 設定フォーマットの確認

行が正しく記述されているか、数値が使われているか確認してください。例：

```ini
PalCaptureRate=2.000000
```

余計な文字や関係ないエントリの変更は避けてください。

### ファイルが保存されたか確認

編集後、`Configs`セクションで`PalWorldSettings.ini`の変更が実際に保存されているか確認してください。

### 必要なら再度再起動

変更後にサーバーが正しく再起動されていなければ、サーバー管理からもう一度再起動してください。

:::note サーバー側のゲームプレイ設定
`PalCaptureRate`はサーバーのゲームプレイ設定なので、プレイヤーはサーバーが更新された設定を読み込んだ後にのみ新しい捕獲率を体感します。
:::
