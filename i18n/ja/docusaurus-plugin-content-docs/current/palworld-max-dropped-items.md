## Introduction

Palworldでは、世界に存在できるドロップアイテムの最大数や、アイテムが消えるまでの時間を制御できます。このガイドでは、ZAP-Hostingのインターフェースで正しい設定ファイルを編集し、ドロップアイテムの設定を調整して安全に反映させる方法を説明します。

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

## Preparation

始める前に、ZAP-HostingのPalworldゲームサーバーにアクセスでき、設定ファイルを編集する権限があることを確認してください。

:::info 手動設定が必要です
この設定はPalworldサーバーの設定ファイルを手動で編集して行います。必要なファイルはゲームサーバー管理画面の「Configs」からアクセス可能です。
:::

## Palworld設定ファイルを開く

ドロップアイテムの上限を変更するには、`PalWorldSettings.ini`ファイルを編集します。

ZAP-Hostingのゲームサーバー管理画面で：

1. Palworldサーバーを開く
2. 「Configs」に移動
3. `PalWorldSettings.ini`ファイルを開く

このファイルには、ドロップアイテムの挙動を含むPalworldサーバーの主要なゲームプレイ設定が含まれています。

## ドロップアイテム設定を変更する

ドロップアイテムの設定は`PalWorldSettings.ini`内のエントリで管理されています。ファイル内の有効な設定行またはセクションの該当値を調整してください。

### 関連する設定キー

ドロップアイテムを制御するために以下の設定キーを使用します：

| 設定キー | デフォルト値 | 説明 |
| --- | --- | --- |
| `DropItemMaxNum` | `3000` | 世界に同時に存在できるドロップアイテムの最大数 |
| `DropItemAliveMaxHours` | `1.0` | ドロップアイテムが自動的に消失するまでの時間（時間単位） |

### 設定例

現在のファイル内容によりますが、これらの値は通常Palworldのオプション設定エントリの一部です。例：

```ini
OptionSettings=(DropItemMaxNum=3000,DropItemAliveMaxHours=1.000000)
```

もし`OptionSettings`エントリにこれらのキーが既に存在する場合は、値だけを変更してください。例：

```ini
OptionSettings=(DropItemMaxNum=2000,DropItemAliveMaxHours=0.500000)
```

この例では：

- `DropItemMaxNum=2000` は世界のドロップアイテム数を最大2000個に制限
- `DropItemAliveMaxHours=0.500000` はドロップアイテムが0.5時間（30分）で消える設定

:::note 値のフォーマットについて
Palworldのサーバー設定は`1.000000`のように小数点以下に複数のゼロを含む形式が多いです。可能な限り既存のフォーマットスタイルを維持してください。
:::

## 適切な値を選ぶ

適切な値はプレイヤー数、サーバーの稼働状況、アイテム生成量によって異なります。

### 推奨ユースケース

| シナリオ | `DropItemMaxNum` | `DropItemAliveMaxHours` |
| --- | --- | --- |
| 小規模プライベートサーバー | `3000` | `1.000000` |
| 多人数マルチプレイヤーサーバー | `2000` | `0.500000` |
| パフォーマンス重視の設定 | `1000`〜`1500` | `0.250000`〜`0.500000` |

### パフォーマンスに関する注意点

ドロップアイテムの上限を下げると、特に以下の場合にサーバーのパフォーマンスが向上します：

- 多数のプレイヤーが同時にアクティブな場合
- 世界で大量のアイテムが生成される場合
- プレイヤーが頻繁に採取、建築、または地面にアイテムを残す場合

:::tip アイテム上限を下げてパフォーマンス改善
ラグやサーバーの応答遅延を感じたら、ドロップアイテムの最大数と消失時間の両方を下げることで、世界のアイテム数を減らし安定性を向上させられます。
:::

:::caution 極端に低い値は避ける
値を低く設定しすぎると、プレイヤーがアイテムの消失が早すぎると感じたり、ドロップアイテムの上限にすぐ達してしまう可能性があります。設定変更後は必ず動作をテストしてください。
:::

## 変更を保存して適用する

`PalWorldSettings.ini`を編集後、ZAP-Hostingのインターフェースでファイルを保存してください。

保存後、Palworldサーバーを再起動して新しいドロップアイテム設定を反映させます。

| 操作 | 必要か |
| --- | --- |
| `PalWorldSettings.ini`の保存 | はい |
| サーバーの再起動 | はい |
| 追加のコンソールコマンド | いいえ |

:::info 再起動が必要です
`PalWorldSettings.ini`の変更は、Palworldサーバーを再起動するまで反映されません。
:::

## 新しい設定を確認する

再起動後、サーバーに参加して通常のプレイ中にドロップアイテムの挙動を監視してください。

以下を確認しましょう：

- ドロップアイテムの数が期待通りに制御されているか
- アイテムが地面に残る時間が設定通りか
- アイテム数や寿命を減らしたことでサーバーのパフォーマンスが改善したか

必要に応じて`PalWorldSettings.ini`に戻り、値を微調整してください。
