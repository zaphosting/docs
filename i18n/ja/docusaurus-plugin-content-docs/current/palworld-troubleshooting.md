## はじめに

Palworld専用サーバーは、Steamアップデートの失敗、バージョン不一致、MODの競合、一時的なSteam接続問題など、さまざまな理由で動作しなくなることがあります。このガイドでは、ZAP-HostingでよくあるPalworldサーバーの問題を特定し、設定ファイルの編集、ファイル検証、サーバー再起動などの正しい対処法を学びます。

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

## 準備

トラブルシューティングを始める前に、ZAP-HostingのWebインターフェースでPalworldゲームサーバーの管理とコンソールにアクセスできることを確認してください。

また、以下の準備も整えておきましょう：

| 必要なもの | 理由 |
| --- | --- |
| ZAP-Hostingゲームサーバーパネルへのアクセス | サーバーの停止、起動、再インストール、設定ファイル編集に必要 |
| サーバーコンソールへのアクセス | サーバーが応答しているか確認するのに便利 |
| 最新のバックアップ | ファイル変更やMOD削除前に推奨 |
| サーバーの直接IPとポート | ゲーム内の「最近のサーバー」リストが信頼できない場合があるため必要 |

:::caution まずはバックアップを作成してください
MODの削除、ファイルの再インストール、Palworldサーバー設定のリセットを行う場合は、誤ってデータを失わないように必ずバックアップを作成してください。
:::

## Palworld設定ファイルへのアクセス

トラブルシューティングの一部では、Palworldの設定ファイルを手動で変更する必要があります。ZAP-Hostingでは、ゲームサーバー管理の`Configs`からこれらのファイルにアクセスできます。

Palworld専用サーバーの主要な設定は通常、以下のファイルに保存されています：

```text
Pal/Saved/Config/LinuxServer/PalWorldSettings.ini
```

サーバーが異なるプラットフォームテンプレートで動作している場合、フォルダ名は異なることがありますが、LinuxベースのPalworldサーバーでは`LinuxServer`パスが標準です。

### ZAPインターフェースで設定ファイルを開く

ファイルにアクセスするには：

1. ZAP-HostingのWebインターフェースでPalworldサーバーを開く。
2. `Configs`セクションに移動する。
3. `PalWorldSettings.ini`を開く。
4. ゲームプレイや接続関連の設定が多く含まれる`OptionSettings=(...)`行を確認する。

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

:::info メイン設定ファイルについて
ほとんどのPalworldサーバーオプションは`PalWorldSettings.ini`の`OptionSettings=(...)`セクションに保存されています。ゲームプレイ設定、パスワード、プレイヤー制限、ネットワーク関連の値を調整する場合は、このファイルを編集します。
:::

### 編集後の保存と再起動

設定値を変更したら：

1. `Configs`セクションでファイルを保存する。
2. ZAP-HostingインターフェースからPalworldサーバーを再起動する。

Palworldは設定変更をライブで確実に反映しないため、`PalWorldSettings.ini`編集後は必ず再起動が必要です。

## Steamアップデート失敗の修正

以下のメッセージが表示される既知のアップデート問題があります：

```text
Error! app '2394010' state is 0x6 after update job
```

これは通常、PalworldのSteamサーバーファイルが正しく更新されなかったことを示します。

### 推奨される修正方法

解決するには：

1. Palworldサーバーを停止する。
2. ZAP-Hostingインターフェースのサーバー管理画面を開く。
3. 再インストールまたはファイル検証機能を使用する。
4. 整合性の検証オプションを選択し、サーバーファイルをチェックして必要に応じて再ダウンロードする。
5. サーバーを再起動する。

:::tip ファイル破損の検証が最も安全な初手
ファイル検証は、Palworldゲームサーバーファイルの欠損や破損を修復するため、手動アップロード不要で最も安全な最初の対処法です。
:::

### 設定ファイルの編集は必要？

このエラーに対しては通常、設定ファイルの手動変更は不要です。問題は`PalWorldSettings.ini`の設定ミスではなく、破損または不完全なゲームファイルに起因します。

## 「接続タイムアウト」の修正

Palworldゲームサーバーに接続中に`Connection timed out`エラーが出る場合、原因は複数考えられます。

## サーバーが実際に起動しているか確認する

まず、サーバーが正しく起動しているか確認しましょう。

### コンソールを使う

ZAP-Hostingのサーバーコンソールを開き、正常な起動ログがあるか確認します。コンソールが利用可能なら、以下の簡単なコマンドを試してください：

```text
info
```

サーバーが正常に応答すれば起動しています。応答がなかったりプロセスが繰り返し停止する場合は、起動時にクラッシュしている可能性があります。

### リソース使用状況を確認

起動中にCPU使用率が異常に低く、コンソールに応答がない場合は、Palworldサーバープロセスがクラッシュまたは初期化に失敗している可能性があります。

| 症状 | 可能な原因 | 推奨アクション |
| --- | --- | --- |
| コンソールに応答なし | 起動時クラッシュまたはハング | サーバーを再起動し、最近の変更を確認 |
| 起動中のCPU使用率が非常に低い | サーバーが正しく初期化されていない | MOD、最近のアップデート、ログを確認 |
| サーバーは起動するがプレイヤーがタイムアウト | 接続方法またはバージョンの問題 | 直接IPを使い、バージョンを確認 |

## 「最近のサーバー」ではなく直接IPで接続する

Palworldのよくある問題として、ゲーム内の「最近のサーバー」タブからの接続が失敗することがあります。

代わりに直接接続を試してください：

1. ZAP-HostingインターフェースからサーバーのIPとポートをコピーする。
2. Palworldでそのアドレスを使って直接接続する。
3. テスト時は「最近のサーバー」リストに頼らない。

:::note 直接接続のほうが信頼性が高い
PalworldのSteamサーバーブラウザや最近のサーバーリストが不安定な場合、直接IP接続がサーバー到達性を確認する最良の方法です。
:::

## MODやUE4SSの問題を確認する

Palworldが最近アップデートされ、サーバーでMODや`UE4SS`を使用している場合、これらの変更が更新されるまでサーバーが動作しなくなることがあります。

### 確認すべきこと

以下を最近インストールまたは更新していないか確認してください：

- ゲームプレイMOD
- カスタムサーバー改造
- `UE4SS`
- Palworldゲームサーバーにフックするその他のサードパーティファイル

問題がPalworldのSteamアップデート直後に発生した場合、これらのファイルが原因の可能性が高いです。

### 推奨される修正方法

1. サーバーを停止する。
2. バックアップを作成する。
3. 最近追加したMODや`UE4SS`を削除または無効化する。
4. サーバーを再起動する。
5. 直接IP接続で動作をテストする。

:::caution アップデート後のMOD互換性に注意
PalworldのアップデートはMODを予告なく壊すことがあります。アップデート前は動作していたのに停止した場合は、他の設定を変える前に必ずMODを外してテストしてください。
:::

### 設定変更は必要？

通常は不要です。MOD関連の接続タイムアウトは`PalWorldSettings.ini`内の設定値ではなく、互換性のないファイルが原因です。

## Steam接続エラーの修正

起動時に以下のメッセージが表示されることがあります：

```text
Connecting anonymously to Steam Public...Retrying
```

これはPalworldの設定破損ではなく、一時的なSteam接続問題に関連しています。

### これは何を意味するか

Palworld専用サーバーは起動やアップデートの一部にSteamサービスを利用しています。Steamが障害、過負荷、メンテナンス中の場合、サーバーが一時的に接続に失敗することがあります。

特にトラフィックが多い時間帯や、通常は火曜日に行われるSteamの定期メンテナンス時に多く発生します。

### 推奨される修正方法

以下を試してください：

1. 5〜10分待つ。
2. サーバーを再起動する。
3. 再度テストする。

Steam全体の障害中は、Steamサービスが復旧するまで待つ必要があります。

### 自動アップデートの考慮

Steam障害時にアップデート関連の起動問題が繰り返される場合、Steamが安定するまでサーバー設定で自動アップデートを無効にすることも検討してください。

:::tip Steamメンテナンス中のアップデートは避ける
可能であれば、Steamのメンテナンス期間中にPalworldのSteamアップデートを強制しないようにしましょう。起動失敗や不要なトラブルシューティングを減らせます。
:::

### 設定変更は必要？

いいえ。この問題は通常、`PalWorldSettings.ini`や他の手動設定ファイルで修正できません。

## 「ゲームのバージョンが互換性がない」問題の修正

Palworldで「マッチが互換性のないゲームバージョンで実行されています」というメッセージが出る場合、クライアントとサーバーのバージョンが一致していません。

## サーバーバージョンを更新する

まず、ZAP-Hostingインターフェースからサーバーを再起動してください。多くの場合、これで最新のPalworldゲームサーバーアップデートが適用されます。

それでもバージョンが合わない場合は、通常のサーバーアップデート手順を実行してください。専用のアップデートガイドがZAP-Docsにあればそちらを参照してください。

### クライアントバージョンを確認する

ローカルのPalworldゲームもSteamで完全にアップデートされていることを確認してください。

| コンポーネント | 確認内容 |
| --- | --- |
| Palworldサーバー | ZAP-Hostingで再起動・更新済み |
| ローカルPalworldゲーム | Steamで最新に更新済み |
| MOD | 互換性がなければ更新または削除 |

:::info バージョン不一致は両方に影響
このエラーは必ずしもサーバーが古いとは限りません。ローカルのPalworldクライアントが古い場合もあるため、両方を必ず確認してください。
:::

### 設定変更は必要？

バージョン不一致に対して設定ファイルの編集は通常不要です。

## `steamclient.so`起動メッセージの理解

起動時に以下のようなメッセージが表示されることがあります：

```text
steamclient.so: cannot open shared object file: No such file or directory
```

多くのPalworldホスティング環境では、サーバーが正常に起動していてもこのSteam関連のメッセージが表示されることがあります。

### 対応方法

サーバーが起動し続けて接続可能なら、このメッセージは無視して問題ありません。

### 問題になる場合

サーバーが完全に起動しない場合で、このメッセージと致命的なエラーが同時に出る場合のみ、さらに調査してください。

:::note すべてのSteamエラーが致命的ではない
起動ログには非致命的な警告が含まれることが多いです。コンソールに警告があっても、サーバーが起動して接続を受け入れているかを重視してください。
:::

## ワールドやギルド関連の接続問題のトラブルシューティング

場合によっては、サーバープロセス自体ではなく、ワールドやギルドの状態に関連した接続問題が発生することがあります。

報告例としては、ギルドメンバーが離脱した後もオフラインプレイヤーに関連したギルドデータが残り、参加できなくなるケースがあります。

### 考えられる対処法

以下を順に試してください：

1. 影響を受けたプレイヤーに可能ならギルドに再加入してもらう。
2. Palworldサーバーを再起動する。
3. 問題が続く場合はバックアップから復元するか、該当のセーブデータを慎重に調査する。

:::danger セーブデータの変更はリスクあり
ワールドやセーブの破損が疑われる場合、最新のバックアップがない限り、無闇に手動でファイルを編集しないでください。誤った編集はPalworldのワールドデータを永久に破損する恐れがあります。
:::

## チェックすべき設定値

このガイドの多くの問題は設定ミスが直接原因ではありませんが、プレイヤーが参加できない場合に`PalWorldSettings.ini`の以下の値を確認すると良いでしょう。

これらの値は通常、`OptionSettings=(...)`セクション内にあります。

| 設定キー | 用途 | 確認ポイント |
| --- | --- | --- |
| `ServerName` | 公開サーバー名 | 意図した名前になっているか |
| `ServerDescription` | サーバー説明 | 任意だが識別に便利 |
| `AdminPassword` | 管理者ログインパスワード | 管理コマンドを使う場合は正しいか |
| `ServerPassword` | 参加パスワード | プレイヤーが認証できない場合は削除または修正 |
| `PublicPort` | ゲーム接続ポート | サービスに割り当てられたポートと一致しているか |
| `PublicIP` | 公開IPアドレス | 特別な理由がなければ変更しない |
| `bIsMultiplay` | マルチプレイヤーモード | 通常の専用サーバー利用なら有効にする |
| `bIsDedicated` | 専用サーバーモード | ホスティング専用サーバーなら有効にする |

### 設定例

ファイルの内容は異なる場合がありますが、関連設定は通常以下のような行にあります：

```ini
[/Script/Pal.PalGameWorldSettings]
OptionSettings=(ServerName="zaphosting",ServerDescription="Palworld Server",AdminPassword="[your_admin_password]",ServerPassword="[your_server_password]",PublicPort=8211,PublicIP="",bIsMultiplay=True,bIsDedicated=True)
```

`[your_admin_password]`や`[your_server_password]`などのプレースホルダーは、ご自身の値に置き換えてください。

:::caution 不明な値は勝手に変更しないでください
Palworldは多くの設定を1行の`OptionSettings`にまとめています。カンマ、引用符、括弧を誤って削除すると、設定が正しく読み込まれなくなります。
:::

## 安全に設定変更を適用する方法

`PalWorldSettings.ini`を編集する必要がある場合は、以下の手順で行ってください：

1. 編集中の競合を避けるため、サーバーを停止する。
2. ZAP-Hostingインターフェースの`Configs`を開く。
3. `Pal/Saved/Config/LinuxServer/PalWorldSettings.ini`を編集する。
4. 変更を保存する。
5. サーバーを起動または再
