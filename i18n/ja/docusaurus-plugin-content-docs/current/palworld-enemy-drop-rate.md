## はじめに

`EnemyDropItemRate` は Palworld における敵のドロップする戦利品の量を制御します。このガイドでは、ZAP-Hostingのゲームサーバー管理画面で正しい設定ファイルを手動で編集し、新しい敵のドロップ率を適用する方法を学びます。



## 準備

始める前に、Palworldゲームサーバーの管理パネルにアクセスでき、サーバー設定ファイルを編集する権限があることを確認してください。

:::info 手動設定が必要です
この設定はサーバー設定ファイルを手動で編集して行います。該当ファイルはZAP-Hostingのゲームサーバー管理画面の`Configs`にあります。
:::

## 設定ファイルの場所を特定する

敵のドロップ率を変更するには、`PalWorldSettings.ini`ファイルを編集する必要があります。

### Configsセクションを開く

ZAP-Hostingのゲームサーバー管理画面にログインし、Palworldサーバーを開きます。次に、利用可能な設定ファイルが一覧表示される`Configs`セクションに移動します。

### `PalWorldSettings.ini`を選択する

`Configs`エリアから`PalWorldSettings.ini`ファイルを開きます。このファイルにはPalworldゲームサーバーの主要なゲームプレイ設定値が含まれており、戦利品やドロップに関する設定もここにあります。

:::note 設定ファイルの概要
Palworld専用サーバーでは、ゲームプレイ設定は通常`PalWorldSettings.ini`に保存されています。敵の戦利品倍率は`EnemyDropItemRate`エントリで設定されています。
:::

## 敵のドロップ率を編集する

正しいファイルを開いたので、戦利品のドロップ倍率を調整できます。

### 正しい設定を探す

`PalWorldSettings.ini`内で`OptionSettings`行を検索し、以下のキーを見つけてください。

```ini
EnemyDropItemRate=1.000000
```

すでにキーが存在する場合は、お好みの倍率に値を変更します。

### 希望の倍率を設定する

`EnemyDropItemRate`は数値の倍率を使用します：

| 設定キー | デフォルト値 | 例の値 | 効果 |
| --- | --- | --- | --- |
| `EnemyDropItemRate` | `1.000000` | `2.000000` | 敵が2倍のアイテムをドロップ |
| `EnemyDropItemRate` | `1.000000` | `0.500000` | 敵が少ないアイテムをドロップ |
| `EnemyDropItemRate` | `1.000000` | `3.000000` | 敵が3倍のアイテムをドロップ |

例えば、倒した敵や野生のパル、ボスからの戦利品を2倍にしたい場合は、以下のように設定します。

```ini
EnemyDropItemRate=2.000000
```

`OptionSettings`全体を編集する場合は、次のような記述になることがあります。

```ini
OptionSettings=(EnemyDropItemRate=2.000000)
```

:::caution 既存の設定を保持してください
多くのPalworldサーバー設定では、`OptionSettings`に複数の値が1行にまとめられています。`EnemyDropItemRate`の値だけを変更し、カンマや括弧、他の設定を削除しないように注意してください。設定が無効になる恐れがあります。
:::

## 関連するドロップ制限を確認する

高い戦利品倍率は地面に落ちるアイテム数を増やすため、特に激しい戦闘やボス戦時にサーバーのパフォーマンスに影響を与える可能性があります。

### `DropItemMaxNum`を確認する

サーバーにすでに大量の同時ドロップアイテムがある場合は、同じ設定ファイル内の`DropItemMaxNum`設定を見直してください。

| 設定キー | 目的 |
| --- | --- |
| `EnemyDropItemRate` | 倒した敵のドロップ戦利品の倍率 |
| `DropItemMaxNum` | 同時に存在できるドロップアイテムの最大数制限 |

:::tip 戦利品とパフォーマンスのバランス
`EnemyDropItemRate`を大幅に増やす場合は、`DropItemMaxNum`を適切な値に保ち、不要なアイテムの蓄積やパフォーマンス低下のリスクを減らすことをおすすめします。
:::

## 変更を保存して適用する

設定を編集したら、`Configs`セクションで`PalWorldSettings.ini`ファイルを保存します。

### サーバーを再起動する

ファイルを保存したら、Palworldサーバーを再起動して新しい設定を読み込ませます。

| 操作 | 必要か |
| --- | --- |
| `PalWorldSettings.ini`の保存 | はい |
| サーバーの再起動 | はい |
| 追加のコンソールコマンド | 確認されたコマンドは不要 |

:::info 再起動が必要です
`PalWorldSettings.ini`の変更は実行中に即時反映されません。ファイル保存後にサーバーを再起動してください。
:::

## 新しいドロップ率を確認する

再起動が完了したら、Palworldサーバーに参加して敵を倒し、新しい戦利品倍率が期待通りに機能しているか確認してください。

ドロップ量が変わらない場合は、`PalWorldSettings.ini`を再度開き、以下を確認してください。

- `EnemyDropItemRate`のスペルが正しいか
- 値が正しい`OptionSettings`設定内にあるか
- ファイルが正常に保存されているか
- 変更後にサーバーが再起動されているか
