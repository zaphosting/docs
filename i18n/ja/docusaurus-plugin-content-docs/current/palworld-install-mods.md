## はじめに

Palworldは主に`UE4SS`、`.lua`、および`.pak`モッズの複数の種類をサポートしています。このガイドでは、サーバーの準備、正しいモッドタイプの特定、必要なファイルのアップロード、そしてモッズを正しく読み込むためのサーバー再起動方法を学びます。

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

## 準備

モッズをインストールする前に、サーバーと選択したモッドが互換性があることを確認してください。

:::danger まずはワールドのバックアップを作成しましょう
モッズをインストールする前に、必ずPalworldのセーブデータのバックアップを作成してください。モッドが互換性がなかったり起動問題を引き起こした場合、以前のワールド状態に戻す必要があります。
:::

以下をまず確認してください：

| 要件 | 詳細 |
| --- | --- |
| サーバーエディション | 専用Palworldサーバーは**Steam**版を使用します。**Game Pass**版専用のモッズは使用しないでください。 |
| モッド互換性 | モッド作者が専用サーバーで動作すると明示しているか確認してください。 |
| モッドタイプ | モッドが`UE4SS`、`.lua`、または`.pak`のどれかを確認してください。 |
| クライアント要件 | 一部のモッズは**サーバー**とすべての**プレイヤークライアント**にインストールが必要です。 |
| サーバーバージョン | モッドインストール前に現在のサーバーバージョンを確認してください。 |

### サーバーバージョンの確認

現在のPalworldサーバーバージョンを確認するには、ZAP-Hostingのゲームサーバー管理画面でサーバーコンソールを開き、以下を実行します：

```text
info
```

これによりバージョン情報が表示され、モッドの要件と比較できます。

:::tip モッドは一つずつインストール
モッドは一度に一つだけインストールし、動作確認を行ってから次のモッドを追加してください。サーバーが起動しない場合やモッドが正しく動作しない場合のトラブルシューティングが簡単になります。
:::

## インストールするモッドタイプの理解

Palworldのモッズはすべて同じ方法でインストールされるわけではありません。ファイルをアップロードする前にモッドタイプを特定する必要があります。

| モッドタイプ | 典型的な内容物 | 一般的なインストールパス | 備考 |
| --- | --- | --- | --- |
| `UE4SS` / `.lua` モッド | `main.lua`などのスクリプトを含むフォルダ | `Pal/Binaries/Win64/ue4ss/Mods/` | 通常は`UE4SS`フレームワークが必要 |
| `.pak` モッド | 1つ以上の`.pak`ファイル、時に追加ファイルあり | `Pal/Content/Paks/~mods/` | 一部モッドは`Pal/Content/Paks/LogicMods/`を使用 |
| クライアント側モッド | 内容は様々 | サーバーに必ずしもインストールしない | モッド作者がサーバー対応を明示している場合のみ使用 |

:::caution モッド作者の指定パスを必ず守ること
このガイドのパスは現在一般的なPalworldモッズの場所です。しかし、一部モッドは異なるフォルダ構成を要求します。作者の指示が異なる場合は必ずそちらに従ってください。
:::

## ZAPインターフェースでサーバーファイルにアクセス

ZAP-Hostingのゲームサーバー管理画面のファイル管理機能を使います。

### Configsセクションを開く

関連する設定ファイルはゲームサーバー管理画面の**Configs**でアクセスできます。Palworldサーバーの設定ファイルの確認や編集に便利です。

:::note Configsとモッドファイルの違い
Palworldのモッドインストールは通常、単一の設定ファイルのゲームプレイ設定を変えるだけでは完了しません。ほとんどの場合、正しいサーバーディレクトリにモッドファイルをアップロードし、必要に応じて**Configs**内の設定ファイルを編集します。
:::

### ファイルマネージャーを開く

`.pak`アーカイブや`UE4SS`スクリプトフォルダなどのモッドファイルをアップロードするには、ZAPインターフェースのファイルマネージャーからサーバーファイルにアクセスする必要があります。

モッドに独自の設定ファイルが含まれている場合は、作者の指示通りにアップロードし、サポートされている値のみを編集してください。

## 必要に応じてUE4SSフレームワークをインストール

`UE4SS`は多くのPalworld Luaおよびスクリプトベースのモッドで使われるモッディングフレームワークです。選択したモッドが依存している場合のみ必要です。

### サーバーがWindowsであることを確認

Palworldの`UE4SS`は通常Windowsサーバービルドで使用されます。サーバーがWindows環境でない場合、`UE4SS`ベースのモッドは期待通りに動作しない可能性があります。

:::info UE4SSの必要性
選択したモッドが`UE4SS`または`.lua`モッドの場合、モッドをアップロードする前にフレームワークが既に存在することを確認してください。
:::

### UE4SSのインストールパスを確認

`UE4SS`がインストールされている場合、通常のディレクトリは以下です：

```text
Pal/Binaries/Win64/ue4ss/
```

多くの`UE4SS`およびLuaモッドが使用するモッドフォルダは：

```text
Pal/Binaries/Win64/ue4ss/Mods/
```

ZAP-Hostingの製品でサーバー管理画面に組み込みのモッディングや`UE4SS`オプションがあれば利用可能です。表示されない場合は、その製品やサーバータイプで利用できないと考えてください。

## LuaまたはUE4SSモッドのアップロードとインストール

Luaやその他の`UE4SS`ベースのPalworldモッドは、通常単一の`.pak`ファイルではなくフォルダとして配布されます。

### ローカルデバイスでモッドを解凍

モッド作者の公式リリースページからアーカイブをダウンロードし、まずPCで解凍してください。作者が明示的に指示しない限り、`.zip`や`.rar`ファイルをそのままアップロードしないでください。

### 正しいパスにモッドフォルダをアップロード

ほとんどのLuaまたは`UE4SS`モッドは、解凍したモッドフォルダを以下にアップロードします：

```text
Pal/Binaries/Win64/ue4ss/Mods/
```

典型的なLuaモッドの構造例：

```text
Pal/Binaries/Win64/ue4ss/Mods/UploadedMod/scripts/main.lua
```

`UploadedMod`はモッド作者が提供した実際のフォルダ名に置き換えてください。

### 構造例

| 項目 | 例のパス |
| --- | --- |
| モッドフォルダ | `Pal/Binaries/Win64/ue4ss/Mods/UploadedMod/` |
| スクリプトファイル | `Pal/Binaries/Win64/ue4ss/Mods/UploadedMod/scripts/main.lua` |

:::caution ファイル名やフォルダ名を勝手に変更しない
モッド作者が明示的に指示しない限り、モッドフォルダやスクリプトファイル、内部ディレクトリ構造の名前を変更しないでください。多くの`UE4SS`モッドは元の構造に依存して正しく読み込まれます。
:::

## .pakモッドのアップロードとインストール

`.pak`モッドはLuaや`UE4SS`スクリプトモッドとは異なる方法でインストールします。

### `.pak`ファイルをアップロード

ほとんどのPalworld `.pak`モッドは以下にアップロードします：

```text
Pal/Content/Paks/~mods/
```

例：

```text
Pal/Content/Paks/~mods/UploadedMod.pak
```

一部のモッドは代わりに以下を使用するよう指示する場合があります：

```text
Pal/Content/Paks/LogicMods/
```

### 追加ファイルがある場合の確認

一部の`.pak`モッドはメタデータや補助ファイルなど複数のファイルを含む場合があります。モッドアーカイブに複数の必要ファイルがある場合は、作者の指示通りすべてアップロードしてください。

| 一般的な`.pak`場所 | 用途 |
| --- | --- |
| `Pal/Content/Paks/~mods/` | 一般的な`.pak`モッドの最も多い場所 |
| `Pal/Content/Paks/LogicMods/` | 作者の指示により使われる場合あり |

## モッドの設定ファイルを編集（必要な場合）

一部のPalworldモッドはアップロード後に編集が必要な独自の設定ファイルを含みます。設定内容はモッドによって異なり、ファイル名や値も選択したモッド次第です。

### 設定ファイルの場所

モッドが設定ファイルを提供する場合、アップロード後に以下の場所にあることがあります：

| モッドタイプ | 設定ファイルの可能な場所 |
| --- | --- |
| `UE4SS` / `.lua` モッド | `Pal/Binaries/Win64/ue4ss/Mods/[your_mod_name]/`内のモッドフォルダ |
| `.pak` モッド | 編集可能な設定が含まれない場合もあるため、モッドのドキュメントを確認 |
| サーバー設定統合 | 場合によってはZAPサーバー管理画面の**Configs**から追加設定可能 |

### 何を変更するか

モッド作者が明示的に記載している値のみ変更してください。一般的な例は：

- モッド機能の有効化・無効化
- 乗数や制限の設定
- 管理者専用動作の定義
- キー名や内部オプションの変更

Palworldモッドは統一された設定フォーマットを使っていないため、すべてのモッドに共通する設定項目はありません。

:::info Palworldモッドに共通の設定項目はなし
現在、すべてのモッドをグローバルに有効化する単一のPalworldサーバー設定ファイルや組み込み設定セクションはありません。実際には正しいファイルを正しいディレクトリに配置し、モッド固有の設定ファイルがあれば編集する形でインストールします。
:::

## サーバーを再起動してモッドをテスト

モッドファイルのアップロードと必要な設定変更が完了したら、Palworldサーバーを再起動してください。

### サーバーの再起動

ZAP-Hostingのゲームサーバー管理画面の再起動機能を使い、サービスを完全に再起動します。

この手順は、Palworldが通常、新たにアップロードされたサーバーモッドをサーバー起動時まで読み込まないため必須です。

### 動作確認

再起動後：

1. サーバーに参加します。
2. ゲーム内でモッド機能をテストします。
3. モッドが動作しない場合はサーバーコンソールのエラーを確認します。
4. サーバーが起動しない、または異常動作する場合は、直近に追加したモッドファイルを削除してください。

:::tip モッド不具合のトラブルシューティング
問題が発生した場合は、直近にインストールしたモッドのファイルだけをまず削除し、サーバーを再起動してください。これが原因特定の最速の方法です。
:::
