## はじめに

Palworldでは、各ギルドがサーバー上に設置できる拠点の最大数を制御できます。このガイドでは、ZAP-Hostingのウェブインターフェースで正しい設定ファイルを手動で編集し、`BaseCampMaxNumInGuild`設定を変更してサーバーを再起動し、変更を適用する方法を説明します。



## 準備

始める前に、ZAP-HostingのウェブインターフェースでPalworldゲームサーバーにアクセスできることを確認してください。

:::info 必要なアクセス権
Palworldサーバーの管理と、設定ファイルを編集するための`Configs`セクションへのアクセス権が必要です。
:::

## 設定ファイルの場所を確認する

最大ギルド拠点数の設定を変更するには、`PalWorldSettings.ini`ファイルを編集する必要があります。

ZAP-HostingのウェブインターフェースでPalworldゲームサーバーの管理画面を開き、以下のパスに移動してください：

`Configs` → `PalWorldSettings.ini`

このファイルには、ギルドや拠点の制限を含むPalworldサーバーの主要なゲームプレイ設定値が含まれています。

## 最大ギルド拠点数の値を編集する

`PalWorldSettings.ini`内の`OptionSettings`セクションを探してください。変更する設定は以下の通りです：

`BaseCampMaxNumInGuild=[your_value]`

`[your_value]`には、各ギルドが設置可能な拠点数の希望する数値を入力してください。

### 設定例

ギルドごとに最大`6`拠点を許可したい場合、設定は以下のようになります：

```ini
BaseCampMaxNumInGuild=6
```

設定が既に存在する場合は値のみを変更し、存在しない場合はファイル内の既存の`OptionSettings`パラメーターリスト内に追加してください。

:::note デフォルト値とバニラの最大値
現在の参考情報によると、デフォルト値は`4`、通常のバニラ最大値は`10`です。`10`を超える値は、通常の無改造Palworldサーバーではサポートされていません。
:::

### 値の参照表

| 設定キー | 説明 | デフォルト値 | バニラ最大値 |
| --- | --- | --- | --- |
| `BaseCampMaxNumInGuild` | ギルドごとに許可される最大拠点数 | `4` | `10` |

:::caution 有効な値を使用する
`BaseCampMaxNumInGuild`は妥当でサポートされている値に設定してください。`10`を超える値は通常サーバー側の改造が必要で、標準のPalworldサーバーでは正しく動作しない可能性があります。
:::

## 設定の保存

値を変更したら、ZAP-Hostingの設定エディターで`PalWorldSettings.ini`ファイルを保存してください。

これで新しい最大ギルド設定が保存されますが、サーバーを再起動するまで反映されません。

## サーバーの再起動

ファイルを保存したら、サーバー管理画面からPalworldサーバーを再起動してください。

Palworldはサーバー起動時に`PalWorldSettings.ini`の設定を読み込むため、再起動しないと新しいギルド拠点制限は通常適用されません。

### 再起動後に行うこと

`BaseCampMaxNumInGuild`を編集した後、追加のコンソールコマンドは通常不要です。再起動後に新しい値が自動的に有効になります。

| 操作 | 必要か |
| --- | --- |
| `PalWorldSettings.ini`の保存 | はい |
| サーバーの再起動 | はい |
| 追加コマンドの実行 | いいえ |

:::tip 新しい制限のテスト
再起動後、サーバーに参加してギルドで拠点設置制限が期待通りに適用されているかテストしてください。
:::

## トラブルシューティング

最大ギルド拠点数の設定が反映されない場合は、以下の点を確認してください。

### 設定エントリーの確認

`BaseCampMaxNumInGuild`が正しく記述され、数値が設定されているか確認してください。例：

```ini
BaseCampMaxNumInGuild=8
```

キー名のタイプミスや無効な値は設定が機能しない原因になります。

### ファイルが保存されているか確認

サーバー再起動前に`Configs` → `PalWorldSettings.ini`で変更が保存されているか確認してください。

### サーバーを完全に再起動する

設定変更後は必ずサーバーを完全に再起動してください。保存だけで再起動しないと古い値が使われ続けます。

### バニラの制限内に収める

`10`を超える値を設定すると、対応するMODを使用していない限りサーバーが無視したり予期しない動作をする可能性があります。標準サーバーの場合は`10`以下にしてください。
