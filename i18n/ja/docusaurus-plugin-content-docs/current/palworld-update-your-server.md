## Introduction

Palworldのゲームサーバーは、最新のPalworldゲームバージョンおよびクライアントアップデートに対応するためにアップデートが必要です。このガイドでは、ZAP-HostingでPalworldゲームサーバーをアップデートする方法、関連設定の確認場所、アップデートが正しく適用されない場合の対処法を説明します。

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

## Preparation

開始する前に、ZAP-HostingのウェブインターフェースでPalworldゲームサーバーにアクセスでき、必要に応じてサーバーの再起動や再インストールができる権限があることを確認してください。

:::info サーバーアクセスの要件
ZAP-Hostingパネルの**Configs**、**Console**、および電源操作を含むゲームサーバー管理へのアクセス権が必要です。
:::

:::note 設定ファイルについて
Palworldのアップデートでは、通常、新しいゲームバージョンをインストールするために編集が必要なゲームプレイ設定ファイルはありません。アップデート処理は通常、サーバーのインストール自体が担当します。手動でアップデート動作を管理している場合は、パネル内のサーバー設定を確認してください。
:::

## ZAP-HostingでのPalworldゲームサーバーアップデートの仕組み

ホスティングプラットフォーム上のPalworld専用サーバーは、サーバー起動時に新しいビルドのチェックを行い、アップデートを実施することが一般的です。現在の情報によると、ZAP-Hostingのサーバーは通常、サーバーの起動または再起動時にこのチェックを自動的に行います。

サービスが自動アップデート設定の場合、新しいPalworldリリース後はサーバーを再起動するだけでアップデートが適用されます。自動アップデートが無効になっている場合は、各パッチ適用後に手動でサーバーを再起動してアップデートチェックを実行する必要があります。

:::caution 自動アップデートの有無について
自動アップデートの設定項目や名称は、ZAP-Hostingのゲームサーバーインターフェースや製品構成によって異なる場合があります。サーバー設定にアップデート関連のトグルが見当たらなくても、常に存在しないとは限りません。製品バージョンや背景処理で自動的に管理されている可能性があります。
:::

## 関連するサーバー設定の確認

まず、ZAP-HostingのウェブインターフェースでPalworldゲームサーバーを開き、アップデートや起動動作に関する設定を確認してください。

### サーバー管理画面を開く

1. ZAP-Hostingのウェブインターフェースにログインします。
2. **Palworld**ゲームサーバーを開きます。
3. **Configs**、**Console**、およびサーバーの電源操作などの利用可能なセクションを確認します。

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

### 設定ファイルの編集が必要か確認する

Palworldのアップデート処理自体において、標準的なサーバー運用でゲームバージョンを手動で変更するための設定ファイルエントリは確認されていません。**Configs**内のPalworldゲームプレイ設定ファイルは、主にゲームプレイルールなどのサーバー設定用です。新しいサーバービルドのダウンロードには使用されません。

一般的に使用されるPalworld設定ファイルは以下の通りです：

| ファイル | 主な用途 | 場所 |
| --- | --- | --- |
| `PalWorldSettings.ini` | ゲームプレイおよびサーバー動作設定 | ゲームサーバー管理の**Configs**内 |

:::note 手動バージョン指定なし
標準的なZAP-Hosting環境で、特定のPalworldサーバーバージョンを強制的に更新するための`PalWorldSettings.ini`のキーは確認されていません。サーバーソフトウェアのアップデートのみが目的の場合、`PalWorldSettings.ini`の編集は通常不要です。
:::

## サーバーのアップデート

サーバーアクセスを確認し、設定をチェックしたら、アップデート処理を開始できます。

### アップデートチェックをトリガーするためにサーバーを再起動する

主な方法はサーバーの再起動です。多くのホスティングされたPalworldサーバーは、起動時に利用可能なゲームアップデートをチェックします。

1. ZAP-HostingのウェブインターフェースからPalworldサーバーを停止または再起動します。
2. サーバーが完全にシャットダウンするまで待ちます。
3. サーバーを再起動します。
4. 起動およびアップデート処理が完了するまで数分待ちます。

サービスに自動アップデートが有効な場合、この再起動で最新のPalworldアップデートがダウンロード・適用されます。

### 自動アップデートが無効の場合

サービスが自動アップデートを行わない設定の場合は、Palworldの各パッチやバージョンアップリリース後に手動でサーバーを再起動する必要があります。

同じ手順を使います：

1. サーバーを停止します。
2. サーバーを再起動します。
3. 起動完了まで待ちます。

:::tip Palworldリリース後のベストプラクティス
新しいPalworldリリースやパッチ配信後は、プレイヤーの接続問題を避けるために、利用者が少ない時間帯にサーバーを再起動してください。クライアントとサーバーのバージョン不一致による問題を防げます。
:::

## アップデートが適用されたか確認する

サーバーが再起動したら、新しいバージョンが有効になっているか確認しましょう。

### コンソール出力を確認する

ゲームサーバー管理の**Console**を開き、起動ログを確認します。サーバーが正常に起動し、アップデートやファイル検証エラーが発生していないかを探します。

ログの具体的な内容はサーバービルドによって異なるため、サーバーが正常に起動し、最新のPalworldゲームバージョンのクライアントからの接続を受け入れているかに注目してください。

### `info`コマンドを使う

サーバーコンソールが対応している場合、以下のコマンドを実行します：

```text
info
```

このコマンドは起動後のサーバー情報確認に使えます。

| コマンド | 用途 |
| --- | --- |
| `info` | アップデート後のサーバー情報を表示して確認 |

:::note コマンド対応状況
コンソールコマンドの対応はPalworld専用サーバーの実装やホストのコンソールアクセス方法によって異なります。`info`が有用な出力を返さない場合は、起動ログや最新クライアントからの接続テストで確認してください。
:::

## アップデート失敗時のトラブルシューティング

再起動してもサーバーがアップデートされない場合は、ZAP-Hostingパネルの復旧オプションを利用してください。

### サーバーファイルの再インストールまたは検証

再起動後も古いバージョンのままの場合：

1. サーバーを完全に停止します。
2. ZAP-Hostingのゲームサーバー管理で再インストールまたは復旧オプションを開きます。
3. 利用可能なら**整合性の検証**などのファイルチェック機能を使います。
4. 処理完了後にサーバーを再起動します。

この処理はPalworldサーバーファイルの再検証や再ダウンロードを行い、不完全または失敗したアップデートを解決できます。

:::caution セーブデータの注意点
再インストール関連機能を使う前に、選択したオプションがゲームファイルのみを対象とするのか、ワールドデータにも影響するのかを理解してください。パネルに明確な説明がない場合は、必ずバックアップを作成するか、サポートに問い合わせてから実行してください。
:::

### クライアントとサーバーのバージョン整合性を確認する

サーバーは正しくアップデートされていても、プレイヤーのローカルゲームクライアントが異なるバージョンの場合、接続できないことがあります。

以下を確認してください：

| 確認項目 | 理由 |
| --- | --- |
| パッチ適用後にサーバーを再起動したか | 起動時にアップデートチェックが行われるため |
| 最新のクライアントアップデートをインストール済みか | プレイヤーは同じゲームバージョンが必要 |
| コンソールに起動エラーがないか | エラーがあるとアップデートが完了しない可能性 |
| ファイル検証を完了したか | ファイル破損がアップデートを妨げることがある |

## Configsで編集が必要な内容

このガイドは手動アップデートのプロセスを扱い、**Configs**に言及しているため、範囲を明確にします：

- Palworldの**Configs**内の設定ファイルはサーバー設定用です。
- `PalWorldSettings.ini`にサーバーソフトウェアのアップデートを手動でダウンロード・適用するための検証済みエントリはありません。
- 通常のバージョンアップデートでは、設定ファイルの値を変更する必要はありません。
- 必要な操作は通常、**サーバーの再起動**であり、アップデート失敗時のみ**ファイル検証や再インストール**を行います。

将来的にZAP-Hostingがパネルに専用のアップデートトグルや起動パラメータを追加した場合は、設定ファイルに未検証のエントリを追加せず、パネルに表示される正確な名称を使用してください。

:::danger 未検証の設定キーを追加しないでください
ZAP-HostingのPalworldサービスで明示的にドキュメント化されていない限り、`PalWorldSettings.ini`や**Configs**内の他ファイルにランダムなアップデートコマンドやSteamCMDパラメータ、未公開のキーを貼り付けないでください。サーバーのアップデートが確実に行われず、設定トラブルの原因になります。
:::

## アップデート後

アップデートが正常に適用されたら：

1. サーバーが正常に稼働していることを確認します。
2. コンソールにエラーがないか確認します。
3. 最新のPalworldクライアントでサーバーに接続テストを行います。
4. コンソールで`info`コマンドが使える場合は実行します。

これで最新バージョンのアップデートが適用されたサーバーがプレイヤーを迎える準備が整いました。
