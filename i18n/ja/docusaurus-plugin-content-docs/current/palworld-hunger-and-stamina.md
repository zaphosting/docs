## はじめに

Palworldでは、プレイヤーとパルの空腹とスタミナの減少速度をコントロールできます。このガイドでは、ZAP-Hostingのゲームサーバー管理画面で正しいサーバー設定ファイルを編集し、安全にカスタム減少率を適用する方法を説明します。

## 準備

開始する前に、ZAP-Hostingのゲームサーバー管理画面でPalworldゲームサーバーにアクセスできることを確認してください。

:::info 設定編集のアクセス要件
Palworldの設定ファイルを手動で編集するには、サーバー管理パネルの「Configs」セクションにアクセスできる必要があります。
:::

## Palworld設定ファイルを開く

空腹とスタミナの挙動を変更するには、`PalWorldSettings.ini`ファイルを編集します。

ZAP-Hostingのゲームサーバー管理画面で：

1. Palworldサーバーを開きます。
2. 「Configs」セクションに移動します。
3. `PalWorldSettings.ini`ファイルを開きます。



:::note ゲームプレイ倍率用のファイル
空腹とスタミナの設定は`PalWorldSettings.ini`に保存されています。これらの値は通常、専用サーバーで使用されるメインのオプション文字列の一部です。
:::

## 空腹とスタミナの値を変更する

`PalWorldSettings.ini`内で、サーバーのオプション値が含まれるゲームプレイ設定セクションを探します。以下の設定キーを追加または調整してください。

:::caution Palworldの重要なスペル
Palworldの設定エントリでは`Decreace`というスペルが使われています。これはサーバー設定フォーマット上の意図的な表記なので、必ず以下のキーを正確に使用してください。
:::

### 利用可能な設定キー

| 設定キー | 説明 | デフォルト値 |
| --- | --- | --- |
| `PlayerStomachDecreaceRate` | プレイヤーの空腹減少速度を制御 | `1.0` |
| `PlayerStaminaDecreaceRate` | プレイヤーのスタミナ減少速度を制御 | `1.0` |
| `PalStomachDecreaceRate` | パルの空腹減少速度を制御 | `1.0` |
| `PalStaminaDecreaceRate` | パルのスタミナ減少速度を制御 | `1.0` |

### 値の動作について

値を小さくすると、空腹やスタミナの消費速度が遅くなります。

| 値 | 効果 |
| --- | --- |
| `1.0` | デフォルトの減少速度 |
| `0.5` | 半分の減少速度 |
| `0.0` | 減少を完全に無効化 |

:::tip バランスの良い設定の選び方
メカニクスを完全に無効化せず、よりゆったりしたサバイバル体験にしたい場合は、空腹とスタミナ両方に`0.5`を設定するのが実用的な出発点です。
:::

## 設定例

ゲームプレイ体験に応じて、`PalWorldSettings.ini`に以下の値を追加または編集してください：

```ini
PlayerStomachDecreaceRate=0.5
PlayerStaminaDecreaceRate=0.5
PalStomachDecreaceRate=0.5
PalStaminaDecreaceRate=0.5
```

この例では、プレイヤーとパルの空腹とスタミナの減少速度をデフォルトの半分に減らします。

空腹とスタミナを完全に無効化したい場合は、以下を使用してください：

```ini
PlayerStomachDecreaceRate=0.0
PlayerStaminaDecreaceRate=0.0
PalStomachDecreaceRate=0.0
PalStaminaDecreaceRate=0.0
```

:::note 設定の配置について
`PalWorldSettings.ini`の構造によっては、これらの値を既存のオプションリスト内に含める必要がある場合があります。ファイルに長い`OptionSettings`エントリが既にある場合は、既存のフォーマットを保持しつつ、該当するキーのみを変更または挿入してください。
:::

## 保存してサーバーを再起動する

ファイルを編集したら：

1. `PalWorldSettings.ini`の変更を保存します。
2. ZAP-Hostingのゲームサーバー管理画面からPalworldサーバーを再起動します。

新しい空腹とスタミナの設定が反映されるには再起動が必要です。

:::caution 再起動が必須
サーバーを再起動しないと、更新した設定値はゲームサーバーに読み込まれません。
:::

## ゲーム内で変更を確認する

サーバーがオンラインに戻ったら、サーバーに参加して新しい設定をテストしてください。

### チェックすべきポイント

- プレイヤーの空腹がよりゆっくり減るか
- プレイヤーのスタミナが移動やアクション中に長持ちするか
- パルの空腹が期待通りの速度で減るか
- パルのスタミナ消費が設定値に合っているか

設定が反映されていない場合は、再度`PalWorldSettings.ini`を開いて以下を確認してください：

- 設定キーのスペルが正確であること
- 値が`1.0`、`0.5`、`0.0`などの有効な小数であること
- 設定が正しく保存されていること
- 編集後にサーバーが完全に再起動されていること
