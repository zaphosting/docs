## Introduction

Palworldのホストキャラクター転送では、ソロまたは協力プレイのホストキャラクターを専用サーバーのセーブに移行できます。このガイドでは、必要なセーブファイルの準備、対応ツールの使用、更新したキャラクターデータのサーバーへのアップロード方法を説明します。

:::danger 実験的なキャラクター転送の警告
この手順は実験的であり、セーブデータを手動で変更します。Palworldのアップデートによりセーブ構造が変わることがあり、ツールや移行手順が正しく動作しなくなる可能性があります。
:::

## Preparation

開始する前に、Palworldゲームサーバーへのアクセス権と、必要なセーブ移行ツールを実行できるローカルのWindows環境があることを確認してください。

### Requirements

以下が必要です：

| 必要条件 | 用途 |
| --- | --- |
| ZAP-HostingのPalworldサーバーへのアクセス | 必要なセーブファイルのダウンロードとアップロードのため |
| ローカルのバックアップ保存場所 | 元のセーブデータの安全なコピーを保管するため |
| [Palworld Save Tools](https://github.com/deafdudecomputers/PalWorldSaveTools) | ホストキャラクターの移行を行うため |
| 新規作成した専用サーバーのキャラクター | ホストキャラクターデータを移行する対象の専用サーバーキャラクター |

:::caution まずバックアップを作成してください
セーブファイルを変更する前に、現在のサーバーセーブの完全なバックアップをダウンロードして保存してください。転送が失敗したりキャラクターデータが破損した場合、元のファイルからサーバーを復元する必要があります。
:::

### 設定ファイルに関する重要な注意点

この転送は、`Configs`フォルダ内のPalworld設定ファイルを編集して完了するものではありません。現在のツールのドキュメントやコミュニティの情報によると、ホストキャラクター転送はセーブデータファイルの置き換えによって行われます。

対象ファイルはサーバーのセーブディレクトリ内にあり、通常のゲームプレイ設定ファイル（例：`PalWorldSettings.ini`）ではありません。

## 使用されるファイルの理解

転送を始める前に、関係するファイルを特定しましょう。

### 転送に必要なセーブファイル

ホストキャラクター移行で使用するセーブデータは以下の通りです：

| ファイルまたはフォルダ | 場所 | 用途 |
| --- | --- | --- |
| `Level.sav` | `Pal/Saved/SaveGames/0/[your_savefolder_id]/Level.sav` | 移行ツールが使用するワールドレベルのセーブデータ |
| `Players/` | `Pal/Saved/SaveGames/0/[your_savefolder_id]/Players/` | プレイヤーのセーブファイル。新規専用サーバーキャラクターも含む |
| `00000001.sav` | アップロードしたソロまたは協力プレイの`Players/`内 | 通常、協力プレイの元ホストキャラクターを表すファイル |

`[your_savefolder_id]`はPalworldのワールドセーブで使われる長いフォルダ名で、セーブごとに異なります。

### ZAPインターフェースでのファイルの場所

ゲームサーバー管理のファイルマネージャーから必要なセーブファイルにアクセスできます。

以下のパスに移動してください：

```text
Pal/Saved/SaveGames/0/[your_savefolder_id]/
```

このフォルダ内には少なくとも以下が存在します：

- `Level.sav`
- `LevelMeta.sav`
- `Players/`

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

## 専用サーバーキャラクターの準備

ホストキャラクターを移行する前に、専用サーバーにあなたのアカウント用の新規プレイヤーセーブが既に存在している必要があります。

### サーバーで新しいキャラクターを作成する

Palworld専用サーバーに通常通り参加し、新しいキャラクターを作成してください。その後、キャラクターが少なくともレベル`2`に達するまでプレイします。

この手順は、移行ツールが移行先として既存の専用サーバーキャラクターファイルを必要とするためです。

### セーブを強制または待機する

新しいキャラクターを作成した後、サーバーが新しいプレイヤーデータをディスクに書き込んだことを確認する必要があります。

以下のいずれかを行ってください：

- 通常約`4`分の自動セーブ間隔を待つ
- サーバーコンソールで`save`コマンドを実行する

| コマンド | 実行場所 | 用途 |
| --- | --- | --- |
| `save` | サーバーコンソール | 現在のワールドとプレイヤーデータをディスクに強制書き込み |

:::info セーブコマンドの使用条件
`save`コマンドを使う場合は、サーバー停止前に実行してください。これにより、`Players/`フォルダ内に新しい専用サーバーキャラクターファイルが確実に存在するようになります。
:::

### サーバーを停止する

セーブが完了したら、サーバー管理画面からPalworldサーバーを停止してください。

サーバーが稼働中のまま続行しないでください。アクティブなセーブ書き込みが、これから置き換えるファイルを上書きまたは競合させる可能性があります。

## 必要なセーブデータのダウンロード

新しいキャラクターが専用サーバーに存在するので、移行に必要なファイルをダウンロードできます。

### セーブディレクトリを開く

ZAP-Hostingのファイルマネージャーで以下に移動します：

```text
Pal/Saved/SaveGames/0/[your_savefolder_id]/
```

### ファイルをダウンロードする

以下の項目をローカルPCにダウンロードしてください：

| 項目 | 必須 |
| --- | --- |
| `Level.sav` | はい |
| `Players/`フォルダ | はい |

両方を同じローカル作業フォルダに保存し、移行ツールが正しく処理できるようにします。

:::tip ファイルは一緒に保管
`Level.sav`と`Players/`フォルダは同じローカルフォルダ内に並べて置いてください。これはPalworld Save Toolsの想定ワークフローに合致します。
:::

## ホストキャラクターの移行

セーブデータをダウンロードしたら、実際のホストキャラクター転送を行います。

### Palworld Save Toolsを起動する

[Palworld Save Tools](https://github.com/deafdudecomputers/PalWorldSaveTools)をダウンロードして解凍し、`PalworldSaveTools.exe`を開きます。

アプリ内で以下を選択してください：

```text
Fix Host Save
```

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

### 正しいファイルを選択する

移行ツール内で：

1. ダウンロードした`Level.sav`を選択
2. 左側の選択欄で`00000001.sav`を選択
3. 右側の選択欄で専用サーバーで作成した新しいキャラクターを選択
4. `Migrate`を選んで移行を開始

| ツールの項目 | 選択する値 |
| --- | --- |
| `Path to Level.sav` | ダウンロードした`Level.sav` |
| 左側キャラクター欄 | `00000001.sav` |
| 右側キャラクター欄 | 新規作成した専用サーバーキャラクター |
| アクション | `Migrate` |

### 移行の内容

移行処理は、ソロまたは協力プレイの元ホストキャラクターデータを、先に作成した専用サーバーキャラクターのエントリに割り当て直します。

そのため、最初にサーバーに参加して新しいプレイヤーセーブを生成しておく必要があります。

:::caution 移行先キャラクターの確認
右側で正しい新規サーバーキャラクターを選択しているか必ず確認してください。誤った対象を選ぶと他のプレイヤーのセーブデータを上書きする恐れがあります。
:::

## 更新したセーブファイルのアップロード

移行が正常に完了したら、修正済みファイルをサーバーにアップロードします。

### 既存のセーブデータを置き換える

ZAP-Hostingのファイルマネージャーで同じサーバーディレクトリに戻ります：

```text
Pal/Saved/SaveGames/0/[your_savefolder_id]/
```

以下をアップロードして置き換えてください：

- 更新済みの`Level.sav`
- 更新済みの`Players/`フォルダ

ファイルマネージャーが既存ファイルの上書きを求めたら、置き換えを承認してください。

### 設定ファイルの変更について

このホストキャラクター転送では、現時点で`PalWorldSettings.ini`などのPalworld設定ファイルを編集する必要は確認されていません。

| 項目 | ホスト転送に必要か |
| --- | --- |
| `PalWorldSettings.ini`の編集 | いいえ |
| `Configs`内ファイルの編集 | 確認された必要なし |
| `Level.sav`の置き換え | はい |
| `Players/`の置き換え | はい |

:::note 追加の設定変更は不要
現在のツールドキュメントと移行手順によると、転送自体に追加の設定エントリや手動の`.ini`変更は不要です。
:::

## サーバーを起動してキャラクターをテスト

更新ファイルをアップロードしたら、Palworldサーバーを再起動してください。

### サーバーに再接続する

新規専用サーバーキャラクターを作成したのと同じアカウントでサーバーに接続します。移行が成功していれば、一時的な新キャラクターではなく転送されたホストキャラクターでログインできます。

### 重要なキャラクターデータを確認する

ログイン後、以下のデータが正しく表示されているか確認してください：

- キャラクターレベル
- インベントリ
- パル（仲間）
- 拠点の所有権
- 進行状況データ

不足や誤りがあれば、すぐにサーバーを停止し、バックアップから復元して再試行してください。

:::danger データが正しくない場合はバックアップを復元
移行後にキャラクター、インベントリ、ワールド所有権データが破損している場合は、プレイを続けないでください。元の`Level.sav`と`Players/`のバックアップを先に復元し、不要な変更の保存を防ぎましょう。
:::
