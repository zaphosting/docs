## はじめに

Palworldでは、装備耐久率がツール、武器、鎧の耐久度が使用中にどれくらい早く減るかを制御します。このガイドでは、ZAP-HostingのPalworldサーバー設定で`EquipmentDurabilityDamageRate`を手動で変更し、正しく適用する方法を学びます。



## 準備

始める前に、ZAP-HostingのウェブインターフェースでPalworldゲームサーバーの管理にアクセスできることを確認してください。また、**Configs**でサーバー設定ファイルを編集する権限が必要です。

:::info 手動設定が必要です
この設定はPalworldの設定ファイル内で手動で変更する必要があります。この特定の変更に対してゲーム内で実行する別のコマンドはありません。
:::

## 耐久設定の理解

Palworldは多くのゲームプレイ設定を`PalWorldSettings.ini`設定ファイルに保存しています。装備耐久に関係する設定は以下です：

- `EquipmentDurabilityDamageRate`

この値は耐久度減少の倍率として機能します：

| 設定キー | 説明 | デフォルト値 |
| --- | --- | --- |
| `EquipmentDurabilityDamageRate` | 装備の耐久度がどれくらい早く減るかを制御 | `1.000000` |

値が低いほど耐久度の減少が少なくなり、装備の寿命が長くなります。`0.000000`にすると装備の耐久度減少が完全に無効になります。

:::note この設定の影響範囲
この設定はツール、武器、鎧などの装備の耐久度減少率を変更します。アイテムのダメージ量、修理速度、品質には影響しません。
:::

## Palworld設定ファイルを開く

設定を変更するには、ZAP-Hostingのゲームサーバー管理からPalworldのメイン設定ファイルを編集します。

### ZAP-Hostingインターフェースでファイルを探す

1. ZAP-Hostingのウェブサイトにログインします。
2. **Palworld**ゲームサーバー管理を開きます。
3. **Configs**に移動します。
4. `PalWorldSettings.ini`ファイルを開きます。

このファイルには耐久度、スタミナ、ダメージ、その他のワールド設定などのゲームプレイ値が保存されています。

## 装備耐久率を編集する

`PalWorldSettings.ini`を開いたら、`OptionSettings`行を探します。Palworldは通常、このセクション内にカンマ区切りのエントリとしてゲームプレイ設定を保存します。

### 設定エントリを追加または変更する

`OptionSettings`内に以下のエントリが存在することを確認してください：

```ini
EquipmentDurabilityDamageRate=1.000000
```

キーがすでにある場合は現在の値を希望の値に置き換えます。存在しない場合は、既存の`OptionSettings=(...)`ブロック内に追加してください。

### 例として使える値

目的に応じて以下の値を使用できます：

| 値 | 効果 |
| --- | --- |
| `1.000000` | デフォルトの耐久度減少 |
| `0.500000` | 装備の寿命が約2倍に |
| `0.250000` | 装備の寿命が約4倍に |
| `0.000000` | 装備が壊れなくなる |

### 設定例スニペット

サーバー構成によって`OptionSettings`の内容は異なる場合がありますが、耐久設定は同じカンマ区切りリスト内に現れます。例：

```ini
[/Script/Pal.PalGameWorldSettings]
OptionSettings=(Difficulty=None,DayTimeSpeedRate=1.000000,NightTimeSpeedRate=1.000000,ExpRate=1.000000,PalCaptureRate=1.000000,PalSpawnNumRate=1.000000,EquipmentDurabilityDamageRate=0.500000)
```

:::caution 既存のフォーマットを保持してください
ファイル編集時に`OptionSettings`行の他の値を削除しないでください。Palworldはこれらの設定が正しいカンマ区切り形式で残っていることを期待しています。
:::

## 変更を保存して適用する

設定ファイルを編集したら、ZAP-Hostingインターフェースで変更を保存します。

### サーバーを再起動する

新しい耐久設定を適用するには、ゲームサーバー管理からPalworldサーバーを再起動してください。

再起動しないと、通常サーバーは更新された設定を読み込みません。

| 操作 | 必要か |
| --- | --- |
| `PalWorldSettings.ini`の保存 | はい |
| サーバーの再起動 | はい |
| ゲーム内コマンドの実行 | いいえ |
| サーバーの再インストール | いいえ |

:::tip 小さな調整で変更をテストしよう
どの耐久値が自分のプレイスタイルに合うかわからない場合は、まず`0.500000`から始めてみてください。耐久度が明確に改善されますが、完全に無効化はされません。
:::

## トラブルシューティング

再起動後に新しい装備耐久の挙動が反映されない場合は、以下を確認してください。

### 設定キーを確認する

キーは正確に以下のように書かれていることを確認してください：

```ini
EquipmentDurabilityDamageRate
```

Palworldの設定キーは管理上、実際には大文字小文字を区別するため、表示通り正確にコピーしてください。

### `OptionSettings`内の配置を確認する

値は`PalWorldSettings.ini`の`OptionSettings=(...)`セクション内にある必要があります。このブロック外に置くとサーバーが無視する可能性があります。

### ファイルが保存されているか確認する

**Configs**で編集後、`PalWorldSettings.ini`を再度開いて変更が残っているか確認してください。残っていなければ保存に失敗しています。

### 必要なら再度再起動する

変更中にプレイヤーがオンラインだったり、サーバーが正常に再起動しなかった場合は、サーバー管理パネルからもう一度完全に再起動してください。
