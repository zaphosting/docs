## はじめに

Palworldはゲームサーバー上にワールド、プレイヤーの進行状況、サーバー設定を保存します。このガイドでは、ZAP-HostingでPalworldサーバーを完全にリセットし、新しいデフォルトインストールから再スタートする方法を説明します。

:::danger 完全データ削除の警告
完全リセットは現在のセーブデータ、設定変更、その他サーバーファイルを永久に削除します。最終手段としてのみ使用してください。
:::

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

## 準備

開始前に、ZAP-HostingのウェブインターフェースでPalworldゲームサーバーにアクセスできること、現在のワールドデータが不要であることを確認してください。

:::info 重要データは必ずバックアップを
現在のワールドや設定のコピーを残したい場合は、リセット前にバックアップを作成してください。リセット後は削除されたデータを通常復元できません。
:::

## Palworldサーバーリセットの内容を理解する

完全なPalworldリセットは設定ファイルの単一設定変更とは異なり、サーバー全体を再インストールし、現在のサーバーデータを削除します。

リセットで通常削除されるものは以下の通りです：

| データ種別 | リセット時の削除有無 |
| --- | --- |
| ワールドセーブデータ | 削除される |
| プレイヤーの進行状況 | 削除される |
| サーバー設定変更 | 削除される |
| インストール済みのMODやカスタムファイル | 削除される |
| デフォルトゲームファイル | 自動的に再インストールされる |

リセット後は新規インストールとデフォルト設定でサーバーが起動します。

## まず設定ファイルの場所を確認する

通常のPalworld設定変更はゲームサーバー管理の`Configs`から該当ファイルにアクセスできます。主なPalworld設定は以下のファイルに保存されていることが多いです：

| ファイル名 | 用途 |
| --- | --- |
| `PalWorldSettings.ini` | Palworldサーバーのメイン設定ファイル |

ZAP-Hostingのインターフェースでは、Palworldサーバー管理の`Configs`から通常アクセス可能です。

:::note リセットに手動設定編集は不要
完全リセットは`PalWorldSettings.ini`の手動編集を必要としません。このファイルは通常の設定変更用で、完全リセットはサーバーの再インストールやフォーマットで全ファイルをデフォルト値で再作成します。
:::

ゲームプレイ設定のみ変更したい場合は、完全リセットではなく`Configs`内の設定ファイルを編集してください。

## サーバーを停止する

リセット開始前にPalworldサーバーを完全に停止する必要があります。

1. ZAP-Hostingのウェブインターフェースにログインします。
2. Palworldゲームサーバーを開きます。
3. サーバー管理画面の操作でサーバーを停止します。
4. サーバーステータスがオフラインを示すまで待ちます。

:::caution サーバー稼働中のリセットは避ける
サーバーが稼働中にリセットを開始すると、ファイルが正しく削除されずセーブデータが不整合になる恐れがあります。
:::

## サーバーの再インストールとリセット

Palworldの完全リセットはZAPインターフェースの再インストールやフォーマット・リセットオプションで行います。

### 再インストール機能を開く

Palworldサーバー管理のサーバー管理エリアで再インストールまたはリセット機能を探します。

パネルのバージョンによって表記が異なる場合がありますが、ZAP-Hostingでは通常サーバー管理画面に再インストールやフォーマット操作が用意されています。

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

### 完全リセットを開始する

サーバーデータを完全にフォーマットまたはリセットする再インストールオプションを選択します。

操作確認が求められたら必ず承認してください。

:::danger この操作は全サーバーデータを消去します
完全な再インストールやフォーマットリセットはセーブデータ、設定、カスタムファイルを削除します。すべてリセットしてよいと確信がある場合のみ続行してください。
:::

### インストール完了まで待つ

リセットを承認したら、再インストール処理が完了するまで待ちます。パネルの状態やサーバーサイズによって数分かかる場合があります。

再インストール中は処理を中断しないでください。

## 新しいPalworldサーバーを起動する

再インストール完了後、サーバー管理画面からPalworldサーバーを再起動します。

起動後は以下の状態になります：

- 新しいワールドセーブが作成される
- デフォルトのサーバー設定が適用される
- 以前のプレイヤーやワールドの進行状況は存在しない

必要に応じて`Configs`に戻り、`PalWorldSettings.ini`で設定を再調整できます。

## リセット結果を確認する

サーバー起動後に接続し、リセットが成功したか確認してください。

以下をチェックします：

| チェック項目 | 期待される結果 |
| --- | --- |
| ワールドの状態 | 新規のワールド |
| プレイヤーデータ | 以前の進行状況なし |
| サーバー設定 | 変更していなければデフォルト値 |
| カスタムファイルやMOD | 手動で再インストールしない限り削除済み |

古いワールドが残っている場合はサーバーを停止し、ZAPパネルで再インストール処理が正常に完了したか確認してください。完全フォーマットリセットが実行されていなければ、慎重に再度実行する必要があります。

## リセット後のサーバー設定再構成

リセット成功後はPalworldサーバーがデフォルト設定値を使用します。再度カスタマイズしたい場合はゲームサーバー管理の`Configs`から`PalWorldSettings.ini`を編集してください。

リセット後に行う典型的な作業例：

- サーバー名の変更
- パスワード設定
- 難易度やゲームプレイ値の調整
- カスタム設定の再適用
- 必要に応じて対応MODや追加ファイルの再インストール

:::tip 設定の再適用は慎重に
以前の設定が問題を起こしていた場合、すべての古い設定をすぐに戻すのは避けてください。本当に必要な設定だけを再適用し、問題の原因を特定しやすくしましょう。
:::

## 設定ファイルリファレンス

以下の表は関連ファイルとリセット動作の概要です：

| 項目 | 詳細 |
| --- | --- |
| メイン設定ファイル | `PalWorldSettings.ini` |
| ZAPでの設定編集場所 | ゲームサーバー管理の`Configs` |
| 完全リセットに手動設定変更は必要か | いいえ |
| 完全リセットに必要な操作 | サーバーの再インストールまたはフォーマット/リセット |
| リセット後の再起動 | はい、再インストール後にサーバーを起動 |
| 追加コマンドの必要性 | 確認されていません |

:::note インターフェース表記は異なる場合あり
再インストールやフォーマットオプションの表記はZAPウェブインターフェースのバージョンによって異なることがあります。リセット機能が見つからない場合は、代替のファイル削除方法を試す前にサポートに連絡してください。
:::
