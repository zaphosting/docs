## Introduction

*グローバルパルボックス*は、Palworldでプレイヤーがサーバー間でパルを転送できるクラウドベースのパル保管システムです。このガイドでは、ZAP-HostingのPalworldゲームサーバーでグローバルパルボックスのインポートとエクスポートを手動で設定ファイルを編集して有効にする方法を説明します。

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

## Preparation

開始する前に、以下を確認してください：

- ZAP-HostingのウェブインターフェースでPalworldゲームサーバーにアクセスできること
- サーバーが停止中であるか、設定変更後に再起動できること
- ゲームサーバー管理の`Configs`セクションにアクセスできること

:::info 設定ファイルへのアクセスについて
ZAP-HostingのPalworldサーバーでは、関連設定はゲームサーバー管理の`Configs`から編集可能です。設定エディターが利用できる場合は外部ファイルアクセスは不要です。
:::

## Palworld設定ファイルを開く

グローバルパルボックス機能を有効にするには、`PalWorldSettings.ini`ファイルを編集します。

### ZAPインターフェースで設定ファイルを探す

1. [ZAP-Hostingのウェブサイト](https://zap-hosting.com)にログインします。
2. Palworldゲームサーバー管理を開きます。
3. `Configs`セクションに移動します。
4. `PalWorldSettings.ini`という名前のファイルを開きます。

このファイルには、グローバルパルボックスのオプションを含むPalworldの主要なサーバー設定が含まれています。

:::note 手動設定が必要です
グローバルパルボックスの設定はサーバー設定ファイルを手動で編集して行います。インターフェースに専用の切り替えがない場合は、`PalWorldSettings.ini`を直接編集するのが正しい方法です。
:::

## グローバルパルボックスのインポートとエクスポートを有効化する

`PalWorldSettings.ini`を開いたら、サーバーオプションリストを見つけてグローバルパルボックスの設定を調整します。

### 必須の設定キー

以下の設定がグローバルパルボックスの動作を制御します：

| 設定キー | 値 | 機能 |
| --- | --- | --- |
| `bAllowGlobalPalboxImport` | `True` または `False` | プレイヤーがグローバルパルボックスからパルをインポートできるか |
| `bAllowGlobalPalboxExport` | `True` または `False` | プレイヤーがグローバルパルボックスへパルをエクスポートできるか |

第三者の参考資料によると、`bAllowGlobalPalboxImport`はデフォルトで`False`（無効）、`bAllowGlobalPalboxExport`はデフォルトで`True`（有効）です。既にこれらの値がファイルにある場合は必要に応じて調整してください。

### 値の設定方法

サーバー間でのグローバルパルボックス転送を完全に有効にするには、両方の値を`True`に設定します。

```ini
bAllowGlobalPalboxImport=True
bAllowGlobalPalboxExport=True
```

これらのオプションが既にファイルにある場合は既存の値を置き換え、存在しない場合は`PalWorldSettings.ini`のサーバー設定セクションに追加してください。

:::caution 既存の構文を保持してください
Palworldの設定ファイルはフォーマットに敏感です。必要な値だけを変更し、カンマや括弧など既存のエントリーを削除しないように注意してください。これらのオプションが他の設定行の一部である場合は特に注意が必要です。
:::

## 変更を保存する

編集後は以下を行います：

1. `PalWorldSettings.ini`エディターで変更を保存します。
2. 両方のグローバルパルボックスの値が正しく存在し設定されていることを確認します。

サーバーパネルに保存ボタンしかない場合は、まずそれを使い、その後サーバーを再起動してください。

## サーバーを再起動する

グローバルパルボックス設定を変更したら、新しい設定を反映させるためにPalworldサーバーを再起動します。

### 新しい設定の適用

ファイル保存後、ゲームサーバー管理からサーバーを再起動してください。

| 操作 | 必要か |
| --- | --- |
| `PalWorldSettings.ini`の保存 | はい |
| サーバーの再起動 | はい |
| 追加のコンソールコマンド実行 | いいえ |

設定ファイル編集後に追加コマンドは不要です。通常のサーバー再起動で新しいグローバルパルボックス設定が適用されます。

:::tip ゲーム内で機能を確認する
再起動後、サーバーに参加してプレイヤーがグローバルパルボックスを使ってパルのインポート・エクスポートができるかテストしてください。これが設定が正しく適用されたかを確認する最も簡単な方法です。
:::

## トラブルシューティング

再起動後にグローバルパルボックスが機能しない場合は、以下を確認してください。

### 値が正しく保存されているか確認

再度`PalWorldSettings.ini`を開き、以下の値が存在するか確認します：

```ini
bAllowGlobalPalboxImport=True
bAllowGlobalPalboxExport=True
```

値が元に戻っている場合は、ファイルが正しく保存されていない可能性があります。

### フォーマットの問題をチェック

既存の設定ブロックに値を挿入した場合、周囲の構文が正しいか確認してください。`PalWorldSettings.ini`のフォーマットが不正だと、Palworldが設定を無視したり正しく読み込めなかったりします。

### 再度サーバーを再起動する

サーバー稼働中にファイルを保存した場合は、設定を確実に反映させるためにもう一度完全に再起動してください。

:::danger 機能の利用可否はゲームバージョンに依存します
グローバルパルボックスはPalworldのゲーム機能です。設定が正しくても動作しない場合は、Palworldサーバーのバージョンやゲーム側の一時的な制限による可能性があります。その場合はサーバーが最新状態か確認してください。
:::
