## Introduction

Palworld เก็บข้อมูลโลกเซิร์ฟเวอร์เฉพาะไว้ในโฟลเดอร์เซฟเฉพาะ และเชื่อมโยงโฟลเดอร์นั้นผ่านการตั้งค่าเซิร์ฟเวอร์ ในคู่มือนี้ คุณจะได้เรียนรู้วิธีอัปโหลดเซฟที่มีอยู่แล้วไปยังเซิร์ฟเวอร์ Palworld ของคุณที่ ZAP-Hosting และอัปเดตการตั้งค่าที่จำเป็นเพื่อให้เซิร์ฟเวอร์โหลดโลกที่ถูกต้อง

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่าคุณมีโฟลเดอร์เซฟ Palworld ที่มีอยู่แล้วบนอุปกรณ์ของคุณ

:::danger แหล่งเซฟที่ไม่รองรับ
เซฟจากเครื่อง Xbox และเซฟบนคลาวด์ PS5 ไม่สามารถย้ายโดยตรงไปยังเซิร์ฟเวอร์เฉพาะ Palworld ได้ คุณสามารถย้ายเซฟได้เฉพาะจากการติดตั้งบนพีซีหรือจากเซิร์ฟเวอร์เฉพาะที่มีอยู่แล้วเท่านั้น
:::

:::info สิทธิ์การเข้าถึงที่จำเป็น
คุณต้องมีสิทธิ์เข้าถึงแผงควบคุมเว็บของเซิร์ฟเวอร์เกม ZAP-Hosting รวมถึงตัวจัดการไฟล์และส่วน `Configs`
:::

หากคุณต้องการความช่วยเหลือในการเข้าถึงไฟล์เซิร์ฟเวอร์ของคุณครั้งแรก ให้ใช้คู่มือการจัดการไฟล์ที่เกี่ยวข้องในเอกสาร ZAP-Hosting สำหรับผลิตภัณฑ์ของคุณ

## Understand the Required Save Structure

ก่อนอัปโหลดใดๆ คุณควรตรวจสอบว่าเซฟของคุณมีโครงสร้างที่ถูกต้อง

บนเซิร์ฟเวอร์เฉพาะ Palworld โลกเซฟที่ใช้งานอยู่จะถูกเก็บไว้ที่:

```text
Pal/Saved/SaveGames/0/[your_save_folder_id]/
```

ชื่อโฟลเดอร์ `[your_save_folder_id]` มักจะเป็นสตริงยาวของตัวอักษรและตัวเลข เช่น:

```text
84B5E2264EC387DEDB43179D666031A1
```

โฟลเดอร์เซฟที่ถูกต้องโดยปกติจะมีไฟล์และโฟลเดอร์คล้ายกับต่อไปนี้:

| รายการ | จุดประสงค์ |
| --- | --- |
| `Level.sav` | ข้อมูลเซฟโลกหลัก |
| `LevelMeta.sav` | เมตาดาต้าโลก |
| `Players/` | ข้อมูลเซฟผู้เล่น |
| `WorldOption.sav` | ไฟล์ตัวเลือกโลกแบบเก่าที่อาจต้องลบออก |

:::caution ลบไฟล์ WorldOption.sav ที่เลิกใช้แล้ว
ถ้าโฟลเดอร์เซฟที่คุณอัปโหลดมีไฟล์ `WorldOption.sav` ให้ลบไฟล์นี้ก่อนเริ่มเซิร์ฟเวอร์ ไฟล์นี้เป็นที่ทราบกันว่าสร้างปัญหาบนเซิร์ฟเวอร์เฉพาะรุ่นปัจจุบันและไม่ควรใช้กับเซฟที่ย้ายมา เว้นแต่จะมีการเปลี่ยนแปลงอย่างเป็นทางการจาก Palworld รุ่นใหม่ที่ต้องการ
:::

## Find the Configuration File in the ZAP Interface

หลังจากอัปโหลดโฟลเดอร์เซฟแล้ว คุณต้องชี้เซิร์ฟเวอร์ไปยังโฟลเดอร์นั้นโดยแก้ไขการตั้งค่า Palworld

ในแผงควบคุมเซิร์ฟเวอร์เกม ZAP-Hosting ให้เปิดส่วน `Configs` และค้นหาไฟล์:

```text
GameUserSettings.ini
```

ขึ้นอยู่กับสภาพแวดล้อมเซิร์ฟเวอร์ปัจจุบัน ไฟล์นี้มักจะถูกเก็บไว้ในเส้นทางใดเส้นทางหนึ่งต่อไปนี้:

| เส้นทางที่เป็นไปได้ | หมายเหตุ |
| --- | --- |
| `Pal/Saved/Config/LinuxServer/GameUserSettings.ini` | เส้นทางทั่วไปบนเซิร์ฟเวอร์ Palworld ที่ใช้ Linux |
| `Pal/Saved/Config/WindowsServer/GameUserSettings.ini` | เส้นทางเก่าหรือทางเลือกบนเซิร์ฟเวอร์ที่ใช้ Windows |

:::note เส้นทาง LinuxServer กับ WindowsServer
เซิร์ฟเวอร์เฉพาะ Palworld มักจะติดตั้งโดยใช้เส้นทางคอนฟิก `LinuxServer` หากคุณไม่เห็น `WindowsServer` ให้ตรวจสอบที่ `LinuxServer` แทน ในแผงควบคุม ZAP วิธีที่ง่ายที่สุดคือเปิด `Configs` แล้วเลือกไฟล์ `GameUserSettings.ini` โดยตรง
:::

## Upload the Existing Save

กระบวนการอัปโหลดขึ้นอยู่กับแหล่งที่มาของเซฟของคุณ แต่ตำแหน่งเป้าหมายบนเซิร์ฟเวอร์ ZAP จะเหมือนกัน

### หยุดเซิร์ฟเวอร์ก่อน

ก่อนแทนที่โลกเริ่มต้น ให้หยุดเซิร์ฟเวอร์ Palworld ของคุณในแผงควบคุมเว็บ ZAP-Hosting

:::caution ป้องกันการเสียหายของเซฟ
อย่าอัปโหลดหรือแทนที่ไฟล์โลกขณะที่เซิร์ฟเวอร์กำลังทำงาน การหยุดเซิร์ฟเวอร์ก่อนช่วยป้องกันการเขียนข้อมูลไม่สมบูรณ์และเซฟเสียหาย
:::

### ลบโฟลเดอร์เซฟเริ่มต้น

เปิดตัวจัดการไฟล์และไปที่:

```text
Pal/Saved/SaveGames/0/
```

ในไดเรกทอรีนี้ คุณจะพบโฟลเดอร์เซฟที่สร้างขึ้นโดยอัตโนมัติ ลบโฟลเดอร์เริ่มต้นนี้ก่อนอัปโหลดเซฟของคุณเอง

### อัปโหลดโฟลเดอร์เซฟที่มีอยู่แล้วของคุณ

อัปโหลดโฟลเดอร์เซฟที่มีอยู่แล้วของคุณไปยัง:

```text
Pal/Saved/SaveGames/0/
```

หลังจากอัปโหลด โครงสร้างควรเป็นแบบนี้:

```text
Pal/
└── Saved/
    └── SaveGames/
        └── 0/
            └── [your_save_folder_id]/
                ├── Level.sav
                ├── LevelMeta.sav
                ├── Players/
                └── WorldOption.sav
```

ถ้ามีไฟล์ `WorldOption.sav` ให้ลบออกหลังจากอัปโหลดเสร็จ

:::tip คัดลอกชื่อโฟลเดอร์ให้ตรงเป๊ะ
คุณจะต้องใช้ชื่อโฟลเดอร์ที่อัปโหลดอย่างแม่นยำสำหรับขั้นตอนถัดไป คัดลอก `[your_save_folder_id]` ตามที่แสดงในตัวจัดการไฟล์ รวมตัวอักษรและตัวเลขทั้งหมด
:::

## Edit GameUserSettings.ini

หลังจากอัปโหลดเซฟเสร็จแล้ว คุณต้องอัปเดตการตั้งค่าเซิร์ฟเวอร์เพื่อให้ Palworld โหลดโลกที่ถูกต้อง

เปิดไฟล์ `GameUserSettings.ini` จากส่วน `Configs` และค้นหาคีย์ `DedicatedServerName`

ตั้งค่าให้ตรงกับชื่อโฟลเดอร์เซฟที่อัปโหลดอย่างแม่นยำ:

```ini
DedicatedServerName=[your_save_folder_id]
```

ตัวอย่าง:

```ini
DedicatedServerName=84B5E2264EC387DEDB43179D666031A1
```

### รายการคอนฟิกที่จำเป็น

ใช้ข้อมูลอ้างอิงนี้เมื่อแก้ไขไฟล์:

| ไฟล์คอนฟิก | คีย์ | ค่าที่ต้องใช้ |
| --- | --- | --- |
| `GameUserSettings.ini` | `DedicatedServerName` | ชื่อโฟลเดอร์เซฟที่อัปโหลดอย่างแม่นยำ |

### การตั้งค่านี้ทำอะไร

`DedicatedServerName` บอกเซิร์ฟเวอร์เฉพาะ Palworld ว่าโฟลเดอร์ใดใน `Pal/Saved/SaveGames/0/` ควรถูกโหลดเป็นโลกที่ใช้งานอยู่

ถ้าค่านี้ไม่ตรงกับชื่อโฟลเดอร์ที่อัปโหลดอย่างแม่นยำ เซิร์ฟเวอร์อาจสร้างโลกใหม่หรือโหลดผิดพลาด

:::danger ต้องตรงกันเป๊ะ
ถ้าคุณเห็นว่าแผนที่ไม่มีความคืบหน้า โลกว่างเปล่า หรือเซฟใหม่ถูกสร้างหลังเริ่มเซิร์ฟเวอร์ สาเหตุที่พบบ่อยที่สุดคือค่า `DedicatedServerName` ไม่ตรงกับชื่อโฟลเดอร์ที่อัปโหลด
:::

## Source-Specific Save Locations

ถ้าคุณไม่แน่ใจว่าจะเอาเซฟต้นฉบับมาจากไหน ให้ใช้เส้นทางแหล่งที่มาที่ถูกต้องด้านล่างนี้

### จากผู้ให้บริการเซิร์ฟเวอร์เฉพาะรายอื่น

บนผู้ให้บริการเดิมของคุณ ให้สำรองโฟลเดอร์เซฟจาก:

```text
Pal/Saved/SaveGames/0/
```

คัดลอกโฟลเดอร์โลกทั้งหมดพร้อมชื่อเดิม จากนั้นอัปโหลดโฟลเดอร์นั้นไปยังเซิร์ฟเวอร์ ZAP-Hosting ของคุณตามที่อธิบายไว้ข้างต้น

### จากเซฟ Steam Co-op

สำหรับเซฟ Steam บน Windows ให้เปิดเส้นทางนี้:

```text
%LOCALAPPDATA%\Pal\Saved\SaveGames\[your_steamid64]\[your_save_folder_id]
```

โฟลเดอร์ `[your_steamid64]` คือ Steam 64-bit ID ของคุณ และ `[your_save_folder_id]` คือโฟลเดอร์โลกที่คุณต้องการย้าย

:::caution ข้อจำกัดตัวละครโฮสต์
เมื่อย้ายโลก Steam co-op ท้องถิ่นไปยังเซิร์ฟเวอร์เฉพาะ ตัวละครโฮสต์เดิมจะไม่ถูกย้ายโดยอัตโนมัติเหมือนข้อมูลผู้เล่นที่เชื่อมต่อ อาจต้องใช้เครื่องมือแปลงเซฟหรือโอนย้ายตัวละครจากบุคคลที่สามเพิ่มเติมถ้าคุณต้องการเก็บตัวละครโฮสต์ไว้
:::

### จาก PC Game Pass

สำหรับการติดตั้ง PC Game Pass ข้อมูลเซฟท้องถิ่นมักจะเก็บไว้ที่:

```text
%LOCALAPPDATA%\Packages\PocketpairInc.Palworld_ad4psfrxyesvt\SystemAppData\wgs\
```

เซฟ Game Pass ไม่ได้เก็บในรูปแบบเดียวกับเซฟ Steam หรือเซิร์ฟเวอร์เฉพาะ ในทางปฏิบัติ คุณมักจะต้องใช้เครื่องมือแปลงจากบุคคลที่สามเพื่อแปลงเซฟให้เป็นรูปแบบที่รองรับ Steam หรือเซิร์ฟเวอร์เฉพาะก่อนอัปโหลด

:::info ต้องแปลงเซฟ Game Pass
การอัปโหลดข้อมูลเซฟ Game Pass ดิบโดยตรงมักไม่เพียงพอ คุณต้องแปลงเซฟก่อน แล้วอัปโหลดโฟลเดอร์โลกที่แปลงแล้วไปยัง `Pal/Saved/SaveGames/0/` และตั้งค่า `DedicatedServerName` ให้ถูกต้อง
:::

## Start the Server

เมื่ออัปโหลดโฟลเดอร์เซฟและอัปเดต `GameUserSettings.ini` เสร็จแล้ว ให้เริ่มเซิร์ฟเวอร์ของคุณอีกครั้งจากแผงควบคุมเว็บ ZAP-Hosting

โดยปกติไม่ต้องใช้คำสั่งคอนโซลเพิ่มเติมสำหรับกระบวนการย้ายนี้

หลังเริ่มเซิร์ฟเวอร์ ให้เข้าร่วมและตรวจสอบว่า:

- โลกที่ถูกต้องถูกโหลด
- อาคารและความคืบหน้าในแผนที่มีอยู่
- ข้อมูลผู้เล่นพร้อมใช้งานตามที่คาดหวัง

## Troubleshooting

ถ้าเซฟที่อัปโหลดไม่โหลดอย่างถูกต้อง ให้ตรวจสอบจุดต่อไปนี้

### เซิร์ฟเวอร์สร้างโลกใหม่

ตรวจสอบว่าค่าต่อไปนี้ใน `GameUserSettings.ini` ตรงกับชื่อโฟลเดอร์ที่อัปโหลดอย่างแม่นยำ:

```ini
DedicatedServerName=[your_save_folder_id]
```

และยืนยันว่าเซฟที่อัปโหลดอยู่ในตำแหน่งนี้โดยตรง:

```text
Pal/Saved/SaveGames/0/[your_save_folder_id]/
```

### แผนที่หรือความคืบหน้าโลกหายไป

โดยปกติหมายถึงสาเหตุใดสาเหตุหนึ่งต่อไปนี้:

| สาเหตุที่เป็นไปได้ | วิธีแก้ไข |
| --- | --- |
| ค่า `DedicatedServerName` ผิด | ป้อนชื่อโฟลเดอร์ที่อัปโหลดอย่างแม่นยำอีกครั้ง |
| โฟลเดอร์เซฟอัปโหลดผิดไดเรกทอรี | ย้ายไปที่ `Pal/Saved/SaveGames/0/` |
| อัปโหลดไม่สมบูรณ์ | อัปโหลดโฟลเดอร์ทั้งหมดใหม่และตรวจสอบว่าไฟล์ครบถ้วน |

### ไฟล์ WorldOption.sav สร้างปัญหา

ถ้าเซฟของคุณมีไฟล์ `WorldOption.sav` ให้ลบไฟล์นี้แล้วเริ่มเซิร์ฟเวอร์ใหม่

ไฟล์นี้เกี่ยวข้องกับพฤติกรรมการจัดการเซฟแบบเก่าและอาจรบกวนโลกเซิร์ฟเวอร์เฉพาะที่ย้ายมา

## Conclusion

ยินดีด้วย คุณได้อัปโหลดเซฟ Palworld ที่มีอยู่แล้วไปยังเซิร์ฟเวอร์ของคุณที่ ZAP-Hosting สำเร็จแล้ว สำหรับคำถามเพิ่มเติมหรือความช่วยเหลือ อย่าลังเลที่จะติดต่อทีมซัพพอร์ตของเรา ซึ่งพร้อมให้บริการทุกวันเพื่อช่วยเหลือคุณ! 🙂
