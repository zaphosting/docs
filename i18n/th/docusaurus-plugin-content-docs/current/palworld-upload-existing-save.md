## Introduction

Palworld เก็บข้อมูลโลกของเซิร์ฟเวอร์เกมเฉพาะไว้ในโฟลเดอร์เซฟเฉพาะ และต้องการการตั้งค่าที่ตรงกันเพื่อโหลดข้อมูลได้ถูกต้อง ในคู่มือนี้ คุณจะได้เรียนรู้วิธีอัปโหลดเซฟที่มีอยู่แล้วไปยังเซิร์ฟเวอร์ Palworld ของคุณที่ ZAP-Hosting และตั้งค่าเซิร์ฟเวอร์ให้เริ่มต้นด้วยข้อมูลโลกที่ถูกต้อง

:::danger แหล่งเซฟที่ไม่รองรับ
คุณไม่สามารถโอนย้ายเซฟจากเครื่อง Xbox หรือ PS5 cloud ไปยังเซิร์ฟเวอร์เกมเฉพาะ Palworld ได้โดยตรง วิธีนี้รองรับเฉพาะเซฟจากการติดตั้งบน PC หรือเซิร์ฟเวอร์เกมเฉพาะที่มีอยู่แล้วเท่านั้น
:::

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่าคุณมีสิ่งต่อไปนี้:

| ความต้องการ | รายละเอียด |
| --- | --- |
| เซฟ Palworld ที่มีอยู่แล้ว | โฟลเดอร์เซฟจากการติดตั้งบน PC หรือเซิร์ฟเวอร์เกมเฉพาะอื่น |
| การเข้าถึงเซิร์ฟเวอร์เกม ZAP-Hosting ของคุณ | คุณต้องเข้าถึงเว็บอินเทอร์เฟซ รวมถึงตัวจัดการไฟล์และส่วน `Configs` |
| เซิร์ฟเวอร์หยุดทำงาน | เซิร์ฟเวอร์ Palworld ควรถูกหยุดก่อนเปลี่ยนข้อมูลเซฟ |
| ชื่อโฟลเดอร์เซฟ | คุณต้องรู้ชื่อโฟลเดอร์เซฟที่อัปโหลดอย่างแม่นยำ เช่น `[your_savefolder_id]` |

:::info การเข้าถึงไฟล์คอนฟิก
บน ZAP-Hosting ไฟล์คอนฟิก Palworld ที่เกี่ยวข้องสามารถเข้าถึงได้ผ่านการจัดการเซิร์ฟเวอร์เกมของคุณในส่วน `Configs` คุณไม่จำเป็นต้องแก้ไขไฟล์โดยตรงผ่านตัวจัดการไฟล์ เว้นแต่คุณต้องการตรวจสอบเส้นทางด้วยตัวเอง
:::

## เข้าใจโครงสร้างเซฟที่ต้องการ

ก่อนอัปโหลดไฟล์ใด ๆ สำคัญที่ต้องเข้าใจว่า Palworld โหลดโฟลเดอร์ไหนจริง ๆ

ตำแหน่งเซฟของเซิร์ฟเวอร์คือ:

```text
Pal/Saved/SaveGames/0/[your_savefolder_id]/
```

ภายในโฟลเดอร์นี้ คุณควรเห็นไฟล์และโฟลเดอร์ที่คล้ายกับต่อไปนี้:

```text
Level.sav
LevelMeta.sav
Players/
```

ในเซฟเก่าหรือเซฟที่ย้ายมา อาจมีไฟล์นี้ด้วย:

```text
WorldOption.sav
```

:::caution ลบไฟล์ WorldOption.sav ที่เลิกใช้แล้ว
ถ้าไฟล์ `WorldOption.sav` อยู่ในโฟลเดอร์เซฟที่อัปโหลด ให้ลบออกก่อนเริ่มเซิร์ฟเวอร์ ไฟล์นี้เป็นที่รู้กันว่าสร้างปัญหากับการตั้งค่าเซิร์ฟเวอร์ Palworld รุ่นใหม่ และไม่ควรใช้กับเซฟที่ย้ายมา เว้นแต่จะได้รับการยืนยันว่าจำเป็นในเซ็ตอัพปัจจุบัน
:::

## หาไฟล์คอนฟิกที่ถูกต้อง

เพื่อให้เซิร์ฟเวอร์โหลดโลกที่คุณอัปโหลด คุณต้องแก้ไขไฟล์ `GameUserSettings.ini`

ในแผงควบคุมเซิร์ฟเวอร์เกม ZAP-Hosting:

1. เปิดเซิร์ฟเวอร์ Palworld ของคุณ
2. ไปที่ `Configs`
3. เปิดไฟล์ `GameUserSettings.ini`

ขึ้นอยู่กับสภาพแวดล้อมเซิร์ฟเวอร์ปัจจุบัน เส้นทางไฟล์ที่แท้จริงมักจะเป็นหนึ่งในนี้:

| เส้นทางที่เป็นไปได้ | หมายเหตุ |
| --- | --- |
| `Pal/Saved/Config/LinuxServer/GameUserSettings.ini` | พบทั่วไปในเซิร์ฟเวอร์ Palworld บนระบบ Linux |
| `Pal/Saved/Config/WindowsServer/GameUserSettings.ini` | อาจพบในเซิร์ฟเวอร์บน Windows |

:::note ความแตกต่างของเส้นทาง
การติดตั้งเซิร์ฟเวอร์ Palworld อาจใช้ `LinuxServer` หรือ `WindowsServer` ในเส้นทางคอนฟิก ขึ้นอยู่กับแพลตฟอร์มที่ผู้ให้บริการใช้ หากคุณแก้ไขไฟล์ผ่าน `Configs` ไฟล์ที่ถูกต้องจะถูกเปิดให้แล้ว คุณแค่ต้องแน่ใจว่าแก้ไขไฟล์ `GameUserSettings.ini` เท่านั้น
:::

## อัปโหลดเซฟจากเซิร์ฟเวอร์เฉพาะอื่น

ถ้าเซฟของคุณมาจากผู้ให้บริการเช่าเซิร์ฟเวอร์เกมรายอื่น คุณสามารถย้ายมาได้โดยตรง

### สำรองเซฟที่มีอยู่

บนผู้ให้บริการเดิมของคุณ ให้ค้นหาและดาวน์โหลดโฟลเดอร์เซฟที่มีอยู่จาก:

```text
Pal/Saved/SaveGames/0/
```

คัดลอกโฟลเดอร์เต็มที่มีชื่อสุ่มตัวอักษรและตัวเลข เช่น:

```text
[your_savefolder_id]
```

### หยุดเซิร์ฟเวอร์ ZAP-Hosting

ก่อนอัปโหลดเซฟใหม่ ให้หยุดเซิร์ฟเวอร์ Palworld ของคุณในเว็บอินเทอร์เฟซ ZAP-Hosting

:::caution ป้องกันปัญหาเซฟซ้อนทับ
อย่าเปลี่ยนไฟล์เซฟขณะเซิร์ฟเวอร์กำลังทำงาน เพราะอาจทำให้การอัปโหลดไม่สมบูรณ์ ข้อมูลถูกเขียนทับ หรือเซฟเสียหายได้
:::

### แทนที่โฟลเดอร์เซฟเริ่มต้น

เปิดตัวจัดการไฟล์ของเซิร์ฟเวอร์เกม แล้วไปที่:

```text
Pal/Saved/SaveGames/0/
```

ลบโฟลเดอร์เซฟเริ่มต้นที่เซิร์ฟเวอร์สร้างขึ้นอัตโนมัติ จากนั้นอัปโหลดโฟลเดอร์เซฟที่มีอยู่ของคุณไปยังตำแหน่งเดียวกัน

หลังอัปโหลด โครงสร้างควรเป็นแบบนี้:

```text
Pal/Saved/SaveGames/0/[your_savefolder_id]/
```

### ตั้งค่าโฟลเดอร์เซฟใน GameUserSettings.ini ให้ถูกต้อง

ตอนนี้เปิด `GameUserSettings.ini` ผ่าน `Configs` แล้วค้นหาคีย์ `DedicatedServerName`

ตั้งค่าให้ตรงกับชื่อโฟลเดอร์เซฟที่อัปโหลด:

```ini
DedicatedServerName=[your_savefolder_id]
```

| รายการคอนฟิก | ค่าที่ต้องใส่ |
| --- | --- |
| `DedicatedServerName` | ชื่อโฟลเดอร์ที่อยู่ใน `Pal/Saved/SaveGames/0/` อย่างแม่นยำ |

:::tip ต้องตรงกันเป๊ะ
ค่า `DedicatedServerName` ต้องตรงกับชื่อโฟลเดอร์ที่อัปโหลดทุกตัวอักษรและตัวเลข ถ้าไม่ตรง เซิร์ฟเวอร์อาจโหลดโลกผิด หรือดูเหมือนไม่มีความคืบหน้าของแผนที่
:::

### เริ่มเซิร์ฟเวอร์

หลังบันทึกการตั้งค่าแล้ว ให้เริ่มเซิร์ฟเวอร์ Palworld ของคุณอีกครั้ง

โดยปกติไม่ต้องใช้คำสั่งคอนโซลเพิ่มเติมหลังอัปโหลด การรีสตาร์ทเซิร์ฟเวอร์เต็มรูปแบบก็เพียงพอให้โหลดเซฟใหม่ได้

## อัปโหลดเซฟจากโลก Steam Co-op

ถ้าคุณเคยโฮสต์โลกของคุณแบบ Steam co-op บนเครื่องเองมาก่อน คุณก็สามารถอัปโหลดเซฟนั้นไปยังเซิร์ฟเวอร์เกมเฉพาะได้เช่นกัน

### หาเซฟ Steam บนเครื่อง

บน Windows PC ของคุณ กด `Windows` + `R` แล้วเปิด:

```text
%LOCALAPPDATA%\Pal\Saved\SaveGames
```

ในตำแหน่งนี้ เปิดโฟลเดอร์ที่ชื่อเป็น SteamID64 ของคุณ จากนั้นหาโฟลเดอร์โลกที่ต้องการอัปโหลด:

```text
%LOCALAPPDATA%\Pal\Saved\SaveGames\[your_steamid64]\[your_savefolder_id]
```

### อัปโหลดเซฟไปยังเซิร์ฟเวอร์

เมื่อเจอโฟลเดอร์เซฟที่ถูกต้องแล้ว:

1. หยุดเซิร์ฟเวอร์ Palworld ของคุณ
2. เปิดตัวจัดการไฟล์
3. ไปที่ `Pal/Saved/SaveGames/0/`
4. ลบโฟลเดอร์เซฟเริ่มต้น
5. อัปโหลดโฟลเดอร์เซฟที่มีอยู่
6. เปิด `GameUserSettings.ini` ใน `Configs`
7. ตั้งค่า:

```ini
DedicatedServerName=[your_savefolder_id]
```

8. บันทึกไฟล์และเริ่มเซิร์ฟเวอร์อีกครั้ง

:::caution ข้อจำกัดของตัวละครโฮสต์
เมื่อย้ายโลก Steam co-op บนเครื่อง ตัวละครโฮสต์จะไม่ถูกโอนย้ายโดยอัตโนมัติแบบเดียวกับข้อมูลผู้เล่นที่เชื่อมต่อ ในทางปฏิบัติ หมายความว่าโฮสต์เดิมอาจต้องใช้ขั้นตอนแปลงเซฟหรือโอนย้ายตัวละครจากภายนอกเพิ่มเติมถ้าต้องการรักษาความต่อเนื่องของตัวละคร
:::

## อัปโหลดเซฟจาก PC Game Pass

เซฟ PC Game Pass ใช้ฟอร์แมตต่างกันและไม่พร้อมใช้งานโดยตรงกับเซิร์ฟเวอร์เกมเฉพาะ Palworld

### หาเซฟ Game Pass

ข้อมูลเซฟ Game Pass บนเครื่องมักเก็บไว้ที่:

```text
%LOCALAPPDATA%\Packages\PocketpairInc.Palworld_ad4psfrxyesvt\SystemAppData\wgs\
```

### แปลงเซฟก่อน

ถ้าต้องการใช้เซฟ PC Game Pass บนเซิร์ฟเวอร์เกมเฉพาะ คุณต้องแปลงเป็นฟอร์แมตที่รองรับ Steam ด้วยเครื่องมือแปลงจากภายนอก

ตัวเลือกที่ใช้กันบ่อยคือ [Palworld Save Tools](https://github.com/cheahjs/palworld-save-tools)

:::danger คำเตือนเครื่องมือภายนอก
เครื่องมือแปลงเซฟจากภายนอกไม่ได้พัฒนาโดย ZAP-Hosting ฟังก์ชันการทำงานอาจเปลี่ยนแปลงได้ และความเข้ากันได้ไม่รับประกัน ควรสำรองเซฟต้นฉบับก่อนใช้เครื่องมือใด ๆ
:::

หลังแปลง เซฟที่ส่งออกมามักจะอยู่ในโฟลเดอร์เช่น:

```text
XGP_converted_saves
```

### อัปโหลดเซฟที่แปลงแล้ว

หลังแปลงเซฟเสร็จ:

1. หยุดเซิร์ฟเวอร์ของคุณ
2. เปิดตัวจัดการไฟล์
3. ไปที่ `Pal/Saved/SaveGames/0/`
4. ลบโฟลเดอร์เซฟเริ่มต้น
5. อัปโหลดโฟลเดอร์เซฟที่แปลงแล้ว
6. เปิด `GameUserSettings.ini` ใน `Configs`
7. ตั้งชื่อโฟลเดอร์ให้ถูกต้อง:

```ini
DedicatedServerName=[your_savefolder_id]
```

8. บันทึกไฟล์และเริ่มเซิร์ฟเวอร์

## การเปลี่ยนแปลงคอนฟิกที่จำเป็น

ขั้นตอนสำคัญที่สุดคือการแก้ไขไฟล์ `GameUserSettings.ini` ให้ถูกต้อง

### ภาพรวมรายการคอนฟิก

| ไฟล์ | ตำแหน่งในอินเทอร์เฟซ ZAP | รายการที่ต้องแก้ไข | ตัวอย่างค่า |
| --- | --- | --- | --- |
| `GameUserSettings.ini` | `Configs` | `DedicatedServerName` | `DedicatedServerName=84B5E2264EC387DEDB43179D666031A1` |

### ตัวอย่างคอนฟิก

ถ้าโฟลเดอร์เซฟที่อัปโหลดชื่อ `84B5E2264EC387DEDB43179D666031A1` รายการนี้ควรเป็นแบบนี้:

```ini
DedicatedServerName=84B5E2264EC387DEDB43179D666031A1
```

อย่าใส่เครื่องหมายคำพูดเพิ่ม เว้นแต่ไฟล์คอนฟิกของคุณใช้ไวยากรณ์แบบนั้นอยู่แล้ว

## ตรวจสอบการอัปโหลด

หลังเซิร์ฟเวอร์เริ่มต้น ให้เข้าร่วมเซิร์ฟเวอร์และตรวจสอบว่าโหลดข้อมูลโลกได้ถูกต้องหรือไม่

คุณควรตรวจสอบสิ่งต่อไปนี้:

| ตรวจสอบ | ผลลัพธ์ที่คาดหวัง |
| --- | --- |
| โหลดโลก | แผนที่และโครงสร้างเดิมปรากฏอยู่ |
| ข้อมูลผู้เล่น | ข้อมูลผู้เล่นที่โอนย้ายมาก่อนหน้านี้พร้อมใช้งานถ้ามี |
| ชื่อโฟลเดอร์เซฟตรงกัน | `DedicatedServerName` ตรงกับชื่อโฟลเดอร์ที่อัปโหลดเป๊ะ |
| ลบไฟล์ที่เลิกใช้แล้ว | ไฟล์ `WorldOption.sav` ไม่อยู่ถ้าเคยสร้างปัญหา |

## แก้ไขปัญหา

ถ้าอัปโหลดไม่สำเร็จตามที่คาดไว้ ให้ตรวจสอบสาเหตุทั่วไปเหล่านี้

### เซิร์ฟเวอร์เริ่มโลกใหม่

ถ้าเซิร์ฟเวอร์สร้างโลกใหม่แทนที่จะโหลดเซฟที่อัปโหลด สาเหตุที่พบบ่อยคือค่า `DedicatedServerName` ไม่ถูกต้อง

ตรวจสอบให้แน่ใจว่า:

- โฟลเดอร์ที่อัปโหลดอยู่ใน `Pal/Saved/SaveGames/0/`
- ชื่อโฟลเดอร์ถูกคัดลอกมาเป๊ะ
- ค่า `DedicatedServerName=[your_savefolder_id]` ตรงกับชื่อโฟลเดอร์นั้นเป๊ะ

### ข้อมูลแผนที่หายไป

ถ้าเซิร์ฟเวอร์เริ่มทำงานแต่โลกหรือความคืบหน้าของแผนที่หาย ให้ตรวจสอบการจับคู่ชื่อโฟลเดอร์อีกครั้ง

ปัญหานี้มักเกิดจากความไม่ตรงกันระหว่าง:

- ชื่อโฟลเดอร์เซฟที่อัปโหลด
- ค่า `DedicatedServerName` ใน `GameUserSettings.ini`

### ดูเหมือนอัปโหลดถูกต้องแต่ยังโหลดไม่ได้

ถ้าโครงสร้างโฟลเดอร์ดูถูกต้องแต่เซฟยังไม่โหลด:

- ยืนยันว่าเซฟมาจากแหล่งที่รองรับ
- ลบไฟล์ `WorldOption.sav` ถ้ามี
- ตรวจสอบว่าเซิร์ฟเวอร์หยุดทำงานเต็มที่ก่อนเปลี่ยนไฟล์
- รีสตาร์ทเซิร์ฟเวอร์หลังบันทึกการตั้งค่า

:::tip เคล็ดลับการอัปโหลดไฟล์
ถ้าอัปโหลดเซฟขนาดใหญ่ ให้รอจนการโอนถ่ายเสร็จสมบูรณ์ก่อนเริ่มเซิร์ฟเวอร์ การเริ่มก่อนเวลาอาจทำให้เซฟไม่สมบูรณ์และโลกโหลดไม่ถูกต้อง
:::
