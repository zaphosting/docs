## Introduction

Palworld ให้คุณควบคุมความถี่ในการเกิดของ Pals ในโลกของคุณผ่านการตั้งค่าเซิร์ฟเวอร์ ในคู่มือนี้ คุณจะได้เรียนรู้วิธีแก้ไขไฟล์การตั้งค่าที่ถูกต้องในแผงควบคุมเซิร์ฟเวอร์เกม ZAP-Hosting และปรับอัตราการเกิด Pal ใหม่อย่างปลอดภัย



## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่า:

- คุณสามารถเข้าถึงเซิร์ฟเวอร์เกม Palworld ของคุณในเว็บอินเทอร์เฟซ ZAP-Hosting ได้
- เซิร์ฟเวอร์ของคุณออฟไลน์ หรือคุณพร้อมที่จะรีสตาร์ทหลังจากทำการเปลี่ยนแปลง
- คุณเข้าใจว่าค่าการเกิดที่สูงขึ้นอาจเพิ่มภาระเซิร์ฟเวอร์และลดประสิทธิภาพ

:::info การตั้งค่าด้วยตนเองจำเป็น
การเปลี่ยนแปลงนี้ต้องทำด้วยตนเองโดยแก้ไขไฟล์การตั้งค่าเซิร์ฟเวอร์ในเมนู **Configs** ของแผงควบคุมเซิร์ฟเวอร์เกม ไม่มีสไลเดอร์แยกในแผงควบคุม ZAP-Hosting สำหรับการตั้งค่านี้โดยเฉพาะ
:::

## เปิดไฟล์การตั้งค่า Palworld

เพื่อเปลี่ยนอัตราการเกิด Pal คุณต้องแก้ไขไฟล์ `PalWorldSettings.ini`

ในแผงควบคุมเซิร์ฟเวอร์เกม ZAP-Hosting ของคุณ:

1. เปิดเซิร์ฟเวอร์ **Palworld** ของคุณ
2. ไปที่เมนู **Configs**
3. เปิดไฟล์ `PalWorldSettings.ini`

ไฟล์นี้ประกอบด้วยการตั้งค่าเซิร์ฟเวอร์หลักที่เกี่ยวกับการเล่นเกม รวมถึงตัวคูณอัตราการเกิด Pal

:::note ตำแหน่งไฟล์การตั้งค่า
สำหรับเซิร์ฟเวอร์ Palworld ของ ZAP-Hosting ไฟล์ที่เกี่ยวข้องจะอยู่ในเมนู **Configs** โดยตรงในแผงควบคุมเซิร์ฟเวอร์เกม ตามที่จัดเตรียมไว้ในเซ็ตอัพเซิร์ฟเวอร์
:::

## เปลี่ยนอัตราการเกิด Pal

การตั้งค่าที่คุณต้องแก้ไขคือ `PalSpawnNumRate`

### ความหมายของ `PalSpawnNumRate`

`PalSpawnNumRate` ควบคุมตัวคูณความถี่การเกิด Pal บนเซิร์ฟเวอร์ของคุณ

| คีย์การตั้งค่า | ค่าเริ่มต้น | คำอธิบาย |
| --- | --- | --- |
| `PalSpawnNumRate` | `1.000000` | ควบคุมจำนวน Pal ที่เกิดในโลก ค่าเพิ่มจะเพิ่มความถี่การเกิด |

ใน Palworld ค่านี้มักจะอยู่ในบรรทัด `OptionSettings` ภายในไฟล์ `PalWorldSettings.ini`

### แก้ไขการตั้งค่า

เปิดไฟล์ `PalWorldSettings.ini` แล้วค้นหาส่วน `OptionSettings=` ในส่วนนั้น ให้หาคีย์ `PalSpawnNumRate`

ถ้าคีย์นี้มีอยู่แล้ว ให้เปลี่ยนค่า เช่น:

```ini
PalSpawnNumRate=1.000000
```

คุณสามารถเพิ่มค่าได้แบบนี้:

```ini
PalSpawnNumRate=2.000000
```

ตัวอย่างนี้จะเพิ่มตัวคูณการเกิด Pal เป็นสองเท่าจากค่าเริ่มต้น

:::tip ค่าที่แนะนำสำหรับเริ่มต้น
เริ่มจากการเพิ่มเล็กน้อย เช่น `1.500000` หรือ `2.000000` แล้วทดสอบประสิทธิภาพเซิร์ฟเวอร์ก่อนใช้ค่าที่สูงกว่านี้
:::

### ตัวอย่างโค้ดการตั้งค่า

ขึ้นอยู่กับเนื้อหาไฟล์ของคุณ การตั้งค่านี้อาจอยู่ในบรรทัด `OptionSettings` ยาวๆ แบบนี้:

```ini
[/Script/Pal.PalGameWorldSettings]
OptionSettings=(Difficulty=None,DayTimeSpeedRate=1.000000,NightTimeSpeedRate=1.000000,ExpRate=1.000000,PalCaptureRate=1.000000,PalSpawnNumRate=2.000000)
```

:::caution อย่าลบหรือแก้ไขไวยากรณ์เดิม
อย่าลบเครื่องหมายจุลภาค, วงเล็บ หรือค่าที่มีอยู่ในบรรทัด `OptionSettings` การจัดรูปแบบผิดพลาดใน `PalWorldSettings.ini` อาจทำให้เซิร์ฟเวอร์โหลดการตั้งค่าไม่ถูกต้อง
:::

## ค่าที่แนะนำและผลกระทบต่อประสิทธิภาพ

คุณสามารถใช้ค่าต่างๆ ตามประสบการณ์การเล่นที่ต้องการ

| ค่า | ผลลัพธ์ |
| --- | --- |
| `1.000000` | อัตราการเกิด Pal เริ่มต้น |
| `1.500000` | เพิ่มความถี่การเกิดเล็กน้อย |
| `2.000000` | มี Pal เกิดมากขึ้นอย่างเห็นได้ชัด |
| `3.000000` ขึ้นไป | เพิ่มการเกิดอย่างหนัก อาจกระทบประสิทธิภาพ |

ค่าสูงจะทำให้โลกดูมีชีวิตชีวามากขึ้น แต่ก็เพิ่มจำนวนเอนทิตีที่เซิร์ฟเวอร์ต้องประมวลผล

:::danger ค่าการเกิดสูงมากอาจลดความเสถียร
การตั้งค่าการเกิดสูงมากอาจส่งผลเสียต่อประสิทธิภาพเซิร์ฟเวอร์ โดยเฉพาะเซิร์ฟเวอร์ที่มีผู้เล่นเยอะหรือมีการตั้งค่าโลกที่ต้องใช้ทรัพยากรมาก หากพบอาการแลค ให้ลดค่าลงและรีสตาร์ทเซิร์ฟเวอร์
:::

## บันทึกและรีสตาร์ทเซิร์ฟเวอร์

หลังจากแก้ไขไฟล์:

1. บันทึกการเปลี่ยนแปลงใน `PalWorldSettings.ini`
2. รีสตาร์ทเซิร์ฟเวอร์ Palworld ของคุณจากแผงควบคุมเซิร์ฟเวอร์เกม ZAP-Hosting

ต้องรีสตาร์ทเพื่อให้การตั้งค่าอัตราการเกิด Pal ใหม่มีผล

## ตรวจสอบการเปลี่ยนแปลง

เมื่อเซิร์ฟเวอร์ออนไลน์อีกครั้ง ให้เข้าร่วมเซิร์ฟเวอร์ Palworld ของคุณและสังเกตกิจกรรมในพื้นที่ที่ Pal ปกติเกิด

ถ้าอัตราการเกิดดูเหมือนไม่เปลี่ยนแปลง:

- เปิดไฟล์ `PalWorldSettings.ini` อีกครั้งและตรวจสอบว่ามี `PalSpawnNumRate`
- ตรวจสอบว่าค่าอยู่ในส่วน `OptionSettings` ที่ถูกต้อง
- ยืนยันว่าไฟล์ถูกบันทึกเรียบร้อยแล้ว
- รีสตาร์ทเซิร์ฟเวอร์อีกครั้งหลังยืนยันการเปลี่ยนแปลง
