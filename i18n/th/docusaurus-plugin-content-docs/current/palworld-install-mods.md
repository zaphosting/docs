## Introduction

Palworld รองรับม็อดเซิร์ฟเวอร์หลายประเภท โดยทั่วไปคือ `UE4SS`, `.lua` และ `.pak` ในคู่มือนี้ คุณจะได้เรียนรู้วิธีเตรียมเซิร์ฟเวอร์ของคุณ ระบุประเภทม็อดที่ถูกต้อง อัปโหลดไฟล์ที่จำเป็น และรีสตาร์ทเซิร์ฟเวอร์เพื่อให้ม็อดโหลดได้อย่างถูกต้อง



## Preparation

ก่อนติดตั้งม็อดใดๆ คุณควรตรวจสอบให้แน่ใจว่าเซิร์ฟเวอร์และม็อดที่เลือกเข้ากันได้

:::danger สำรองข้อมูลโลกของคุณก่อนเสมอ
คุณควรสร้างสำรองข้อมูลการบันทึกโลกของ Palworld ก่อนติดตั้งม็อดเสมอ หากม็อดไม่เข้ากันหรือทำให้เซิร์ฟเวอร์ไม่สามารถเริ่มต้นได้ คุณอาจต้องกู้คืนสถานะโลกก่อนหน้า
:::

คุณควรตรวจสอบสิ่งต่อไปนี้ก่อน:

| ข้อกำหนด | รายละเอียด |
| --- | --- |
| เวอร์ชันเซิร์ฟเวอร์ | เซิร์ฟเวอร์เฉพาะ Palworld ใช้เวอร์ชัน **Steam** ม็อดที่ออกแบบสำหรับเวอร์ชัน **Game Pass** เท่านั้นไม่ควรใช้ |
| ความเข้ากันได้ของม็อด | ยืนยันว่าผู้สร้างม็อดระบุชัดเจนว่าม็อดใช้งานได้บนเซิร์ฟเวอร์เฉพาะ |
| ประเภทม็อด | ตรวจสอบว่าม็อดเป็น `UE4SS`, `.lua` หรือ `.pak` |
| ความต้องการฝั่งไคลเอนต์ | ม็อดบางตัวต้องติดตั้งทั้งบน **เซิร์ฟเวอร์** และ **ไคลเอนต์ผู้เล่น** ทุกคน |
| เวอร์ชันเซิร์ฟเวอร์ | ตรวจสอบเวอร์ชันเซิร์ฟเวอร์ปัจจุบันก่อนติดตั้งม็อด |

### ตรวจสอบเวอร์ชันเซิร์ฟเวอร์ของคุณ

เพื่อยืนยันเวอร์ชันเซิร์ฟเวอร์ Palworld ปัจจุบัน ให้เปิดคอนโซลเซิร์ฟเวอร์ในแผงควบคุมเกมเซิร์ฟเวอร์ ZAP-Hosting แล้วรันคำสั่ง:

```text
info
```

คำสั่งนี้จะแสดงข้อมูลเวอร์ชันที่คุณสามารถนำไปเปรียบเทียบกับความต้องการของม็อดได้

:::tip ติดตั้งม็อดทีละตัว
คุณควรติดตั้งม็อดทีละตัวและทดสอบก่อนเพิ่มม็อดตัวถัดไป เพื่อให้ง่ายต่อการแก้ไขปัญหา หากเซิร์ฟเวอร์ไม่สามารถเริ่มต้นหรือม็อดไม่ทำงานอย่างถูกต้อง
:::

## เข้าใจประเภทม็อดที่คุณกำลังติดตั้ง

ม็อด Palworld ไม่ได้ติดตั้งเหมือนกันทั้งหมด คุณต้องระบุประเภทม็อดก่อนอัปโหลดไฟล์

| ประเภทม็อด | เนื้อหาทั่วไป | เส้นทางติดตั้งทั่วไป | หมายเหตุ |
| --- | --- | --- | --- |
| ม็อด `UE4SS` / `.lua` | โฟลเดอร์ที่มีสคริปต์ เช่น `main.lua` | `Pal/Binaries/Win64/ue4ss/Mods/` | โดยปกติต้องใช้เฟรมเวิร์ก `UE4SS` |
| ม็อด `.pak` | ไฟล์ `.pak` หนึ่งไฟล์หรือมากกว่า บางครั้งมีไฟล์เสริม | `Pal/Content/Paks/~mods/` | ม็อดบางตัวอาจใช้ `Pal/Content/Paks/LogicMods/` แทน |
| ม็อดฝั่งไคลเอนต์ | แตกต่างกันไป | ไม่ใช่ทุกม็อดที่ติดตั้งบนเซิร์ฟเวอร์ได้ | ต้องใช้เฉพาะถ้าผู้สร้างม็อดยืนยันว่ารองรับเซิร์ฟเวอร์ |

:::caution ตามเส้นทางที่ผู้สร้างม็อดกำหนด
เส้นทางในคู่มือนี้เป็นตำแหน่งที่ใช้บ่อยสำหรับม็อด Palworld ปัจจุบัน แต่บางม็อดอาจต้องโครงสร้างโฟลเดอร์ที่แตกต่างกัน คุณควรปฏิบัติตามคำแนะนำของผู้สร้างม็อดเสมอหากแตกต่างกัน
:::

## เข้าถึงไฟล์เซิร์ฟเวอร์ของคุณในอินเทอร์เฟซ ZAP

คุณจะต้องใช้พื้นที่จัดการไฟล์ในแผงควบคุมเกมเซิร์ฟเวอร์ ZAP-Hosting

### เปิดส่วน Configs

ไฟล์คอนฟิกที่เกี่ยวข้องสามารถเข้าถึงได้ในแผงควบคุมเกมเซิร์ฟเวอร์ของคุณภายใต้ **Configs** พื้นที่นี้เหมาะสำหรับตรวจสอบและแก้ไขไฟล์คอนฟิกที่มีสำหรับเซิร์ฟเวอร์ Palworld ของคุณ

:::note ความแตกต่างระหว่าง Configs กับไฟล์ม็อด
การติดตั้งม็อด Palworld มักไม่เสร็จสมบูรณ์เพียงแค่เปลี่ยนการตั้งค่าในไฟล์คอนฟิกเดียวเท่านั้น ในหลายกรณี คุณต้องอัปโหลดไฟล์ม็อดจริงไปยังไดเรกทอรีเซิร์ฟเวอร์ที่ถูกต้อง และม็อดบางตัวอาจต้องแก้ไขคอนฟิกเพิ่มเติมในไฟล์ที่อยู่ใน **Configs** ด้วย
:::

### เปิดตัวจัดการไฟล์

เพื่ออัปโหลดไฟล์ม็อด เช่น ไฟล์ `.pak` หรือโฟลเดอร์สคริปต์ `UE4SS` คุณต้องเข้าถึงไฟล์เซิร์ฟเวอร์ผ่านตัวจัดการไฟล์ในอินเทอร์เฟซ ZAP

ถ้าม็อดมีไฟล์คอนฟิกของตัวเอง คุณควรอัปโหลดไฟล์นั้นตามที่ผู้สร้างม็อดให้มาเป๊ะๆ แล้วแก้ไขเฉพาะเมื่อผู้สร้างม็อดระบุค่าที่รองรับไว้เท่านั้น

## ติดตั้งเฟรมเวิร์ก UE4SS หากจำเป็น

`UE4SS` คือเฟรมเวิร์กม็อดที่ใช้กับม็อด Lua และสคริปต์หลายตัวของ Palworld คุณต้องใช้เฉพาะเมื่อม็อดที่เลือกขึ้นอยู่กับมันเท่านั้น

### ยืนยันว่าเซิร์ฟเวอร์ของคุณใช้ Windows

`UE4SS` สำหรับ Palworld มักใช้กับเวอร์ชันเซิร์ฟเวอร์ Windows หากเซิร์ฟเวอร์ของคุณไม่ใช่สภาพแวดล้อมเซิร์ฟเวอร์ Palworld บน Windows ม็อดที่ใช้ `UE4SS` อาจไม่ทำงานตามที่คาดหวัง

:::info ความต้องการ UE4SS
ถ้าม็อดที่คุณเลือกเป็นม็อด `UE4SS` หรือ `.lua` คุณควรตรวจสอบว่าเฟรมเวิร์กนี้ติดตั้งอยู่แล้วก่อนอัปโหลดม็อด
:::

### ตรวจสอบเส้นทางติดตั้ง UE4SS

ถ้า `UE4SS` ติดตั้งอยู่ โฟลเดอร์ที่เกี่ยวข้องโดยทั่วไปคือ:

```text
Pal/Binaries/Win64/ue4ss/
```

โฟลเดอร์ม็อดที่ใช้โดยม็อด `UE4SS` และ Lua ส่วนใหญ่คือ:

```text
Pal/Binaries/Win64/ue4ss/Mods/
```

ถ้าผลิตภัณฑ์ ZAP-Hosting ของคุณมีตัวเลือกม็อดหรือ `UE4SS` ในแผงควบคุมเซิร์ฟเวอร์ คุณสามารถใช้ตัวเลือกนั้นได้ หากไม่เห็นตัวเลือกนี้ในอินเทอร์เฟซของคุณ อย่าสมมติว่ามีสำหรับผลิตภัณฑ์หรือประเภทเซิร์ฟเวอร์ของคุณ

## อัปโหลดและติดตั้งม็อด Lua หรือ UE4SS

ม็อด Lua และม็อด Palworld ที่ใช้ `UE4SS` มักแจกจ่ายเป็นโฟลเดอร์ ไม่ใช่ไฟล์ `.pak` เดียว

### แตกไฟล์ม็อดบนอุปกรณ์ของคุณ

ดาวน์โหลดไฟล์ม็อดจากหน้าปล่อยอย่างเป็นทางการของผู้สร้างม็อด แล้วแตกไฟล์บนคอมพิวเตอร์ของคุณก่อน คุณไม่ควรอัปโหลดไฟล์ `.zip` หรือ `.rar` เว้นแต่ผู้สร้างม็อดจะบอกให้ทำ

### อัปโหลดโฟลเดอร์ม็อดไปยังเส้นทางที่ถูกต้อง

สำหรับม็อด Lua หรือ `UE4SS` ส่วนใหญ่ ให้อัปโหลดโฟลเดอร์ม็อดที่แตกไฟล์แล้วไปที่:

```text
Pal/Binaries/Win64/ue4ss/Mods/
```

โครงสร้างม็อด Lua ทั่วไปจะเป็นแบบนี้:

```text
Pal/Binaries/Win64/ue4ss/Mods/UploadedMod/scripts/main.lua
```

แทนที่ `UploadedMod` ด้วยชื่อโฟลเดอร์จริงที่ผู้สร้างม็อดให้มา

### ตัวอย่างโครงสร้าง

| รายการ | ตัวอย่างเส้นทาง |
| --- | --- |
| โฟลเดอร์ม็อด | `Pal/Binaries/Win64/ue4ss/Mods/UploadedMod/` |
| ไฟล์สคริปต์ | `Pal/Binaries/Win64/ue4ss/Mods/UploadedMod/scripts/main.lua` |

:::caution อย่าเปลี่ยนชื่อไฟล์โดยไม่จำเป็น
คุณไม่ควรเปลี่ยนชื่อโฟลเดอร์ม็อด ไฟล์สคริปต์ หรือโครงสร้างภายในเว้นแต่ผู้สร้างม็อดจะบอกให้ทำ ม็อด `UE4SS` หลายตัวขึ้นอยู่กับโครงสร้างเดิมเพื่อโหลดอย่างถูกต้อง
:::

## อัปโหลดและติดตั้งม็อด .pak

ม็อด `.pak` ติดตั้งต่างจากม็อด Lua หรือสคริปต์ `UE4SS`

### อัปโหลดไฟล์ `.pak`

สำหรับม็อด `.pak` ส่วนใหญ่ของ Palworld ให้อัปโหลดไฟล์ไปที่:

```text
Pal/Content/Paks/~mods/
```

ตัวอย่าง:

```text
Pal/Content/Paks/~mods/UploadedMod.pak
```

ม็อดบางตัวอาจบอกให้ใช้:

```text
Pal/Content/Paks/LogicMods/
```

### ตรวจสอบไฟล์เสริมถ้ามี

ม็อด `.pak` บางตัวอาจมีไฟล์มากกว่าหนึ่งไฟล์ เช่น ไฟล์เมตาดาต้าหรือไฟล์เสริม หากไฟล์ม็อดมีหลายไฟล์ที่ต้องใช้ ให้อัปโหลดทั้งหมดตามที่ผู้สร้างม็อดระบุ

| ตำแหน่งไฟล์ `.pak` ทั่วไป | กรณีใช้งาน |
| --- | --- |
| `Pal/Content/Paks/~mods/` | ตำแหน่งที่ใช้บ่อยสำหรับม็อด `.pak` ทั่วไป |
| `Pal/Content/Paks/LogicMods/` | ใช้โดยม็อดบางตัวตามคำแนะนำของผู้สร้างม็อด |

## แก้ไขไฟล์คอนฟิกม็อดถ้าม็อดต้องการ

ม็อด Palworld บางตัวมีไฟล์คอนฟิกของตัวเองที่ต้องแก้ไขหลังอัปโหลด การตั้งค่าเหล่านี้ไม่เหมือนกันในทุกม็อด ดังนั้นชื่อไฟล์และค่าที่ต้องแก้ไขขึ้นอยู่กับม็อดที่เลือก

### ไฟล์คอนฟิกอยู่ที่ไหน

ถ้าม็อดมีไฟล์คอนฟิก อาจอยู่ในตำแหน่งเหล่านี้หลังอัปโหลด:

| ประเภทม็อด | ตำแหน่งไฟล์คอนฟิกที่เป็นไปได้ |
| --- | --- |
| ม็อด `UE4SS` / `.lua` | อยู่ในโฟลเดอร์ม็อดที่ `Pal/Binaries/Win64/ue4ss/Mods/[ชื่อม็อดของคุณ]/` |
| ม็อด `.pak` | บางครั้งไม่มีไฟล์คอนฟิกให้แก้ไข ตรวจสอบเอกสารม็อด |
| การรวมคอนฟิกเซิร์ฟเวอร์ | บางกรณีอาจแก้ไขการตั้งค่าเพิ่มเติมผ่าน **Configs** ในแผงควบคุมเซิร์ฟเวอร์ ZAP |

### ควรแก้ไขอะไรบ้าง

คุณควรแก้ไขเฉพาะค่าที่ผู้สร้างม็อดระบุไว้ชัดเจน ตัวอย่างทั่วไปได้แก่:

- เปิดหรือปิดฟีเจอร์ม็อด
- ตั้งค่าตัวคูณหรือตัวจำกัด
- กำหนดพฤติกรรมสำหรับแอดมินเท่านั้น
- เปลี่ยนชื่อคีย์หรือออปชันภายในที่ม็อดใช้

เพราะม็อด Palworld ไม่มีรูปแบบคอนฟิกมาตรฐานเดียว จึงไม่มีรายการคอนฟิกสากลที่ใช้กับทุกม็อด

:::info ไม่มีรายการคอนฟิกม็อด Palworld สากล
ตอนนี้ไม่มีไฟล์คอนฟิกเซิร์ฟเวอร์ Palworld หรือส่วนคอนฟิกในตัวที่เปิดใช้งานม็อดทั้งหมดพร้อมกันได้ ในทางปฏิบัติ การติดตั้งม็อดมักทำโดยการวางไฟล์ในไดเรกทอรีที่ถูกต้อง แล้วแก้ไขไฟล์คอนฟิกเฉพาะม็อดถ้ามี
:::

## รีสตาร์ทเซิร์ฟเวอร์และทดสอบม็อด

หลังจากอัปโหลดไฟล์ม็อดและแก้ไขคอนฟิกที่จำเป็นแล้ว คุณต้องรีสตาร์ทเซิร์ฟเวอร์ Palworld ของคุณ

### รีสตาร์ทเซิร์ฟเวอร์

ใช้ฟังก์ชันรีสตาร์ทในแผงควบคุมเกมเซิร์ฟเวอร์ ZAP-Hosting เพื่อรีสตาร์ทบริการอย่างเต็มที่

ขั้นตอนนี้จำเป็นเพราะ Palworld โดยปกติจะไม่โหลดม็อดเซิร์ฟเวอร์ที่อัปโหลดใหม่จนกว่าเซิร์ฟเวอร์จะเริ่มต้นใหม่

### ทดสอบการทำงาน

หลังรีสตาร์ท:

1. เข้าร่วมเซิร์ฟเวอร์
2. ทดสอบฟีเจอร์ม็อดในเกม
3. ตรวจสอบคอนโซลเซิร์ฟเวอร์หากม็อดไม่ทำงาน
4. ลบไฟล์ม็อดที่เพิ่มล่าสุดถ้าเซิร์ฟเวอร์ไม่สามารถเริ่มต้นหรือทำงานผิดปกติ

:::tip แก้ไขปัญหาม็อดที่ล้มเหลว
ถ้าม็อดทำให้เกิดปัญหา ให้ลบไฟล์จากม็อดที่ติดตั้งล่าสุดก่อน แล้วรีสตาร์ทเซิร์ฟเวอร์อีกครั้ง วิธีนี้เร็วที่สุดในการยืนยันว่าม็อดนั้นเป็นสาเหตุหรือไม่
:::

## Quick reference

| งาน | การดำเนินการ |
| --- | --- |
