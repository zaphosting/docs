## Introduction

*Global Palbox* ใน Palworld ช่วยให้ผู้เล่นสามารถย้าย Pals ระหว่างเซิร์ฟเวอร์ได้โดยใช้ระบบเก็บ Pal บนคลาวด์ทั่วโลก ในคู่มือนี้ คุณจะได้เรียนรู้วิธีเปิดใช้งานการนำเข้าและส่งออก Global Palbox บนเซิร์ฟเวอร์ Palworld ของคุณที่ ZAP-Hosting โดยการแก้ไขไฟล์คอนฟิกที่ถูกต้องด้วยตนเอง



## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่า:

- คุณสามารถเข้าถึงเซิร์ฟเวอร์เกม Palworld ของคุณผ่านเว็บอินเทอร์เฟซของ ZAP-Hosting
- เซิร์ฟเวอร์ของคุณถูกหยุดทำงานอยู่ หรือสามารถรีสตาร์ทได้หลังจากเปลี่ยนแปลง
- คุณสามารถเข้าถึงส่วน `Configs` ในการจัดการเซิร์ฟเวอร์เกมของคุณ

:::info การเข้าถึงไฟล์คอนฟิก
สำหรับเซิร์ฟเวอร์ Palworld ของ ZAP-Hosting การตั้งค่าที่เกี่ยวข้องสามารถแก้ไขได้ผ่านการจัดการเซิร์ฟเวอร์เกมในส่วน `Configs` คุณไม่จำเป็นต้องเข้าถึงไฟล์ภายนอกหากมีตัวแก้ไขคอนฟิกในนั้น
:::

## เปิดไฟล์คอนฟิก Palworld

เพื่อเปิดใช้งานฟีเจอร์ Global Palbox คุณต้องแก้ไขไฟล์ `PalWorldSettings.ini`

### ค้นหาไฟล์คอนฟิกในอินเทอร์เฟซ ZAP

1. เข้าสู่ระบบที่ [เว็บไซต์ ZAP-Hosting](https://zap-hosting.com)
2. เปิดการจัดการเซิร์ฟเวอร์เกม Palworld ของคุณ
3. ไปที่ส่วน `Configs`
4. เปิดไฟล์ชื่อ `PalWorldSettings.ini`

ไฟล์นี้ประกอบด้วยการตั้งค่าเซิร์ฟเวอร์หลักที่ Palworld ใช้งาน รวมถึงตัวเลือก Global Palbox ด้วย

:::note ต้องแก้ไขคอนฟิกด้วยตนเอง
การตั้งค่า Global Palbox ต้องแก้ไขผ่านไฟล์คอนฟิกเซิร์ฟเวอร์โดยตรง หากคุณไม่เห็นสวิตช์แยกสำหรับฟีเจอร์นี้ในอินเทอร์เฟซ การแก้ไขไฟล์ `PalWorldSettings.ini` โดยตรงคือวิธีที่ถูกต้อง
:::

## เปิดใช้งานการนำเข้าและส่งออก Global Palbox

เมื่อเปิดไฟล์ `PalWorldSettings.ini` แล้ว คุณต้องค้นหารายการตัวเลือกเซิร์ฟเวอร์และปรับแต่งค่าของ Global Palbox

### คีย์คอนฟิกที่ต้องตั้งค่า

การตั้งค่าต่อไปนี้ควบคุมพฤติกรรมของ Global Palbox:

| คีย์คอนฟิก | ค่า | ฟังก์ชัน |
| --- | --- | --- |
| `bAllowGlobalPalboxImport` | `True` หรือ `False` | อนุญาตให้ผู้เล่นนำเข้า Pals จาก Global Palbox |
| `bAllowGlobalPalboxExport` | `True` หรือ `False` | อนุญาตให้ผู้เล่นส่งออก Pals ไปยัง Global Palbox |

ตามข้อมูลอ้างอิงจากแหล่งภายนอกปัจจุบัน ค่าเริ่มต้นของ `bAllowGlobalPalboxImport` คือ `False` (ปิดใช้งาน) ขณะที่ `bAllowGlobalPalboxExport` คือ `True` (เปิดใช้งาน) หากไฟล์ของคุณมีค่านี้อยู่แล้ว คุณเพียงแค่ปรับแต่งตามต้องการ

### ตั้งค่าค่า

เพื่อเปิดใช้งานการโอนย้าย Global Palbox ระหว่างเซิร์ฟเวอร์อย่างเต็มที่ ให้ตั้งค่าทั้งสองเป็น `True`

```ini
bAllowGlobalPalboxImport=True
bAllowGlobalPalboxExport=True
```

ถ้าตัวเลือกเหล่านี้มีอยู่แล้วในไฟล์ ให้แทนที่ค่าที่มีอยู่ หากไม่มี ให้เพิ่มเข้าไปในส่วนการตั้งค่าเซิร์ฟเวอร์ในไฟล์ `PalWorldSettings.ini`

:::caution รักษารูปแบบเดิมของไฟล์ไว้
ไฟล์คอนฟิกของ Palworld มีความไวต่อรูปแบบการจัดวางข้อมูล ควรเปลี่ยนแค่ค่าที่จำเป็นและหลีกเลี่ยงการลบเครื่องหมายจุลภาค วงเล็บ หรือรายการอื่น ๆ ที่มีอยู่แล้ว หากตัวเลือกเหล่านี้เป็นส่วนหนึ่งของบรรทัดการตั้งค่าที่ใหญ่กว่าในไฟล์ของคุณ
:::

## บันทึกการเปลี่ยนแปลง

หลังจากแก้ไขไฟล์:

1. บันทึกการเปลี่ยนแปลงในตัวแก้ไขไฟล์ `PalWorldSettings.ini`
2. ตรวจสอบให้แน่ใจว่าค่าทั้งสองของ Global Palbox มีอยู่และตั้งค่าอย่างถูกต้อง

ถ้าแผงควบคุมเซิร์ฟเวอร์ของคุณมีปุ่มบันทึก ให้กดก่อนแล้วค่อยรีสตาร์ทเซิร์ฟเวอร์ในขั้นตอนถัดไป

## รีสตาร์ทเซิร์ฟเวอร์

หลังจากเปลี่ยนแปลงการตั้งค่า Global Palbox คุณต้องรีสตาร์ทเซิร์ฟเวอร์ Palworld เพื่อให้การตั้งค่าใหม่ถูกโหลด

### ใช้การตั้งค่าใหม่

รีสตาร์ทเซิร์ฟเวอร์ของคุณจากการจัดการเซิร์ฟเวอร์เกมหลังจากบันทึกไฟล์แล้ว

| การกระทำ | จำเป็นหรือไม่ |
| --- | --- |
| บันทึกไฟล์ `PalWorldSettings.ini` | ใช่ |
| รีสตาร์ทเซิร์ฟเวอร์ | ใช่ |
| รันคำสั่งคอนโซลเพิ่มเติม | ไม่จำเป็น |

ไม่ต้องใช้คำสั่งเพิ่มเติมหลังจากแก้ไขไฟล์คอนฟิก การรีสตาร์ทเซิร์ฟเวอร์ปกติจะเพียงพอสำหรับการใช้การตั้งค่า Global Palbox ใหม่

:::tip ตรวจสอบฟีเจอร์ในเกม
หลังรีสตาร์ท เข้าร่วมเซิร์ฟเวอร์ของคุณและทดสอบว่าผู้เล่นสามารถนำเข้าและส่งออก Pals ผ่าน Global Palbox ได้หรือไม่ นี่คือวิธีที่ง่ายที่สุดในการยืนยันว่าการตั้งค่าถูกใช้งานสำเร็จ
:::

## Troubleshooting

ถ้า Global Palbox ไม่ทำงานหลังรีสตาร์ท ให้ตรวจสอบจุดต่อไปนี้

### ยืนยันว่าค่าถูกบันทึกอย่างถูกต้อง

เปิดไฟล์ `PalWorldSettings.ini` อีกครั้งและตรวจสอบว่าค่ายังอยู่ดังนี้:

```ini
bAllowGlobalPalboxImport=True
bAllowGlobalPalboxExport=True
```

ถ้าค่ากลับไปเป็นค่าเดิม อาจเป็นไปได้ว่าไฟล์ไม่ได้ถูกบันทึกอย่างถูกต้อง

### ตรวจสอบปัญหารูปแบบไฟล์

ถ้าคุณเพิ่มค่าลงในบล็อกการตั้งค่าที่มีอยู่แล้ว ให้แน่ใจว่ารูปแบบโดยรอบยังถูกต้อง รูปแบบไฟล์ `PalWorldSettings.ini` ที่ผิดพลาดอาจทำให้ Palworld ไม่สนใจการตั้งค่าหรือโหลดไม่สำเร็จ

### รีสตาร์ทเซิร์ฟเวอร์อีกครั้ง

ถ้าคุณบันทึกไฟล์ขณะที่เซิร์ฟเวอร์กำลังทำงาน ให้รีสตาร์ทเซิร์ฟเวอร์อีกครั้งเพื่อให้แน่ใจว่าการตั้งค่าใหม่ถูกนำไปใช้

:::danger ความพร้อมใช้งานของฟีเจอร์ขึ้นกับเวอร์ชันเกม
Global Palbox เป็นฟีเจอร์ของเกมที่ Palworld จัดให้ หากการตั้งค่าไม่ทำงานแม้ว่าคอนฟิกถูกต้อง ฟีเจอร์นี้อาจขึ้นกับเวอร์ชันเซิร์ฟเวอร์ Palworld ปัจจุบันหรือข้อจำกัดชั่วคราวจากฝั่งเกม ในกรณีนั้น ให้ตรวจสอบว่าเซิร์ฟเวอร์ของคุณอัปเดตเป็นเวอร์ชันล่าสุดแล้ว
:::

## Conclusion

ยินดีด้วย คุณได้เปิดใช้งานการนำเข้าและส่งออก Global Palbox บนเซิร์ฟเวอร์ Palworld ของคุณเรียบร้อยแล้ว สำหรับคำถามเพิ่มเติมหรือต้องการความช่วยเหลือ อย่าลังเลที่จะติดต่อทีมซัพพอร์ตของเรา ซึ่งพร้อมให้บริการทุกวันเพื่อช่วยเหลือคุณ! 🙂
