## Introduction

Palworld ให้คุณปรับแต่งว่าผู้เล่นจะสร้างความเสียหายได้มากแค่ไหนและรับความเสียหายได้มากแค่ไหนผ่านค่าการตั้งค่าเซิร์ฟเวอร์ ในคู่มือนี้ คุณจะได้เรียนรู้วิธีแก้ไขไฟล์คอนฟิกที่ถูกต้องในเซิร์ฟเวอร์เกมของคุณที่ ZAP-Hosting ปรับตัวคูณความเสียหายและการป้องกันของผู้เล่น และนำการเปลี่ยนแปลงไปใช้ให้ถูกต้อง



## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่าเซิร์ฟเวอร์ Palworld ของคุณติดตั้งเรียบร้อยแล้วและคุณสามารถเข้าถึงเว็บแอดมินได้

คุณต้องมี:
- เซิร์ฟเวอร์เกม Palworld ที่เปิดใช้งานอยู่กับ ZAP-Hosting
- การเข้าถึงเว็บอินเทอร์เฟซของเซิร์ฟเวอร์เกม
- สิทธิ์ในการแก้ไขไฟล์ภายใต้โฟลเดอร์ `Configs`

:::info การตั้งค่าด้วยตนเองจำเป็น
การตั้งค่านี้ต้องทำด้วยตนเองโดยการแก้ไขไฟล์คอนฟิกของ Palworld ไม่มีคำสั่งในเกมเพิ่มเติมสำหรับการตั้งค่านี้โดยเฉพาะ
:::

## เปิดไฟล์คอนฟิกที่ถูกต้อง

เพื่อเปลี่ยนการโจมตีและการป้องกันของผู้เล่น คุณต้องแก้ไขไฟล์ `PalWorldSettings.ini`

ในแอดมินเซิร์ฟเวอร์เกมของ ZAP-Hosting:
1. เปิดเซิร์ฟเวอร์ Palworld ของคุณ
2. ไปที่ `Configs`
3. เปิดไฟล์ `PalWorldSettings.ini`

ไฟล์นี้มีตัวคูณหลักของเกมเพลย์ที่เซิร์ฟเวอร์เฉพาะใช้ รวมถึงค่าการโจมตีของผู้เล่นและการรับความเสียหายของผู้เล่นด้วย

:::note ตำแหน่งไฟล์คอนฟิก
บริบทของงานยืนยันว่าไฟล์ที่เกี่ยวข้องสามารถเข้าถึงได้ผ่านแอดมินเซิร์ฟเวอร์เกมในเมนู `Configs` หากอินเทอร์เฟซของคุณแตกต่างเล็กน้อย ให้ค้นหารายการไฟล์คอนฟิกของเซิร์ฟเวอร์และเปิดไฟล์ `PalWorldSettings.ini`
:::

## แก้ไขค่าการโจมตีและการป้องกันของผู้เล่น

ในไฟล์ `PalWorldSettings.ini` คุณต้องค้นหารายการคอนฟิกดังนี้

| คีย์คอนฟิก | ฟังก์ชัน | ค่าเริ่มต้น |
| --- | --- | --- |
| `PlayerDamageRateAttack` | ควบคุมว่าผู้เล่นสร้างความเสียหายได้มากแค่ไหน | `1.000000` |
| `PlayerDamageRateDefense` | ควบคุมว่าผู้เล่นรับความเสียหายได้มากแค่ไหน | `1.000000` |

ค่าพวกนี้มักจะอยู่ในบล็อกตัวเลือกหลักของไฟล์

### ตัวอย่างคอนฟิก

ใช้ตัวอย่างนี้เป็นแนวทาง:

```ini
PlayerDamageRateAttack=1.000000
PlayerDamageRateDefense=1.000000
```

ถ้าค่าพวกนี้มีอยู่แล้ว ให้เปลี่ยนแค่ตัวเลขเท่านั้น หากไฟล์ของคุณใช้บรรทัดตัวเลือกยาวบรรทัดเดียว ให้แก้ไขรายการที่มีอยู่ด้วยความระมัดระวังโดยไม่ลบเครื่องหมายจุลภาค วงเล็บ หรือค่าข้างเคียง

### วิธีการทำงานของค่า

| ค่า | ผลลัพธ์ |
| --- | --- |
| ค่า `PlayerDamageRateAttack` สูงขึ้น | ผู้เล่นสร้างความเสียหายได้มากขึ้น |
| ค่า `PlayerDamageRateAttack` ต่ำลง | ผู้เล่นสร้างความเสียหายน้อยลง |
| ค่า `PlayerDamageRateDefense` สูงขึ้น | ผู้เล่นรับความเสียหายน้อยลงตามสมดุลที่เกมตั้งใจไว้ แต่โดยทั่วไปใช้เป็นตัวคูณความเสียหายที่รับ |
| ค่า `PlayerDamageRateDefense` ต่ำลง | ผู้เล่นรับความเสียหายมากขึ้น |

:::caution เข้าใจตัวคูณการป้องกัน
`PlayerDamageRateDefense` มีผลต่อตัวคูณความเสียหายที่ผู้เล่นได้รับ ค่าต่ำหมายถึงผู้เล่นรับความเสียหายมากขึ้น ในขณะที่ค่าสูงจะลดความอันตรายสัมพัทธ์น้อยลงตามพฤติกรรมการปรับสมดุลของเซิร์ฟเวอร์ ควรทดสอบการตั้งค่าหลังจากเปลี่ยนเสมอ
:::

## เลือกค่าตัวคูณที่เหมาะสม

คุณสามารถปรับแต่งการตั้งค่าตามระดับความยากที่ต้องการสำหรับเซิร์ฟเวอร์ของคุณ

### ตัวอย่างสมดุล

ถ้าคุณต้องการประสบการณ์ที่ใกล้เคียงค่าเริ่มต้น ให้ตั้งค่าทั้งสองเป็น `1.000000`:

```ini
PlayerDamageRateAttack=1.000000
PlayerDamageRateDefense=1.000000
```

### ตัวอย่างการต่อสู้ที่ง่ายขึ้น

ถ้าคุณต้องการให้ผู้เล่นสร้างความเสียหายมากขึ้นและรอดชีวิตได้ง่ายขึ้น คุณสามารถเพิ่มค่าการโจมตีและทดสอบสมดุลการป้องกันอย่างระมัดระวัง:

```ini
PlayerDamageRateAttack=1.500000
PlayerDamageRateDefense=1.500000
```

### ตัวอย่างการต่อสู้ที่ยากขึ้น

ถ้าคุณต้องการให้ผู้เล่นสร้างความเสียหายน้อยลงและรับความเสียหายมากขึ้น คุณสามารถลดค่าลงได้:

```ini
PlayerDamageRateAttack=0.800000
PlayerDamageRateDefense=0.800000
```

:::tip ปรับทีละน้อย
เปลี่ยนตัวคูณทีละน้อย เช่น `0.1` หรือ `0.25` เพื่อให้ง่ายต่อการหาสมดุลที่ดีโดยไม่ทำให้การต่อสู้รู้สึกง่ายหรือโหดเกินไป
:::

## บันทึกไฟล์และรีสตาร์ทเซิร์ฟเวอร์

หลังจากแก้ไขไฟล์ `PalWorldSettings.ini` ให้บันทึกไฟล์ในส่วน `Configs` ของ ZAP-Hosting

เมื่อบันทึกไฟล์แล้ว ให้รีสตาร์ทเซิร์ฟเวอร์ Palworld ของคุณเพื่อโหลดการตั้งค่าความเสียหายใหม่

### การดำเนินการที่ต้องทำหลังแก้ไข

| การดำเนินการ | จำเป็นหรือไม่ |
| --- | --- |
| บันทึกไฟล์ `PalWorldSettings.ini` | จำเป็น |
| รีสตาร์ทเซิร์ฟเวอร์ | จำเป็น |
| รันคำสั่งในเกม | ไม่จำเป็น |
| รันคำสั่งคอนโซลด้วยตนเอง | ไม่จำเป็น |

:::info ต้องรีสตาร์ทเซิร์ฟเวอร์
การเปลี่ยนแปลง `PlayerDamageRateAttack` และ `PlayerDamageRateDefense` จะไม่ถูกนำไปใช้จนกว่าเซิร์ฟเวอร์จะถูกรีสตาร์ท
:::

## ตรวจสอบการตั้งค่าใหม่

หลังรีสตาร์ท เข้าร่วมเซิร์ฟเวอร์และทดสอบการต่อสู้โดยตรง

คุณควรตรวจสอบว่า:
- ผู้เล่นสร้างความเสียหายตามที่คาดไว้หรือไม่
- การโจมตีของศัตรูรู้สึกแรงขึ้นหรือน้อยลงหรือไม่
- สมดุลโดยรวมยังเหมาะกับเกมเพลย์ที่คุณตั้งใจไว้หรือไม่

ถ้าผลลัพธ์ไม่เป็นไปตามที่ต้องการ ให้กลับไปที่ไฟล์ `PalWorldSettings.ini` ปรับตัวคูณอีกครั้ง บันทึกไฟล์ และรีสตาร์ทเซิร์ฟเวอร์อีกครั้ง

## Conclusion

ยินดีด้วย คุณได้เปลี่ยนการตั้งค่าการโจมตีและการป้องกันของผู้เล่นในเซิร์ฟเวอร์ Palworld ของคุณเรียบร้อยแล้ว สำหรับคำถามหรือความช่วยเหลือเพิ่มเติม อย่าลังเลที่จะติดต่อทีมซัพพอร์ตของเรา ซึ่งพร้อมให้บริการทุกวันเพื่อช่วยเหลือคุณ! 🙂
