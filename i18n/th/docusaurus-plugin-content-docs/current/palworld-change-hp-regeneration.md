## Introduction

Palworld ให้คุณเปลี่ยนการตั้งค่าการฟื้นฟูสำหรับทั้งผู้เล่นและ Pal ผ่านการตั้งค่าเซิร์ฟเวอร์หลัก ในคู่มือนี้ คุณจะได้เรียนรู้วิธีแก้ไขไฟล์คอนฟิกที่ถูกต้องในเว็บอินเทอร์เฟซของ ZAP-Hosting ปรับค่าอัตราการฟื้นฟู HP และนำการเปลี่ยนแปลงไปใช้ได้อย่างถูกต้อง

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่าเซิร์ฟเวอร์ Palworld ของคุณออนไลน์และคุณสามารถเข้าถึงการจัดการเว็บผ่านแผงควบคุมของ ZAP-Hosting ได้

:::info การเข้าถึงการตั้งค่า
คุณต้องมีสิทธิ์เข้าถึงการจัดการเซิร์ฟเวอร์เกมและส่วน `Configs` เพื่อแก้ไขไฟล์คอนฟิกของ Palworld ด้วยตนเอง
:::

## เปิดไฟล์คอนฟิก Palworld

เพื่อเปลี่ยนอัตราการฟื้นฟู HP คุณต้องแก้ไขไฟล์ `PalWorldSettings.ini`

ในแผงจัดการเซิร์ฟเวอร์เกมของ ZAP-Hosting:

1. เปิดเซิร์ฟเวอร์ Palworld ของคุณ
2. ไปที่เมนู `Configs`
3. เปิดไฟล์ `PalWorldSettings.ini`

ไฟล์นี้เก็บค่าการตั้งค่าหลักของเกมเพลย์บนเซิร์ฟเวอร์ของคุณ รวมถึงตัวคูณการฟื้นฟูสุขภาพของผู้เล่นและ Pal

:::note การแก้ไขคอนฟิกด้วยตนเอง
ขึ้นอยู่กับการตั้งค่าปัจจุบันของคุณ การตั้งค่าอาจอยู่ในบรรทัดพารามิเตอร์ยาวภายในส่วน `OptionSettings` คุณควรแก้ไขค่าเดิมอย่างระมัดระวังและรักษารูปแบบให้เหมือนเดิม
:::

## เปลี่ยนค่าอัตราการฟื้นฟู HP

การตั้งค่าอัตราการฟื้นฟู HP จะเก็บเป็นตัวคูณตัวเลข ค่า `1.0` หมายถึงใช้ความเร็วฟื้นฟูเริ่มต้น

### การตั้งค่าการฟื้นฟูที่รองรับ

ใช้คีย์คอนฟิกต่อไปนี้ในไฟล์ `PalWorldSettings.ini`:

| คีย์คอนฟิก | คำอธิบาย | ค่าเริ่มต้น |
| --- | --- | --- |
| `PlayerAutoHPRegeneRate` | อัตราการฟื้นฟู HP ธรรมชาติของผู้เล่น | `1.0` |
| `PlayerAutoHpRegeneRateInSleep` | อัตราการฟื้นฟู HP ของผู้เล่นขณะนอนหลับ | `1.0` |
| `PalAutoHPRegeneRate` | อัตราการฟื้นฟู HP ธรรมชาติของ Pal | `1.0` |
| `PalAutoHpRegeneRateInSleep` | อัตราการฟื้นฟู HP ของ Pal ขณะนอนใน Palbox | `1.0` |

### พฤติกรรมของค่า

คุณสามารถใช้ตรรกะค่าต่อไปนี้เมื่อเปลี่ยนการฟื้นฟู:

| ค่า | ผลลัพธ์ |
| --- | --- |
| `1.0` | ความเร็วฟื้นฟูเริ่มต้น |
| มากกว่า `1.0` | ฟื้นฟูเร็วขึ้น |
| น้อยกว่า `1.0` | ฟื้นฟูช้าลง |
| `0.0` | ปิดการฟื้นฟู |

:::tip การเลือกค่าอัตราการฟื้นฟูที่เหมาะสม
ถ้าคุณต้องการประสบการณ์การเอาตัวรอดที่ง่ายขึ้นเล็กน้อย ลองใช้ค่าเช่น `1.5` หรือ `2.0` ถ้าต้องการความท้าทายมากขึ้น ให้ใช้ค่าต่ำกว่า `1.0` หรือปิดการฟื้นฟูด้วยค่า `0.0`
:::

## แก้ไขรายการคอนฟิก

ในเซิร์ฟเวอร์ Palworld ส่วนใหญ่ ค่าพวกนี้จะอยู่ในบรรทัด `OptionSettings=(...)` ของไฟล์ `PalWorldSettings.ini`

### ตัวอย่างคอนฟิก

เพิ่มรายการถ้าไม่มี หรือเปลี่ยนค่าที่มีอยู่ถ้ามีแล้ว:

```ini
OptionSettings=(PlayerAutoHPRegeneRate=1.0,PlayerAutoHpRegeneRateInSleep=1.0,PalAutoHPRegeneRate=1.0,PalAutoHpRegeneRateInSleep=1.0)
```

ตัวอย่างเช่น ถ้าคุณต้องการให้ผู้เล่นและ Pal ฟื้นฟูธรรมชาติเพิ่มขึ้น คุณอาจใช้:

```ini
OptionSettings=(PlayerAutoHPRegeneRate=2.0,PlayerAutoHpRegeneRateInSleep=2.0,PalAutoHPRegeneRate=2.0,PalAutoHpRegeneRateInSleep=2.0)
```

ถ้าคุณต้องการเปลี่ยนแค่บางค่า ให้ปรับเฉพาะรายการนั้นๆ และปล่อยค่าอื่นๆ ใน `OptionSettings` เดิมไว้เหมือนเดิม

:::caution รักษาค่าที่มีอยู่ใน OptionSettings
อย่าลบรายการที่ไม่เกี่ยวข้องออกจากบรรทัด `OptionSettings` ส่วนนี้มักจะมีการตั้งค่าเกมเพลย์หลายอย่าง การลบออกอาจทำให้การตั้งค่าอื่นๆ ของเซิร์ฟเวอร์ถูกรีเซ็ตโดยไม่ตั้งใจ
:::

## บันทึกและนำการเปลี่ยนแปลงไปใช้

หลังจากแก้ไขไฟล์แล้ว ให้บันทึกการเปลี่ยนแปลงในส่วน `Configs` ของ ZAP-Hosting

เพื่อให้การตั้งค่าอัตราการฟื้นฟูใหม่มีผล ให้รีสตาร์ทเซิร์ฟเวอร์ Palworld ของคุณ

### รีสตาร์ทเซิร์ฟเวอร์

1. บันทึกไฟล์ `PalWorldSettings.ini` ที่แก้ไขแล้ว
2. กลับไปที่การจัดการเซิร์ฟเวอร์ของคุณ
3. รีสตาร์ทเซิร์ฟเวอร์

การรีสตาร์ทจำเป็นเพราะ Palworld จะอ่านการตั้งค่าเกมเพลย์เหล่านี้ตอนเริ่มต้นเซิร์ฟเวอร์

:::info ต้องรีสตาร์ทเซิร์ฟเวอร์
การเปลี่ยนอัตราการฟื้นฟู HP จะไม่ทำงานทันทีขณะที่เซิร์ฟเวอร์กำลังรันอยู่ คุณต้องรีสตาร์ทเซิร์ฟเวอร์หลังบันทึกการตั้งค่า
:::

## ตรวจสอบการตั้งค่าอัตราการฟื้นฟูใหม่

หลังจากเซิร์ฟเวอร์รีสตาร์ทแล้ว เข้าร่วมเซิร์ฟเวอร์ของคุณและทดสอบพฤติกรรมการฟื้นฟูใหม่ในเกม

คุณสามารถตรวจสอบการเปลี่ยนแปลงได้โดยดูที่:

- การฟื้นฟู HP ธรรมชาติของผู้เล่น
- การฟื้นฟู HP ของผู้เล่นขณะนอนหลับ
- การฟื้นฟู HP ธรรมชาติของ Pal
- พฤติกรรมการฟื้นฟูของ Pal ขณะนอนใน Palbox

ถ้าการฟื้นฟูไม่เป็นไปตามที่คาดไว้ ให้เปิดไฟล์ `PalWorldSettings.ini` อีกครั้งและตรวจสอบว่า:

- คีย์คอนฟิกสะกดถูกต้องเป๊ะ
- ค่าใช้ตัวเลขทศนิยมที่ถูกต้อง เช่น `1.0` หรือ `2.0`
- รายการยังอยู่ในส่วน `OptionSettings`
- เซิร์ฟเวอร์ถูกรีสตาร์ทหลังบันทึกแล้ว
