## Introduction

`EnemyDropItemRate` ควบคุมจำนวนไอเท็มที่ศัตรูดรอปใน Palworld ในคู่มือนี้ คุณจะได้เรียนรู้วิธีแก้ไขไฟล์คอนฟิกที่ถูกต้องด้วยตนเองในแผงควบคุมเซิร์ฟเวอร์เกม ZAP-Hosting ของคุณและตั้งค่าอัตราการดรอปของศัตรูใหม่ได้สำเร็จ

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่าคุณสามารถเข้าถึงแผงควบคุมเซิร์ฟเวอร์เกม Palworld ของคุณและมีสิทธิ์แก้ไขไฟล์คอนฟิกเซิร์ฟเวอร์ได้

:::info ต้องแก้ไขคอนฟิกด้วยตนเอง
การตั้งค่านี้ต้องทำโดยการแก้ไขไฟล์คอนฟิกเซิร์ฟเวอร์ด้วยตนเอง ไฟล์ที่เกี่ยวข้องจะอยู่ในแผงควบคุมเซิร์ฟเวอร์เกม ZAP-Hosting ของคุณภายใต้เมนู `Configs`
:::

## Locate the Configuration File

เพื่อเปลี่ยนอัตราการดรอปของศัตรู คุณต้องแก้ไขไฟล์ `PalWorldSettings.ini`

### Open the Configs Section

ล็อกอินเข้าแผงควบคุมเซิร์ฟเวอร์เกม ZAP-Hosting ของคุณและเปิดเซิร์ฟเวอร์ Palworld จากนั้นไปที่เมนู `Configs` ซึ่งจะแสดงรายการไฟล์คอนฟิกที่มีอยู่

### Select `PalWorldSettings.ini`

เปิดไฟล์ `PalWorldSettings.ini` จากเมนู `Configs` ไฟล์นี้เก็บค่าคอนฟิกหลักของเกมเพลย์สำหรับเซิร์ฟเวอร์เกม Palworld ของคุณ รวมถึงการตั้งค่าเกี่ยวกับไอเท็มและการดรอป

:::note ภาพรวมไฟล์คอนฟิก
บนเซิร์ฟเวอร์เฉพาะ Palworld การตั้งค่าเกมเพลย์มักจะถูกเก็บไว้ในไฟล์ `PalWorldSettings.ini` โดยตัวคูณไอเท็มดรอปของศัตรูจะถูกตั้งค่าผ่านรายการ `EnemyDropItemRate`
:::

## Edit the Enemy Drop Rate

เมื่อคุณเปิดไฟล์ที่ถูกต้องแล้ว คุณสามารถปรับตัวคูณการดรอปไอเท็มได้

### Find the Correct Setting

ค้นหาบรรทัด `OptionSettings` ในไฟล์ `PalWorldSettings.ini` และหาคีย์นี้:

```ini
EnemyDropItemRate=1.000000
```

ถ้าคีย์นี้มีอยู่แล้ว ให้เปลี่ยนค่าตัวเลขเป็นตัวคูณที่คุณต้องการ

### Set Your Desired Multiplier

`EnemyDropItemRate` ใช้ตัวคูณเป็นตัวเลข:

| คีย์คอนฟิก | ค่าเริ่มต้น | ตัวอย่างค่า | ผลลัพธ์ |
| --- | --- | --- | --- |
| `EnemyDropItemRate` | `1.000000` | `2.000000` | ศัตรูดรอปไอเท็มสองเท่า |
| `EnemyDropItemRate` | `1.000000` | `0.500000` | ศัตรูดรอปไอเท็มน้อยลง |
| `EnemyDropItemRate` | `1.000000` | `3.000000` | ศัตรูดรอปไอเท็มสามเท่า |

ตัวอย่างเช่น หากต้องการให้ไอเท็มดรอปจากศัตรูที่ถูกฆ่า Pals ป่า และบอสเพิ่มเป็นสองเท่า ให้ตั้งค่าเป็น:

```ini
EnemyDropItemRate=2.000000
```

ถ้าคุณแก้ไขรายการ `OptionSettings` แบบเต็ม อาจมีลักษณะคล้ายกับตัวอย่างนี้:

```ini
OptionSettings=(EnemyDropItemRate=2.000000)
```

:::caution อย่าแก้ไขค่าตั้งต้นอื่น ๆ
ในหลายการตั้งค่าเซิร์ฟเวอร์ Palworld รายการ `OptionSettings` จะมีค่าหลายตัวในบรรทัดเดียว ให้เปลี่ยนแค่ค่า `EnemyDropItemRate` เท่านั้น หลีกเลี่ยงการลบเครื่องหมายจุลภาค วงเล็บ หรือค่าตั้งต้นอื่น ๆ เพราะอาจทำให้คอนฟิกล้มเหลวได้
:::

## Review Related Drop Limits

ตัวคูณไอเท็มดรอปที่สูงขึ้นอาจทำให้จำนวนไอเท็มที่ดรอปบนพื้นเพิ่มขึ้น ซึ่งอาจส่งผลต่อประสิทธิภาพเซิร์ฟเวอร์ โดยเฉพาะในช่วงการต่อสู้หนักหรือการสู้บอส

### Check `DropItemMaxNum`

ถ้าเซิร์ฟเวอร์ของคุณมีจำนวนไอเท็มดรอปพร้อมกันสูงอยู่แล้ว ให้ตรวจสอบการตั้งค่า `DropItemMaxNum` ในไฟล์คอนฟิกเดียวกัน

| คีย์คอนฟิก | จุดประสงค์ |
| --- | --- |
| `EnemyDropItemRate` | ตัวคูณไอเท็มที่ศัตรูดรอป |
| `DropItemMaxNum` | จำกัดจำนวนไอเท็มดรอปที่อยู่บนพื้นพร้อมกัน |

:::tip สมดุลระหว่างไอเท็มดรอปและประสิทธิภาพ
ถ้าคุณเพิ่มค่า `EnemyDropItemRate` มาก ๆ ควรตั้งค่า `DropItemMaxNum` ให้อยู่ในระดับที่เหมาะสมเพื่อลดความเสี่ยงของการสะสมไอเท็มเกินจำเป็นและปัญหาประสิทธิภาพ
:::

## Save and Apply the Changes

หลังจากแก้ไขไฟล์คอนฟิกแล้ว ให้บันทึกไฟล์ `PalWorldSettings.ini` ในเมนู `Configs`

### Restart the Server

เมื่อบันทึกไฟล์เสร็จแล้ว ให้รีสตาร์ทเซิร์ฟเวอร์ Palworld ของคุณเพื่อให้การตั้งค่าใหม่ถูกโหลด

| การกระทำ | จำเป็นหรือไม่ |
| --- | --- |
| บันทึกไฟล์ `PalWorldSettings.ini` | จำเป็น |
| รีสตาร์ทเซิร์ฟเวอร์ | จำเป็น |
| คำสั่งคอนโซลเพิ่มเติม | ไม่มีคำสั่งที่ยืนยันว่าจำเป็น |

:::info ต้องรีสตาร์ทเซิร์ฟเวอร์
การเปลี่ยนแปลงในไฟล์ `PalWorldSettings.ini` จะไม่ถูกนำไปใช้ทันทีในระหว่างที่เซิร์ฟเวอร์กำลังทำงาน คุณต้องรีสตาร์ทเซิร์ฟเวอร์หลังจากบันทึกไฟล์
:::

## Verify the New Drop Rate

หลังจากรีสตาร์ทเสร็จแล้ว ให้เข้าร่วมเซิร์ฟเวอร์ Palworld ของคุณและฆ่าศัตรูเพื่อตรวจสอบว่าอัตราการดรอปไอเท็มใหม่ทำงานตามที่ตั้งไว้หรือไม่

ถ้าปริมาณไอเท็มดรอปไม่เปลี่ยนแปลง ให้เปิดไฟล์ `PalWorldSettings.ini` อีกครั้งและตรวจสอบว่า:

- คำว่า `EnemyDropItemRate` พิมพ์ถูกต้อง
- ค่าตัวเลขอยู่ในรายการ `OptionSettings` ที่ถูกต้อง
- ไฟล์ถูกบันทึกเรียบร้อยแล้ว
- เซิร์ฟเวอร์ถูกรีสตาร์ทหลังจากแก้ไข

## Conclusion

ยินดีด้วย คุณได้เปลี่ยนอัตราการดรอปของศัตรูบนเซิร์ฟเวอร์ Palworld ของคุณสำเร็จแล้ว หากมีคำถามเพิ่มเติมหรือต้องการความช่วยเหลือ กรุณาติดต่อทีมซัพพอร์ตของเราได้เลย ทีมงานพร้อมให้บริการทุกวัน! 🙂
