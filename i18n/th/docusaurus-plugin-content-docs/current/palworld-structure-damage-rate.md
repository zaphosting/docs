## Introduction

Palworld ให้คุณควบคุมได้ว่าโครงสร้างจะได้รับความเสียหายมากแค่ไหนและเสื่อมสภาพเร็วแค่ไหนตามเวลา ในคู่มือนี้ คุณจะได้เรียนรู้วิธีแก้ไขไฟล์การตั้งค่าที่ถูกต้องในแผงควบคุมเซิร์ฟเวอร์เกม ZAP-Hosting ของคุณและนำการตั้งค่าอัตราความเสียหายโครงสร้างใหม่ไปใช้



## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่าเซิร์ฟเวอร์ Palworld ของคุณติดตั้งเรียบร้อยแล้วและคุณสามารถเข้าถึงการจัดการผ่านเว็บได้

:::info สิทธิ์การเข้าถึงที่จำเป็น
คุณต้องมีสิทธิ์เข้าถึงแผงควบคุมเซิร์ฟเวอร์เกม ZAP-Hosting และส่วน `Configs` ของเซิร์ฟเวอร์ Palworld ของคุณ
:::

:::note การตั้งค่าด้วยตนเอง
การตั้งค่านี้ทำโดยการแก้ไขไฟล์การตั้งค่า Palworld ด้วยตนเอง การตั้งค่าที่ถูกต้องจะไม่ถูกเปลี่ยนผ่านปุ่มเปิด-ปิดแบบคลิกเดียวในคู่มือนี้
:::

## เปิดไฟล์การตั้งค่าที่ถูกต้อง

เพื่อเปลี่ยนอัตราความเสียหายและการเสื่อมสภาพของโครงสร้าง คุณต้องแก้ไขไฟล์ `PalWorldSettings.ini`

ในแผงควบคุมเซิร์ฟเวอร์เกม ZAP-Hosting ของคุณ:

1. เปิดเซิร์ฟเวอร์ **Palworld** ของคุณ
2. ไปที่เมนู **Configs**
3. เปิดไฟล์ `PalWorldSettings.ini`

ไฟล์นี้เก็บค่าการตั้งค่าหลักของเกมเพลย์สำหรับเซิร์ฟเวอร์ของคุณ รวมถึงตัวคูณที่เกี่ยวข้องกับโครงสร้าง

## แก้ไขการตั้งค่าอัตราความเสียหายของโครงสร้าง

ค่าที่เกี่ยวข้องจะถูกเก็บไว้ในรายการตั้งค่าเซิร์ฟเวอร์ภายในไฟล์ `PalWorldSettings.ini`

### คีย์การตั้งค่าที่เกี่ยวข้อง

ใช้การตั้งค่าต่อไปนี้เพื่อควบคุมพฤติกรรมความเสียหายของโครงสร้าง:

| คีย์การตั้งค่า | คำอธิบาย | ค่าเริ่มต้น |
| --- | --- | --- |
| `BuildObjectDamageRate` | ควบคุมว่าระบบจะทำความเสียหายกับโครงสร้างมากแค่ไหน | `1.0` |
| `BuildObjectDeteriorationDamageRate` | ควบคุมความเร็วในการเสื่อมสภาพของโครงสร้างตามเวลา | `1.0` |

ค่า `1.0` คืออัตราปกติ ค่าเลขต่ำกว่าจะลดผลกระทบ ในขณะที่ค่าสูงกว่าจะเพิ่มผลกระทบ

### ตัวอย่างการตั้งค่า

ขึ้นอยู่กับเนื้อหาไฟล์ปัจจุบัน ค่าพวกนี้มักจะเป็นส่วนหนึ่งของรายการตัวเลือกเซิร์ฟเวอร์ใน `PalWorldSettings.ini`

```ini
BuildObjectDamageRate=1.0
BuildObjectDeteriorationDamageRate=1.0
```

ถ้าการตั้งค่าของคุณใช้สตริงตัวเลือกแบบรวม ให้แน่ใจว่าแก้ไขเฉพาะค่าตัวเลขและเก็บไวยากรณ์รอบๆ ไว้เหมือนเดิม

ตัวอย่างเช่น:

```ini
OptionSettings=(BuildObjectDamageRate=1.0,BuildObjectDeteriorationDamageRate=1.0)
```

:::caution อย่าลบหรือแก้ไขไวยากรณ์เดิม
ไฟล์ `PalWorldSettings.ini` อาจมีการตั้งค่าหลายรายการในบรรทัด `OptionSettings=(...)` เดียวกัน หากเป็นกรณีนี้ในเซิร์ฟเวอร์ของคุณ อย่าลบเครื่องหมายจุลภาค วงเล็บ หรือรายการอื่นๆ ที่มีอยู่เมื่อแก้ไขไฟล์
:::

## เลือกค่าที่เหมาะสม

คุณสามารถปรับตัวคูณตามความทนทานที่ต้องการให้โครงสร้างที่ผู้เล่นสร้างขึ้นมี

### ตัวคูณความเสียหายของโครงสร้าง

`BuildObjectDamageRate` เปลี่ยนแปลงความเสียหายโดยตรงที่โครงสร้างได้รับ

| ค่า | ผลลัพธ์ |
| --- | --- |
| `0.5` | โครงสร้างได้รับความเสียหายครึ่งหนึ่ง |
| `1.0` | ความเสียหายโครงสร้างปกติ |
| `2.0` | โครงสร้างได้รับความเสียหายสองเท่า |

### ตัวคูณการเสื่อมสภาพของโครงสร้าง

`BuildObjectDeteriorationDamageRate` เปลี่ยนความเร็วในการเสื่อมสภาพของโครงสร้างตามเวลา

| ค่า | ผลลัพธ์ |
| --- | --- |
| `0.1` | เสื่อมสภาพช้ามาก |
| `1.0` | ความเร็วเสื่อมสภาพปกติ |
| `2.0` | เสื่อมสภาพเร็วขึ้น |

:::tip แนะนำค่าขั้นต่ำของการเสื่อมสภาพ
แนะนำให้ตั้งค่า `BuildObjectDeteriorationDamageRate` ไว้ที่ `0.1` หรือสูงกว่า การตั้งค่าต่ำมากหรือปิดการเสื่อมสภาพอาจทำให้โครงสร้างที่ไม่ได้ใช้ยังคงอยู่เป็นเวลานาน ซึ่งอาจส่งผลเสียต่อการทำความสะอาดและประสิทธิภาพเซิร์ฟเวอร์ในระยะยาว
:::

## บันทึกไฟล์และรีสตาร์ทเซิร์ฟเวอร์

หลังจากแก้ไขค่าใน `PalWorldSettings.ini` ให้บันทึกไฟล์ในส่วน `Configs`

จากนั้นคุณต้องรีสตาร์ทเซิร์ฟเวอร์ Palworld เพื่อให้การตั้งค่าอัตราความเสียหายโครงสร้างใหม่ถูกโหลด

### การดำเนินการที่ต้องทำหลังแก้ไข

| การดำเนินการ | จำเป็นหรือไม่ |
| --- | --- |
| บันทึกไฟล์ `PalWorldSettings.ini` | จำเป็น |
| รีสตาร์ทเซิร์ฟเวอร์ | จำเป็น |
| คำสั่งคอนโซลเพิ่มเติม | ไม่มีคำสั่งที่ยืนยันว่าจำเป็น |

:::info ต้องรีสตาร์ทเซิร์ฟเวอร์
การเปลี่ยนแปลง `BuildObjectDamageRate` และ `BuildObjectDeteriorationDamageRate` จะไม่ถูกนำไปใช้จนกว่าเซิร์ฟเวอร์จะถูกรีสตาร์ท
:::

## ตรวจสอบการเปลี่ยนแปลง

เมื่อเซิร์ฟเวอร์กลับมาออนไลน์แล้ว ให้เข้าร่วมเซิร์ฟเวอร์ Palworld ของคุณและทดสอบพฤติกรรมใหม่

คุณสามารถตรวจสอบการเปลี่ยนแปลงได้โดยดูว่า:

- โครงสร้างได้รับความเสียหายโดยตรงมากหรือน้อยกว่าก่อนหน้านี้หรือไม่
- โครงสร้างที่ถูกทิ้งร้างหรือเปิดเผยเสื่อมสภาพตามอัตราที่คาดไว้หรือไม่

ถ้าการเปลี่ยนแปลงไม่ถูกนำไปใช้ ให้เปิดไฟล์ `PalWorldSettings.ini` อีกครั้งและตรวจสอบว่า:

- ชื่อการตั้งค่าถูกเขียนอย่างถูกต้องเป็น `BuildObjectDamageRate` และ `BuildObjectDeteriorationDamageRate`
- ค่าถูกวางในส่วนหรือบรรทัด `OptionSettings` ที่ถูกต้อง
- เซิร์ฟเวอร์ถูกรีสตาร์ทหลังจากบันทึกไฟล์แล้ว
