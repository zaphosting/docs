## Introduction

Palworld ให้คุณควบคุมจำนวนทรัพยากรที่ผู้เล่นเก็บได้และความเร็วในการเกิดใหม่ของวัตถุที่เก็บได้ ในคู่มือนี้ คุณจะได้เรียนรู้วิธีแก้ไขไฟล์คอนฟิกที่ถูกต้องในเซิร์ฟเวอร์เกม Palworld ของคุณบน ZAP-Hosting เพื่อเปลี่ยนอัตราการดรอปของการเก็บของและการตั้งค่าทรัพยากรที่เกี่ยวข้อง



## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่าคุณสามารถเข้าถึงเซิร์ฟเวอร์เกม Palworld ของคุณผ่านเว็บอินเทอร์เฟซ ZAP-Hosting และเซิร์ฟเวอร์อยู่ในสถานะออฟไลน์หรือสามารถรีสตาร์ทได้หลังจากทำการเปลี่ยนแปลง

:::info การเข้าถึงไฟล์คอนฟิก
สำหรับ Palworld การตั้งค่าเกมเพลย์ที่เกี่ยวข้องจะถูกเก็บไว้ในไฟล์ `PalWorldSettings.ini` ในการจัดการเซิร์ฟเวอร์เกมของ ZAP-Hosting คุณสามารถเข้าถึงไฟล์นี้ได้ผ่านส่วน `Configs`
:::

## เปิดไฟล์คอนฟิก Palworld

เพื่อเปลี่ยนการตั้งค่าการเก็บของ คุณต้องแก้ไขไฟล์คอนฟิกหลักของเซิร์ฟเวอร์ Palworld

### ค้นหาไฟล์ในอินเทอร์เฟซ ZAP-Hosting

1. เข้าสู่ระบบที่ [เว็บอินเทอร์เฟซ ZAP-Hosting](https://zap-hosting.com)
2. เปิดเซิร์ฟเวอร์เกม Palworld ของคุณ
3. ไปที่ส่วน `Configs` ในการจัดการเซิร์ฟเวอร์
4. เปิดไฟล์ชื่อ `PalWorldSettings.ini`

:::note ไฟล์ที่ถูกต้อง
การตั้งค่าที่เกี่ยวข้องกับการเก็บของตามที่อธิบายในคู่มือนี้จะถูกเก็บไว้ใน `PalWorldSettings.ini` หากคุณไม่เห็นรายการที่คาดหวังทันที โดยปกติจะอยู่ภายในบรรทัดคอนฟิก `OptionSettings`
:::

## แก้ไขการตั้งค่าการเก็บของ

Palworld เก็บตัวเลือกเกมเพลย์หลายอย่างในรูปแบบคู่คีย์-ค่า ภายในส่วน `OptionSettings` ของไฟล์ `PalWorldSettings.ini` เพื่อเพิ่มทรัพยากรที่เก็บได้หรือเปลี่ยนความเร็วในการเกิดใหม่ของโหนดทรัพยากร คุณต้องปรับค่าที่เกี่ยวข้องในส่วนนี้

### คีย์คอนฟิกที่เกี่ยวข้อง

ใช้การตั้งค่าต่อไปนี้สำหรับพฤติกรรมที่เกี่ยวกับการเก็บของ:

| คีย์คอนฟิก | ค่าเริ่มต้น | คำอธิบาย |
| --- | --- | --- |
| `CollectionDropRate` | `1.000000` | ควบคุมจำนวนไอเท็มที่ผู้เล่นได้รับจากทรัพยากรที่เก็บได้ ค่าเพิ่มจะเพิ่มจำนวนที่เก็บได้ |
| `CollectionObjectRespawnSpeedRate` | `1.000000` | ควบคุมความเร็วในการเกิดใหม่ของวัตถุที่เก็บได้ ค่าเพิ่มจะทำให้ทรัพยากรเกิดใหม่เร็วขึ้น |
| `CollectionObjectHpRate` | `1.000000` | ควบคุมพลังชีวิตของวัตถุที่เก็บได้ เช่น หินหรือไม้ ค่าเพิ่มจะทำให้วัตถุใช้เวลาทำลายนานขึ้น |

### ตัวอย่างค่าคอนฟิก

ถ้าคุณต้องการเพิ่มทรัพยากรที่เก็บได้เป็นสองเท่าและทำให้โหนดทรัพยากรเกิดใหม่เร็วขึ้นสองเท่า ให้ตั้งค่าทั้งสองเป็น `2.000000`

```ini
CollectionDropRate=2.000000
CollectionObjectRespawnSpeedRate=2.000000
```

ถ้าคุณต้องการให้วัตถุที่เก็บได้แตกง่ายขึ้น คุณสามารถลดตัวคูณพลังชีวิตได้ดังนี้:

```ini
CollectionObjectHpRate=0.500000
```

:::tip ค่าที่แนะนำสำหรับเริ่มต้น
ค่า `2.000000` เป็นจุดเริ่มต้นที่นิยมสำหรับทั้ง `CollectionDropRate` และ `CollectionObjectRespawnSpeedRate` ซึ่งช่วยให้การเล่นเกมเร็วขึ้นอย่างเห็นได้ชัดโดยไม่เปลี่ยนแปลงเกม Palworld อย่างรุนแรงเกินไป
:::

## ใช้การเปลี่ยนแปลงใน `PalWorldSettings.ini`

หลังจากเปิดไฟล์ `PalWorldSettings.ini` ให้ค้นหาบรรทัด `OptionSettings` ที่มีอยู่แล้วและปรับคีย์ที่เกี่ยวข้องภายในบรรทัดนั้นโดยตรง

### ตัวอย่างส่วน `OptionSettings`

ขึ้นอยู่กับการตั้งค่าเซิร์ฟเวอร์ปัจจุบันของคุณ บรรทัดนี้อาจมีการตั้งค่าหลายอย่างอยู่แล้ว คุณเพียงแค่เปลี่ยนค่าของคีย์ที่เกี่ยวกับการเก็บของถ้ามีอยู่ หรือเพิ่มเข้าไปถ้ายังไม่มี

```ini
OptionSettings=(Difficulty=None,DayTimeSpeedRate=1.000000,NightTimeSpeedRate=1.000000,ExpRate=1.000000,PalCaptureRate=1.000000,PalSpawnNumRate=1.000000,PalDamageRateAttack=1.000000,PalDamageRateDefense=1.000000,PlayerDamageRateAttack=1.000000,PlayerDamageRateDefense=1.000000,PlayerStomachDecreaceRate=1.000000,PlayerStaminaDecreaceRate=1.000000,PlayerAutoHPRegeneRate=1.000000,PlayerAutoHpRegeneRateInSleep=1.000000,PalStomachDecreaceRate=1.000000,PalStaminaDecreaceRate=1.000000,PalAutoHPRegeneRate=1.000000,PalAutoHpRegeneRateInSleep=1.000000,BuildObjectDamageRate=1.000000,BuildObjectDeteriorationDamageRate=1.000000,CollectionDropRate=2.000000,CollectionObjectHpRate=1.000000,CollectionObjectRespawnSpeedRate=2.000000,EnemyDropItemRate=1.000000)
```

:::caution รักษารูปแบบเดิมไว้
โปรดอย่าลบเครื่องหมายจุลภาค วงเล็บ หรือการตั้งค่าอื่น ๆ ในบรรทัด `OptionSettings` โดยไม่ได้ตั้งใจ เพราะอาจทำให้เซิร์ฟเวอร์โหลดคอนฟิกไม่ถูกต้อง
:::

## บันทึกและรีสตาร์ทเซิร์ฟเวอร์

เมื่อแก้ไขไฟล์เสร็จแล้ว ให้บันทึกการเปลี่ยนแปลงในส่วน `Configs`

### ความจำเป็นในการรีสตาร์ท

Palworld จะไม่ใช้การเปลี่ยนแปลงการตั้งค่าเกมเพลย์เหล่านี้ทันทีขณะที่เซิร์ฟเวอร์กำลังทำงาน คุณต้องรีสตาร์ทเซิร์ฟเวอร์หลังบันทึกไฟล์เพื่อให้ค่าใหม่ถูกโหลด

| การกระทำ | จำเป็นหรือไม่ |
| --- | --- |
| บันทึกไฟล์ `PalWorldSettings.ini` | จำเป็น |
| รีสตาร์ทเซิร์ฟเวอร์ | จำเป็น |
| คำสั่งคอนโซลเพิ่มเติม | ไม่มีคำสั่งที่ยืนยันว่าจำเป็น |

:::info ต้องรีสตาร์ทเซิร์ฟเวอร์
จำเป็นต้องรีสตาร์ทเซิร์ฟเวอร์เต็มรูปแบบหลังจากเปลี่ยนค่า `CollectionDropRate`, `CollectionObjectRespawnSpeedRate` หรือ `CollectionObjectHpRate` ไม่มีคำสั่งในเกมหรือคอนโซลเพิ่มเติมที่จำเป็นสำหรับการตั้งค่าเหล่านี้
:::

## ตรวจสอบพฤติกรรมการเก็บของใหม่

หลังจากรีสตาร์ทเสร็จแล้ว ให้เข้าร่วมเซิร์ฟเวอร์และทดสอบวัตถุที่เก็บได้ เช่น ต้นไม้ หิน หรือโหนดแร่

### สิ่งที่ควรตรวจสอบ

- ผู้เล่นได้รับวัสดุมากขึ้นต่อการเก็บหนึ่งครั้งหรือไม่
- โหนดทรัพยากรที่ถูกทำลายเกิดใหม่เร็วขึ้นหรือไม่
- วัตถุที่เก็บได้รู้สึกแตกง่ายหรือยากขึ้นถ้าคุณเปลี่ยนค่า `CollectionObjectHpRate`

ถ้าผลลัพธ์แรงเกินไปหรือน้อยเกินไป ให้กลับไปแก้ไขค่าใน `PalWorldSettings.ini` อีกครั้ง

:::tip ปรับแต่งเซิร์ฟเวอร์ของคุณ
ถ้าคุณต้องการการตั้งค่าการเก็บของใน Palworld ที่สมดุลมากขึ้น ให้เพิ่มค่าทีละน้อย เช่น จาก `1.000000` เป็น `1.500000` ก่อนจะเพิ่มเป็นตัวคูณที่สูงขึ้น
:::

## อ้างอิงการตั้งค่า

ตารางต่อไปนี้สรุปค่าที่สำคัญที่สุดสำหรับการตั้งค่าการเก็บของใน Palworld นี้

| การตั้งค่า | ตัวอย่าง | ผลลัพธ์ |
| --- | --- | --- |
| `CollectionDropRate=1.000000` | ค่าเริ่มต้น | จำนวนทรัพยากรที่เก็บได้ตามปกติ |
| `CollectionDropRate=2.000000` | เพิ่มขึ้น | ทรัพยากรที่เก็บได้เพิ่มเป็นสองเท่า |
| `CollectionObjectRespawnSpeedRate=1.000000` | ค่าเริ่มต้น | ความเร็วการเกิดใหม่ตามปกติ |
| `CollectionObjectRespawnSpeedRate=2.000000` | เพิ่มขึ้น | การเกิดใหม่ของทรัพยากรเร็วขึ้น |
| `CollectionObjectHpRate=1.000000` | ค่าเริ่มต้น | พลังชีวิตของวัตถุที่เก็บได้ตามปกติ |
| `CollectionObjectHpRate=0.500000` | ลดลง | วัตถุที่เก็บได้แตกง่ายขึ้น |

## Conclusion

ยินดีด้วย คุณได้เปลี่ยนอัตราการดรอปของการเก็บของในเซิร์ฟเวอร์ Palworld ของคุณเรียบร้อยแล้ว หากมีคำถามเพิ่มเติมหรือต้องการความช่วยเหลือ โปรดอย่าลังเลที่จะติดต่อทีมซัพพอร์ตของเรา ซึ่งพร้อมให้บริการทุกวันเพื่อช่วยเหลือคุณ! 🙂
