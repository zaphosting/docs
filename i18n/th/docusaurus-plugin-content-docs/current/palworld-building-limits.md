## Introduction

Palworld ให้คุณควบคุมขีดจำกัดและข้อจำกัดการสร้างหลายอย่างผ่านการตั้งค่าเซิร์ฟเวอร์ ในคู่มือนี้ คุณจะได้เรียนรู้วิธีแก้ไขไฟล์คอนฟิกที่ถูกต้องในแผงควบคุม ZAP-Hosting ด้วยตนเอง เปลี่ยนค่าการสร้างที่เกี่ยวข้อง และนำการเปลี่ยนแปลงไปใช้ได้อย่างถูกต้อง

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่า:

- คุณมีสิทธิ์เข้าถึงเซิร์ฟเวอร์เกม Palworld ของคุณในระบบจัดการเซิร์ฟเวอร์เกมของ ZAP-Hosting
- เซิร์ฟเวอร์ของคุณกำลังออฟไลน์ หรือคุณพร้อมที่จะรีสตาร์ทเซิร์ฟเวอร์หลังจากทำการเปลี่ยนแปลง
- คุณทราบว่าคู่มือนี้ครอบคลุมขีดจำกัดการสร้างทั่วไปและข้อจำกัดพื้นที่ ไม่ใช่ขีดจำกัดฐานเฉพาะของกิลด์

:::info ต้องแก้ไขคอนฟิกด้วยตนเอง
การตั้งค่าเหล่านี้ต้องแก้ไขด้วยตนเองในไฟล์คอนฟิก ไฟล์ที่เกี่ยวข้องสามารถเข้าถึงได้ในระบบจัดการเซิร์ฟเวอร์เกมของ ZAP-Hosting ภายใต้เมนู `Configs`
:::

:::note ขีดจำกัดฐานกิลด์
หากคุณต้องการเปลี่ยนจำนวนฐานต่อกิลด์แทนขีดจำกัดการสร้างทั่วไปที่กล่าวถึงในที่นี้ ควรใช้คู่มือขีดจำกัดฐานกิลด์แยกต่างหากหากมีใน ZAP-Docs
:::

## เปิดไฟล์คอนฟิก

เพื่อเปลี่ยนขีดจำกัดการสร้าง คุณต้องแก้ไขไฟล์ `PalWorldSettings.ini`

ในระบบจัดการเซิร์ฟเวอร์เกมของ ZAP-Hosting:

1. เปิดเซิร์ฟเวอร์ Palworld ของคุณ
2. ไปที่เมนู `Configs`
3. เปิดไฟล์ `PalWorldSettings.ini`

ไฟล์นี้ประกอบด้วยการตั้งค่าหลักของโลกและการเล่นเกมสำหรับเซิร์ฟเวอร์ Palworld ของคุณ รวมถึงรายการคอนฟิกที่เกี่ยวข้องกับการสร้างหลายรายการ

## แก้ไขการตั้งค่าขีดจำกัดการสร้าง

ค่าที่เกี่ยวข้องจะถูกเก็บไว้ในส่วน `OptionSettings` ของไฟล์ `PalWorldSettings.ini`

### คีย์คอนฟิกที่เกี่ยวข้อง

ใช้การตั้งค่าต่อไปนี้เพื่อควบคุมขีดจำกัดการสร้างและข้อจำกัดพื้นที่:

| คีย์คอนฟิก | คำอธิบาย | ตัวอย่างค่า |
| --- | --- | --- |
| `MaxBuildingLimitNum` | กำหนดจำนวนอาคารสูงสุดต่อผู้เล่น `0` หมายถึงปิดการจำกัด | `0` |
| `BaseCampMaxNum` | กำหนดจำนวนฐานค่ายสูงสุดที่อนุญาตบนเซิร์ฟเวอร์ทั้งหมด | `128` |
| `bBuildAreaLimit` | ควบคุมว่าจำกัดการสร้างใกล้โครงสร้างบางอย่างหรือไม่ | `False` |

### ตัวอย่างคอนฟิก

ขึ้นอยู่กับเนื้อหาไฟล์ปัจจุบัน ค่าพวกนี้มักจะเป็นส่วนหนึ่งของบรรทัด `OptionSettings=(...)`

```ini
OptionSettings=(MaxBuildingLimitNum=0,BaseCampMaxNum=128,bBuildAreaLimit=False)
```

ถ้าไฟล์ของคุณมีบรรทัด `OptionSettings` ที่ยาวกว่า อย่าลบค่าที่มีอยู่แล้ว คุณเพียงแค่ต้องเปลี่ยนหรือเพิ่มรายการที่เกี่ยวข้องภายในบล็อกการตั้งค่านั้นเท่านั้น

### ความหมายของแต่ละค่า

| การตั้งค่า | ผลลัพธ์ |
| --- | --- |
| `MaxBuildingLimitNum=0` | ยกเลิกขีดจำกัดการสร้างต่อผู้เล่น |
| `MaxBuildingLimitNum=[your_number]` | จำกัดจำนวนอาคารต่อผู้เล่นตามค่าที่ระบุ |
| `BaseCampMaxNum=[your_number]` | กำหนดจำนวนฐานค่ายรวมที่อนุญาตบนเซิร์ฟเวอร์ |
| `bBuildAreaLimit=True` | ป้องกันการสร้างใกล้โครงสร้างที่ถูกจำกัด เช่น จุดเดินทางด่วน |
| `bBuildAreaLimit=False` | ปิดข้อจำกัดพื้นที่นั้น |

:::caution รักษารูปแบบเดิมไว้
ไฟล์ `PalWorldSettings.ini` มีความไวต่อรูปแบบการเขียน ให้แน่ใจว่าคุณเปลี่ยนแค่ค่าที่ต้องการและรักษาเครื่องหมายจุลภาค วงเล็บ และโครงสร้าง `OptionSettings=(...)` ไว้เหมือนเดิม
:::

## บันทึกการเปลี่ยนแปลง

หลังจากแก้ไขค่าแล้ว:

1. บันทึกไฟล์ในเมนู `Configs`
2. ตรวจสอบบรรทัดอีกครั้งเพื่อหาข้อผิดพลาดด้านรูปแบบ

ถ้ารูปแบบไม่ถูกต้อง เซิร์ฟเวอร์อาจไม่สนใจการตั้งค่าที่เปลี่ยนแปลงหรือไม่สามารถนำไปใช้ได้อย่างถูกต้อง

### ตัวอย่างค่าที่กำหนดเอง

นี่คือตัวอย่างที่จำกัดผู้เล่นแต่ละคนให้สร้างได้สูงสุด `5000` อาคาร อนุญาตฐานค่ายสูงสุด `20` แห่งบนเซิร์ฟเวอร์ และเปิดใช้งานข้อจำกัดพื้นที่สร้าง:

```ini
OptionSettings=(MaxBuildingLimitNum=5000,BaseCampMaxNum=20,bBuildAreaLimit=True)
```

นี่คือตัวอย่างอีกแบบที่ยกเลิกขีดจำกัดการสร้างของผู้เล่นและปิดข้อจำกัดพื้นที่:

```ini
OptionSettings=(MaxBuildingLimitNum=0,BaseCampMaxNum=20,bBuildAreaLimit=False)
```

## รีสตาร์ทเซิร์ฟเวอร์

หลังจากบันทึกการตั้งค่าแล้ว คุณต้องรีสตาร์ทเซิร์ฟเวอร์ Palworld ของคุณเพื่อให้การตั้งค่าใหม่ถูกโหลด

ในระบบจัดการเซิร์ฟเวอร์เกมของ ZAP-Hosting:

1. หยุดเซิร์ฟเวอร์ถ้ายังทำงานอยู่
2. เริ่มเซิร์ฟเวอร์อีกครั้ง

จำเป็นต้องรีสตาร์ทเต็มรูปแบบเพื่อให้การเปลี่ยนแปลงใน `PalWorldSettings.ini` มีผล

:::tip ใช้การเปลี่ยนแปลงอย่างมั่นใจ
ถ้าคุณแก้ไขคอนฟิกหลายอย่างพร้อมกัน ควรบันทึกการแก้ไขทั้งหมดก่อน แล้วค่อยรีสตาร์ทเซิร์ฟเวอร์ทีเดียว เพื่อหลีกเลี่ยงเวลาหยุดทำงานที่ไม่จำเป็น
:::

## ตรวจสอบขีดจำกัดใหม่

เมื่อเซิร์ฟเวอร์ออนไลน์อีกครั้ง ให้เข้าร่วมเซิร์ฟเวอร์และทดสอบพฤติกรรมการสร้างใหม่

คุณควรตรวจสอบว่า:

- ผู้เล่นสามารถวางโครงสร้างได้มากหรือน้อยกว่าก่อนหรือไม่
- จำนวนฐานค่ายรวมตรงกับค่าที่ตั้งไว้หรือไม่
- การสร้างใกล้โครงสร้างที่ถูกจำกัดได้รับอนุญาตหรือถูกบล็อกตามค่า `bBuildAreaLimit`

ถ้าการเปลี่ยนแปลงไม่แสดงผล ให้เปิดไฟล์ `PalWorldSettings.ini` อีกครั้งและตรวจสอบว่า:

- ค่าถูกบันทึกอย่างถูกต้อง
- คีย์อยู่ภายในบล็อก `OptionSettings`
- เซิร์ฟเวอร์ถูกรีสตาร์ทเต็มที่หลังแก้ไข

## อ้างอิงการตั้งค่า

| ไฟล์ | ตำแหน่งใน ZAP-Hosting | การดำเนินการหลังแก้ไข |
| --- | --- | --- |
| `PalWorldSettings.ini` | เมนู `Configs` ในระบบจัดการเซิร์ฟเวอร์เกม | รีสตาร์ทเซิร์ฟเวอร์ |

| การตั้งค่า | การใช้งานแนะนำ |
| --- | --- |
| `MaxBuildingLimitNum` | ใช้ควบคุมขีดจำกัดการสร้างต่อผู้เล่น |
| `BaseCampMaxNum` | ใช้ควบคุมจำนวนฐานค่ายรวมบนเซิร์ฟเวอร์ |
| `bBuildAreaLimit` | ใช้อนุญาตหรือจำกัดการสร้างใกล้โครงสร้างที่ได้รับการปกป้อง |

## Conclusion
