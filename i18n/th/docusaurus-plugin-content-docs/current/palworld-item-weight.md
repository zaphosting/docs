## Introduction

Palworld ให้คุณปรับน้ำหนักไอเทมบนเซิร์ฟเวอร์ของคุณได้โดยการเปลี่ยนค่าคอนฟิกในไฟล์ตั้งค่าเซิร์ฟเวอร์หลัก ในคู่มือนี้ คุณจะได้เรียนรู้ว่าจะหาไฟล์ที่ถูกต้องในเว็บอินเทอร์เฟซของ ZAP-Hosting ได้ที่ไหน, การตั้งค่า `item weight` ที่ต้องแก้ไข และวิธีใช้การเปลี่ยนแปลงอย่างถูกต้อง



## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่าเซิร์ฟเวอร์เกม Palworld ของคุณออนไลน์และคุณสามารถเข้าถึงแผงควบคุมเว็บของมันได้

:::info สิทธิ์การเข้าถึงที่จำเป็น
คุณต้องมีสิทธิ์เข้าถึงแผงควบคุมเซิร์ฟเวอร์ Palworld ของคุณในเว็บอินเทอร์เฟซ ZAP-Hosting เพื่อแก้ไขไฟล์คอนฟิกภายใต้เมนู **Configs**
:::

## เปิดไฟล์คอนฟิก Palworld

เพื่อเปลี่ยนตัวคูณน้ำหนักไอเทม คุณต้องแก้ไขไฟล์ `PalWorldSettings.ini`

ในแผงควบคุมเซิร์ฟเวอร์เกมของ ZAP-Hosting:

1. เปิดเซิร์ฟเวอร์ Palworld ของคุณ
2. ไปที่ **Configs**
3. เปิดไฟล์ `PalWorldSettings.ini`

ไฟล์นี้เก็บค่าคอนฟิกหลักของเกมเพลย์ที่เซิร์ฟเวอร์ Palworld ของคุณใช้

:::note จุดประสงค์ของไฟล์คอนฟิก
`PalWorldSettings.ini` เก็บตัวปรับแต่งเกมเพลย์หลายอย่าง รวมถึงอัตราความเสียหาย, ความอึด, การดรอป และ `item weight`
:::

## แก้ไขการตั้งค่า Item Weight

ในไฟล์ `PalWorldSettings.ini` ให้ค้นหาส่วน `OptionSettings` และหาคีย์ `ItemWeightRate`

ถ้าคีย์นี้มีอยู่แล้ว ให้เปลี่ยนค่า ถ้าไม่มี ให้เพิ่มเข้าไปในรายการพารามิเตอร์ของ `OptionSettings`

### คีย์คอนฟิก

ใช้การตั้งค่าดังนี้:

```ini
ItemWeightRate=1.000000
```

### ความหมายของค่า

`ItemWeightRate` ควบคุมตัวคูณน้ำหนักของไอเทมบนเซิร์ฟเวอร์ของคุณ

| คีย์คอนฟิก | ค่าเริ่มต้น | ผลลัพธ์ |
|---|---:|---|
| `ItemWeightRate` | `1.000000` | น้ำหนักไอเทมมาตรฐาน |
| `ItemWeightRate` ต่ำกว่า `1.0` | ตัวอย่าง: `0.500000` | ไอเทมน้ำหนักเบาลง ทำให้ผู้เล่นพกพาได้มากขึ้น |
| `ItemWeightRate` สูงกว่า `1.0` | ตัวอย่าง: `2.000000` | ไอเทมน้ำหนักมากขึ้น ทำให้ผู้เล่นพกพาได้น้อยลง |

### ตัวอย่างค่า

คุณสามารถใช้ตัวอย่างค่าต่อไปนี้ตามสมดุลเกมเพลย์ที่ต้องการ:

| ผลลัพธ์ที่ต้องการ | ค่า |
|---|---:|
| น้ำหนักไอเทมมาตรฐาน | `1.000000` |
| น้ำหนักไอเทมครึ่งหนึ่ง | `0.500000` |
| ไอเทมน้ำหนักเบามาก | `0.250000` |
| น้ำหนักไอเทมสองเท่า | `2.000000` |

:::tip เลือกตัวคูณที่เหมาะสม
ถ้าคุณต้องการประสบการณ์การเอาตัวรอดที่ผ่อนคลายขึ้น ค่า `item weight` ที่ต่ำกว่า เช่น `0.5` มักเป็นจุดเริ่มต้นที่ดี ช่วยลดแรงกดดันในอินเวนทอรีโดยไม่ทำให้การจัดการน้ำหนักหายไปทั้งหมด
:::

## ตัวอย่างคอนฟิก

ใน Palworld ค่าตัวปรับแต่งเกมเพลย์เหล่านี้มักเก็บอยู่ในบรรทัด `OptionSettings=(...)` ของไฟล์ `PalWorldSettings.ini` ไฟล์ของคุณอาจมีการตั้งค่าอื่น ๆ อีกมากมายอยู่แล้ว

ตัวอย่างง่าย ๆ จะเป็นแบบนี้:

```ini
[/Script/Pal.PalGameWorldSettings]
OptionSettings=(ItemWeightRate=0.500000)
```

ในหลายเซิร์ฟเวอร์ `OptionSettings` จะมีค่าหลายตัวคั่นด้วยเครื่องหมายจุลภาค ในกรณีนั้น ให้เพิ่มหรือแก้ไขเฉพาะส่วน `ItemWeightRate` แทนการลบค่าที่มีอยู่

ตัวอย่าง:

```ini
[/Script/Pal.PalGameWorldSettings]
OptionSettings=(Difficulty=None,DayTimeSpeedRate=1.000000,NightTimeSpeedRate=1.000000,ExpRate=1.000000,PalCaptureRate=1.000000,ItemDropRate=1.000000,ItemWeightRate=0.500000)
```

:::caution อย่าลบการตั้งค่าที่มีอยู่
อย่าลบค่าตัวอื่นในบรรทัด `OptionSettings` เว้นแต่คุณต้องการรีเซ็ตจริง ๆ การลบเครื่องหมายจุลภาค, วงเล็บ หรือค่าที่มีอยู่แล้ว อาจทำให้เกิดข้อผิดพลาดในการคอนฟิก
:::

## บันทึกและใช้การเปลี่ยนแปลง

หลังจากแก้ไขไฟล์:

1. บันทึกการเปลี่ยนแปลงใน `PalWorldSettings.ini`
2. รีสตาร์ทเซิร์ฟเวอร์ Palworld ของคุณ

ต้องรีสตาร์ทเซิร์ฟเวอร์เพราะเซิร์ฟเวอร์จะอ่านค่าคอนฟิกเกมเพลย์นี้ตอนเริ่มต้น ค่า `item weight` ใหม่จะไม่ถูกนำไปใช้เต็มที่จนกว่าเซิร์ฟเวอร์จะรีสตาร์ทเสร็จ

## ตรวจสอบน้ำหนักไอเทมใหม่

หลังรีสตาร์ท เข้าร่วมเซิร์ฟเวอร์และทดสอบพฤติกรรมการพกพาไอเทมในเกม

คุณควรสังเกตว่า:

- ค่าที่ต่ำกว่าจะลดน้ำหนักไอเทมที่มีผลจริง
- ค่าที่สูงกว่าจะเพิ่มน้ำหนักไอเทมที่มีผลจริง
- ความจุอินเวนทอรีจะรู้สึกแตกต่างตามตัวคูณที่เลือก

ถ้าการเปลี่ยนแปลงดูเหมือนไม่ถูกนำไปใช้ ให้เปิดไฟล์ `PalWorldSettings.ini` อีกครั้งและตรวจสอบว่า:

| ตรวจสอบ | สิ่งที่ต้องยืนยัน |
|---|---|
| ไฟล์ถูกต้อง | คุณแก้ไขไฟล์ `PalWorldSettings.ini` |
| ตำแหน่งถูกต้อง | ไฟล์ถูกเปิดผ่านเมนู **Configs** ในแผงควบคุมเซิร์ฟเวอร์ |
| คีย์ถูกต้อง | มีคีย์ `ItemWeightRate` อยู่ |
| ไวยากรณ์ถูกต้อง | ค่าถูกใส่ในบรรทัด `OptionSettings=(...)` ถ้าไฟล์ของคุณใช้รูปแบบนี้ |
| รีสตาร์ทเสร็จสมบูรณ์ | เซิร์ฟเวอร์ถูกรีสตาร์ทหลังบันทึก |

## Conclusion

ยินดีด้วย คุณได้เปลี่ยนการตั้งค่าน้ำหนักไอเทมบนเซิร์ฟเวอร์ Palworld ของคุณสำเร็จแล้ว หากมีคำถามหรือขอความช่วยเหลือเพิ่มเติม กรุณาติดต่อทีมซัพพอร์ตของเราได้เลย ทีมงานพร้อมให้บริการทุกวัน! 🙂
