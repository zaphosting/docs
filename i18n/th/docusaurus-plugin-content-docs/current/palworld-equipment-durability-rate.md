## Introduction

ใน Palworld อัตราความทนทานของอุปกรณ์จะควบคุมความเร็วที่เครื่องมือ อาวุธ และชุดเกราะของคุณสูญเสียความทนทานระหว่างการใช้งาน ในคู่มือนี้ คุณจะได้เรียนรู้วิธีเปลี่ยนค่า `EquipmentDurabilityDamageRate` ด้วยตนเองในคอนฟิกเซิร์ฟเวอร์ Palworld ของคุณบน ZAP-Hosting และวิธีใช้การเปลี่ยนแปลงอย่างถูกต้อง



## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่าคุณมีสิทธิ์เข้าถึงการจัดการเซิร์ฟเวอร์เกม Palworld ของคุณในเว็บอินเทอร์เฟซ ZAP-Hosting และคุณต้องมีสิทธิ์แก้ไขไฟล์คอนฟิกเซิร์ฟเวอร์ภายใต้เมนู **Configs**

:::info ต้องแก้ไขคอนฟิกด้วยตนเอง
การตั้งค่านี้ต้องแก้ไขด้วยตนเองในไฟล์คอนฟิกของ Palworld ไม่มีคำสั่งแยกที่ต้องรันในเกมสำหรับการเปลี่ยนแปลงนี้โดยเฉพาะ
:::

## Understanding the durability setting

Palworld เก็บการตั้งค่าเกมเพลย์หลายอย่างไว้ในไฟล์คอนฟิก `PalWorldSettings.ini` การตั้งค่าที่เกี่ยวข้องกับความทนทานของอุปกรณ์คือ:

- `EquipmentDurabilityDamageRate`

ค่านี้ทำหน้าที่เป็นตัวคูณสำหรับการสูญเสียความทนทาน:

| Config key | คำอธิบาย | ค่าเริ่มต้น |
| --- | --- | --- |
| `EquipmentDurabilityDamageRate` | ควบคุมความเร็วที่อุปกรณ์สูญเสียความทนทาน | `1.000000` |

ค่าที่ต่ำกว่าจะลดการสูญเสียความทนทาน หมายความว่าอุปกรณ์ของคุณจะใช้งานได้นานขึ้น ค่า `0.000000` จะปิดการสูญเสียความทนทานของอุปกรณ์ทั้งหมด

:::note สิ่งที่การตั้งค่านี้มีผลต่อ
การตั้งค่านี้เปลี่ยนอัตราการสูญเสียความทนทานของอุปกรณ์ เช่น เครื่องมือ อาวุธ และชุดเกราะ ไม่ได้เพิ่มความเสียหายของไอเท็ม ความเร็วในการซ่อม หรือคุณภาพของไอเท็ม
:::

## Open the Palworld configuration file

เพื่อเปลี่ยนการตั้งค่า คุณต้องแก้ไขไฟล์คอนฟิกหลักของเซิร์ฟเวอร์ Palworld จากการจัดการเซิร์ฟเวอร์เกมของคุณบน ZAP-Hosting

### Find the file in the ZAP-Hosting interface

1. เข้าสู่ระบบเว็บไซต์ ZAP-Hosting
2. เปิดการจัดการเซิร์ฟเวอร์เกม **Palworld** ของคุณ
3. ไปที่เมนู **Configs**
4. เปิดไฟล์ `PalWorldSettings.ini`

นี่คือไฟล์ที่เก็บค่าต่างๆ ของเกมเพลย์ Palworld เช่น ความทนทาน ความอึด ความเสียหาย และการตั้งค่าโลกอื่นๆ

## Edit the equipment durability rate

เมื่อเปิดไฟล์ `PalWorldSettings.ini` แล้ว ให้ค้นหาบรรทัด `OptionSettings` โดยปกติ Palworld จะเก็บการตั้งค่าเกมเพลย์เป็นรายการที่คั่นด้วยเครื่องหมายจุลภาคภายในส่วนนี้

### Add or change the config entry

คุณต้องตรวจสอบให้แน่ใจว่ามีรายการนี้อยู่ใน `OptionSettings`:

```ini
EquipmentDurabilityDamageRate=1.000000
```

ถ้าคีย์นี้มีอยู่แล้ว ให้แทนค่าปัจจุบันด้วยค่าที่คุณต้องการ หากไม่มี ให้เพิ่มเข้าไปในบล็อก `OptionSettings=(...)` ที่มีอยู่

### Example values

คุณสามารถใช้ค่าต่อไปนี้ตามผลลัพธ์ที่ต้องการ:

| ค่า | ผลลัพธ์ |
| --- | --- |
| `1.000000` | การสูญเสียความทนทานตามค่าเริ่มต้น |
| `0.500000` | อุปกรณ์ใช้งานได้นานขึ้นประมาณสองเท่า |
| `0.250000` | อุปกรณ์ใช้งานได้นานขึ้นประมาณสี่เท่า |
| `0.000000` | อุปกรณ์ไม่เสียหายเลย |

### Example configuration snippet

เนื้อหาของบรรทัด `OptionSettings` ของคุณอาจแตกต่างกันตามการตั้งค่าเซิร์ฟเวอร์ แต่การตั้งค่าความทนทานควรอยู่ในรายการที่คั่นด้วยจุลภาคเดียวกัน เช่น:

```ini
[/Script/Pal.PalGameWorldSettings]
OptionSettings=(Difficulty=None,DayTimeSpeedRate=1.000000,NightTimeSpeedRate=1.000000,ExpRate=1.000000,PalCaptureRate=1.000000,PalSpawnNumRate=1.000000,EquipmentDurabilityDamageRate=0.500000)
```

:::caution รักษารูปแบบเดิมไว้
อย่าลบค่าตัวอื่นออกจากบรรทัด `OptionSettings` ขณะแก้ไขไฟล์ Palworld คาดหวังให้การตั้งค่าเหล่านี้อยู่ในรูปแบบที่คั่นด้วยจุลภาคอย่างถูกต้อง
:::

## Save and apply the changes

หลังจากแก้ไขไฟล์คอนฟิกแล้ว ให้บันทึกการเปลี่ยนแปลงในอินเทอร์เฟซ ZAP-Hosting

### Restart the server

เพื่อให้การตั้งค่าอัตราความทนทานใหม่มีผล ให้รีสตาร์ทเซิร์ฟเวอร์ Palworld ของคุณจากการจัดการเซิร์ฟเวอร์เกม

ถ้าไม่รีสตาร์ท เซิร์ฟเวอร์มักจะไม่โหลดคอนฟิกที่อัปเดต

| การกระทำ | จำเป็นหรือไม่ |
| --- | --- |
| บันทึกไฟล์ `PalWorldSettings.ini` | ใช่ |
| รีสตาร์ทเซิร์ฟเวอร์ | ใช่ |
| รันคำสั่งในเกม | ไม่ใช่ |
| ติดตั้งเซิร์ฟเวอร์ใหม่ | ไม่ใช่ |

:::tip ทดสอบการเปลี่ยนแปลงด้วยการปรับเล็กน้อยก่อน
ถ้าคุณไม่แน่ใจว่าค่าความทนทานใดเหมาะกับสไตล์การเล่นของคุณ ให้เริ่มที่ `0.500000` ซึ่งจะทำให้อุปกรณ์ทนทานขึ้นอย่างเห็นได้ชัดโดยไม่ปิดระบบนี้ทั้งหมด
:::

## Troubleshooting

ถ้าการเปลี่ยนแปลงอัตราความทนทานของอุปกรณ์ไม่ทำงานหลังรีสตาร์ท ให้ตรวจสอบจุดต่อไปนี้

### Verify the config key

ตรวจสอบให้แน่ใจว่าคีย์เขียนถูกต้องตามนี้:

```ini
EquipmentDurabilityDamageRate
```

คีย์คอนฟิกของ Palworld มีความไวต่ออักษรตัวพิมพ์เล็ก-ใหญ่จริงๆ เพื่อการจัดการที่แม่นยำ ควรคัดลอกชื่อคีย์ตามที่แสดง

### Check the placement in `OptionSettings`

ค่าต้องอยู่ภายในส่วน `OptionSettings=(...)` ของไฟล์ `PalWorldSettings.ini` ถ้าวางนอกบล็อกนี้ เซิร์ฟเวอร์อาจไม่สนใจค่า

### Confirm the file was saved

หลังแก้ไขในเมนู **Configs** ให้ตรวจสอบว่าการเปลี่ยนแปลงยังอยู่เมื่อเปิดไฟล์ `PalWorldSettings.ini` อีกครั้ง ถ้าไม่อยู่ แสดงว่าไฟล์อาจไม่ได้บันทึกสำเร็จ

### Restart again if needed

ถ้ามีผู้เล่นออนไลน์ระหว่างเปลี่ยนแปลงหรือเซิร์ฟเวอร์ไม่ได้รีสตาร์ทอย่างสมบูรณ์ ให้รีสตาร์ทใหม่อีกครั้งจากแผงจัดการเซิร์ฟเวอร์
