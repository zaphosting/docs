## Introduction

Palworld ให้คุณปรับความเร็วของรอบกลางวันกลางคืนบนเซิร์ฟเวอร์เกมของคุณได้ ในคู่มือนี้ คุณจะได้เรียนรู้วิธีเปลี่ยนความเร็วกลางวันกลางคืนโดยแก้ไขไฟล์คอนฟิกที่ถูกต้องในแผงควบคุมเซิร์ฟเวอร์เกม ZAP-Hosting และนำการเปลี่ยนแปลงไปใช้ให้ถูกต้อง

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่าคุณสามารถเข้าถึงเซิร์ฟเวอร์เกม Palworld ของคุณผ่านเว็บอินเทอร์เฟซ ZAP-Hosting และมีสิทธิ์แก้ไขไฟล์คอนฟิกเซิร์ฟเวอร์

:::info ต้องตั้งค่าด้วยตนเอง
การตั้งค่านี้ต้องทำด้วยตนเองผ่านไฟล์คอนฟิกของเซิร์ฟเวอร์ คุณต้องแก้ไขการตั้งค่า Palworld โดยตรงแทนการใช้คำสั่งอัตโนมัติในเกม
:::

## Locate the Configuration File

เพื่อเปลี่ยนความเร็วกลางวันกลางคืน คุณต้องแก้ไขไฟล์ `PalWorldSettings.ini`

ในแผงควบคุมเซิร์ฟเวอร์เกม ZAP-Hosting คุณสามารถเข้าถึงไฟล์นี้ได้ผ่านส่วน **Configs** เปิดเซิร์ฟเวอร์ Palworld ของคุณในเว็บอินเทอร์เฟซแล้วไปที่ส่วนจัดการไฟล์คอนฟิก

ไฟล์ที่เกี่ยวข้องคือ:

```ini
PalWorldSettings.ini
```

:::note ตำแหน่งไฟล์คอนฟิก
ขึ้นอยู่กับเทมเพลตเซิร์ฟเวอร์เกมและเลย์เอาต์ของแผงควบคุม ไฟล์นี้จะอยู่ในส่วน **Configs** ของแผงควบคุม ZAP-Hosting หากแสดงเส้นทางภายในเต็มในอินเทอร์เฟซของคุณ โดยปกติจะเป็นไฟล์ตั้งค่าเซิร์ฟเวอร์ Palworld สำหรับการตั้งค่าเกมเพลย์
:::

## Edit the Day and Night Speed Settings

ในไฟล์ `PalWorldSettings.ini` ให้ค้นหาการตั้งค่าเกมเพลย์สำหรับความเร็วกลางวันและกลางคืน

คุณต้องปรับค่าต่อไปนี้:

| Config key | ค่าเริ่มต้น | คำอธิบาย |
| --- | --- | --- |
| `DayTimeSpeedRate` | `1.000000` | ควบคุมความเร็วของกลางวันที่ผ่านไป |
| `NightTimeSpeedRate` | `1.000000` | ควบคุมความเร็วของกลางคืนที่ผ่านไป |

ค่ายิ่งสูงเวลาจะผ่านไปเร็วขึ้น ค่าต่ำเวลาจะผ่านไปช้าลง

### Example Configuration

ถ้าคุณต้องการให้กลางวันและกลางคืนผ่านไปเร็วขึ้นทั้งคู่ คุณสามารถตั้งค่าสูงขึ้นแบบนี้ได้:

```ini
DayTimeSpeedRate=2.000000
NightTimeSpeedRate=2.000000
```

ถ้าคุณต้องการให้กลางวันยาวขึ้นแต่กลางคืนเร็วขึ้น คุณสามารถใช้ค่าต่างกัน เช่น:

```ini
DayTimeSpeedRate=0.500000
NightTimeSpeedRate=2.000000
```

### Where to Place the Values

Palworld เก็บการตั้งค่าเกมเพลย์หลายอย่างไว้ในส่วน `OptionSettings` ของไฟล์ `PalWorldSettings.ini` คุณควรแก้ไขค่าที่มีอยู่ของ `DayTimeSpeedRate` และ `NightTimeSpeedRate` ในส่วนนี้แทนการเพิ่มคีย์ซ้ำในที่อื่น

ส่วนตัวอย่างจะมีลักษณะประมาณนี้:

```ini
[/Script/Pal.PalGameWorldSettings]
OptionSettings=(DayTimeSpeedRate=1.000000,NightTimeSpeedRate=1.000000,ExpRate=1.000000,PalCaptureRate=1.000000)
```

หลังแก้ไขอาจเป็นแบบนี้:

```ini
[/Script/Pal.PalGameWorldSettings]
OptionSettings=(DayTimeSpeedRate=2.000000,NightTimeSpeedRate=1.500000,ExpRate=1.000000,PalCaptureRate=1.000000)
```

:::caution แก้ไขค่าที่มีอยู่ด้วยความระมัดระวัง
ตรวจสอบให้แน่ใจว่าคุณเปลี่ยนแค่ค่าหลัง `DayTimeSpeedRate=` และ `NightTimeSpeedRate=` เท่านั้น อย่าลบเครื่องหมายจุลภาค วงเล็บ หรือการตั้งค่าอื่นในบรรทัด `OptionSettings` เพราะถ้าฟอร์แมตผิด เซิร์ฟเวอร์จะโหลดคอนฟิกไม่ถูกต้อง
:::

## Save and Apply the Changes

เมื่อคุณอัปเดตค่าใน `PalWorldSettings.ini` แล้ว ให้บันทึกไฟล์ในตัวแก้ไขคอนฟิกของ ZAP-Hosting

หลังบันทึก ให้รีสตาร์ทเซิร์ฟเวอร์ Palworld ของคุณเพื่อให้การตั้งค่ารอบวันใหม่ถูกโหลด

| Action | Required |
| --- | --- |
| บันทึกไฟล์ `PalWorldSettings.ini` | ใช่ |
| รีสตาร์ทเซิร์ฟเวอร์ | ใช่ |
| รันคำสั่งคอนโซลเพิ่มเติม | ไม่จำเป็น |

:::tip ต้องรีสตาร์ทเซิร์ฟเวอร์
การเปลี่ยนแปลงคอนฟิกโลกของ Palworld จะไม่ถูกนำไปใช้จนกว่าเซิร์ฟเวอร์จะถูกรีสตาร์ทเสมอ ดังนั้นอย่าลืมรีสตาร์ทเซิร์ฟเวอร์หลังเปลี่ยนความเร็วกลางวันหรือกลางคืน
:::

## Verify the New Day Cycle

หลังรีสตาร์ทเสร็จแล้ว เข้าร่วมเซิร์ฟเวอร์ของคุณและสังเกตการเปลี่ยนแปลงเวลาภายในเกม

คุณควรสังเกตได้ว่า:

- **กลางวัน** ผ่านไปเร็วหรือช้าตามค่า `DayTimeSpeedRate`
- **กลางคืน** ผ่านไปเร็วหรือช้าตามค่า `NightTimeSpeedRate`

ถ้าความเร็วไม่เปลี่ยน ให้เปิดไฟล์ `PalWorldSettings.ini` อีกครั้งและตรวจสอบว่า:

- ค่าถูกบันทึกอย่างถูกต้อง
- ฟอร์แมตของบรรทัด `OptionSettings` ยังถูกต้อง
- เซิร์ฟเวอร์ถูกรีสตาร์ทหลังจากเปลี่ยนแปลง

## Configuration Reference

ใช้ตารางนี้เป็นข้อมูลอ้างอิงด่วนเมื่อคุณต้องการเปลี่ยนการตั้งค่ากลางวันในภายหลัง

| Setting | ตัวอย่าง | ผลลัพธ์ |
| --- | --- | --- |
| `DayTimeSpeedRate=0.500000` | กลางวันช้าลง | กลางวันยาวนานขึ้น |
| `DayTimeSpeedRate=2.000000` | กลางวันเร็วขึ้น | กลางวันผ่านไปเร็วขึ้น |
| `NightTimeSpeedRate=0.500000` | กลางคืนช้าลง | กลางคืนยาวนานขึ้น |
| `NightTimeSpeedRate=2.000000` | กลางคืนเร็วขึ้น | กลางคืนผ่านไปเร็วขึ้น |

:::note การตั้งค่าที่สมดุล
ถ้าคุณต้องการประสบการณ์เกมที่เป็นธรรมชาติมากขึ้น หลีกเลี่ยงการตั้งค่าที่สูงเกินไป การเปลี่ยนกลางวันกลางคืนเร็วมากอาจทำให้การทำฟาร์ม การสำรวจ และการจัดการฐานยากขึ้น
:::
