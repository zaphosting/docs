## Introduction

Palworld ให้คุณปรับตัวคูณการเล่นเกมผ่านการตั้งค่าเซิร์ฟเวอร์ รวมถึงจำนวน XP ที่ผู้เล่นได้รับ ในคู่มือนี้ คุณจะได้เรียนรู้วิธีเพิ่มอัตรา XP บนเซิร์ฟเวอร์ Palworld ของคุณที่ ZAP-Hosting โดยการแก้ไขไฟล์การตั้งค่าที่ถูกต้องและนำการเปลี่ยนแปลงไปใช้ให้ถูกวิธี



## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่าคุณสามารถเข้าถึงเซิร์ฟเวอร์เกม Palworld ของคุณผ่านเว็บอินเทอร์เฟซของ ZAP-Hosting และมีสิทธิ์แก้ไขไฟล์การตั้งค่า

:::info การเข้าถึงการตั้งค่าเป็นสิ่งจำเป็น
คุณต้องเข้าถึงการจัดการเซิร์ฟเวอร์ผ่านเว็บเพื่อแก้ไขไฟล์การตั้งค่าภายใต้ส่วน `Configs` หากคุณไม่สามารถเข้าถึงการจัดการเซิร์ฟเวอร์ได้ ให้ตรวจสอบสิทธิ์การเข้าถึงผลิตภัณฑ์ของคุณในแผงควบคุม ZAP-Hosting ก่อน
:::

## Locate the configuration file

เพื่อเพิ่ม XP บนเซิร์ฟเวอร์ Palworld ของคุณ คุณต้องแก้ไขไฟล์ `PalWorldSettings.ini`

ในแผงจัดการเซิร์ฟเวอร์เกม ZAP-Hosting:

1. เปิดเซิร์ฟเวอร์ Palworld ของคุณ
2. ไปที่ส่วน `Configs`
3. เปิดไฟล์ `PalWorldSettings.ini`

ไฟล์นี้ประกอบด้วยการตั้งค่าเกมหลักที่เซิร์ฟเวอร์เฉพาะ Palworld ใช้งาน รวมถึงตัวคูณ XP

## Edit the XP multiplier

การตั้งค่าที่ควบคุมการได้รับ XP คือ `ExpRate`

### Find the correct setting

เปิดไฟล์ `PalWorldSettings.ini` และค้นหาบรรทัด `OptionSettings` หรือส่วนที่กำหนดตัวคูณการเล่นเกม

รายการการตั้งค่าที่เกี่ยวข้องคือ:

```ini
ExpRate=1.000000
```

### Change the value

ปรับค่าของ `ExpRate` เป็นตัวคูณที่คุณต้องการใช้

| Config key | ค่าเริ่มต้น | ตัวอย่างค่า | ผลลัพธ์ |
| --- | --- | --- | --- |
| `ExpRate` | `1.000000` | `2.000000` | ได้ XP สองเท่า |
| `ExpRate` | `1.000000` | `3.000000` | ได้ XP สามเท่า |

ตัวอย่างเช่น เพื่อเปิดใช้งาน XP สองเท่า ให้ตั้งค่าเป็น:

```ini
ExpRate=2.000000
```

เพื่อเปิดใช้งาน XP สามเท่า ให้ตั้งค่าเป็น:

```ini
ExpRate=3.000000
```

:::tip รูปแบบค่าที่แนะนำ
การตั้งค่าเซิร์ฟเวอร์ Palworld มักใช้ค่าทศนิยมเช่น `1.000000` หรือ `2.000000` การใช้รูปแบบเดียวกันช่วยให้การตั้งค่าดูเรียบร้อยและอ่านง่ายขึ้น
:::

## Example configuration

ขึ้นอยู่กับเนื้อหาไฟล์ปัจจุบัน การตั้งค่านี้มักจะอยู่ภายในบล็อก `OptionSettings` เช่น:

```ini
[/Script/Pal.PalGameWorldSettings]
OptionSettings=(Difficulty=None,DayTimeSpeedRate=1.000000,NightTimeSpeedRate=1.000000,ExpRate=2.000000,PalCaptureRate=1.000000)
```

ถ้า `ExpRate` มีอยู่แล้ว ให้เปลี่ยนค่าเท่านั้น หากไม่มี ให้เพิ่ม `ExpRate=[your_value]` ภายในบล็อก `OptionSettings=(...)` ที่มีอยู่

:::caution แก้ไขบล็อก OptionSettings ที่มีอยู่ด้วยความระมัดระวัง
อย่าสร้างรายการ `OptionSettings` ซ้ำหลายบรรทัด เว้นแต่การตั้งค่าปัจจุบันของคุณต้องการแบบนั้น ในกรณีส่วนใหญ่ คุณควรแก้ไขเพียงบรรทัด `OptionSettings=(...)` ที่มีอยู่และเปลี่ยนค่า `ExpRate` ที่นั่นเท่านั้น
:::

## Save and restart the server

หลังจากเปลี่ยนตัวคูณ XP:

1. บันทึกการเปลี่ยนแปลงในไฟล์ `PalWorldSettings.ini`
2. รีสตาร์ทเซิร์ฟเวอร์ Palworld ของคุณจากแผงจัดการเซิร์ฟเวอร์ ZAP-Hosting

ต้องรีสตาร์ทเซิร์ฟเวอร์เพราะ Palworld จะไม่ใช้การตั้งค่านี้ทันทีขณะที่เซิร์ฟเวอร์กำลังทำงานอยู่

| การกระทำ | จำเป็นหรือไม่ |
| --- | --- |
| บันทึกไฟล์ `PalWorldSettings.ini` | ใช่ |
| รีสตาร์ทเซิร์ฟเวอร์ | ใช่ |
| รันคำสั่งคอนโซลเพิ่มเติม | ไม่จำเป็น |

:::note ไม่ต้องใช้คำสั่งเพิ่มเติม
สำหรับการตั้งค่านี้ โดยปกติไม่ต้องใช้คำสั่งในเกมหรือคอนโซลเพิ่มเติม อัตรา XP ใหม่จะถูกนำไปใช้หลังจากรีสตาร์ทเซิร์ฟเวอร์
:::

## Verify the new XP rate

เมื่อเซิร์ฟเวอร์กลับมาออนไลน์แล้ว ให้เข้าร่วมเซิร์ฟเวอร์และทำกิจกรรมที่ให้ XP เช่น การกำจัดศัตรู การจับ Pals หรือการเล่นเกมตามปกติ

ถ้า XP ที่ได้รับดูเหมือนไม่เปลี่ยนแปลง:

- เปิดไฟล์ `PalWorldSettings.ini` อีกครั้ง
- ยืนยันว่า `ExpRate` อยู่ในบล็อก `OptionSettings`
- ตรวจสอบว่าค่าถูกเขียนอย่างถูกต้อง เช่น `2.000000`
- ตรวจสอบว่าเซิร์ฟเวอร์ถูกรีสตาร์ทอย่างสมบูรณ์หลังบันทึกไฟล์

:::danger หลีกเลี่ยงไวยากรณ์การตั้งค่าที่ไม่ถูกต้อง
ถ้าคุณเผลอลบเครื่องหมายจุลภาค วงเล็บ หรือค่าต่างๆ ในบรรทัด `OptionSettings=(...)` เซิร์ฟเวอร์อาจไม่สนใจการตั้งค่านี้หรือโหลดการตั้งค่าไม่ถูกต้อง ตรวจสอบบรรทัดทั้งหมดก่อนบันทึกเสมอ
:::

## Conclusion

ยินดีด้วย คุณได้เพิ่มอัตราการได้รับ XP บนเซิร์ฟเวอร์ Palworld ของคุณเรียบร้อยแล้ว หากมีคำถามหรือต้องการความช่วยเหลือเพิ่มเติม อย่าลังเลที่จะติดต่อทีมซัพพอร์ตของเรา ซึ่งพร้อมให้บริการทุกวันเพื่อช่วยเหลือคุณ! 🙂
