## Introduction

Palworld ให้คุณควบคุมความเร็วในการลดความหิวและความอึดของผู้เล่นและ Pals ได้ ในคู่มือนี้ คุณจะได้เรียนรู้วิธีแก้ไขไฟล์การตั้งค่าเซิร์ฟเวอร์ที่ถูกต้องในเว็บอินเทอร์เฟซของ ZAP-Hosting และนำอัตราการลดแบบกำหนดเองไปใช้ได้อย่างปลอดภัย

## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่าคุณสามารถเข้าถึงเซิร์ฟเวอร์เกม Palworld ของคุณในระบบจัดการเซิร์ฟเวอร์เกมของ ZAP-Hosting ได้

:::info การเข้าถึงการตั้งค่า
คุณต้องมีสิทธิ์เข้าถึงแผงจัดการเซิร์ฟเวอร์และส่วน `Configs` เพื่อแก้ไขไฟล์การตั้งค่า Palworld ด้วยตนเอง
:::

## เปิดไฟล์การตั้งค่า Palworld

เพื่อเปลี่ยนพฤติกรรมความหิวและความอึด คุณต้องแก้ไขไฟล์ `PalWorldSettings.ini`

ในระบบจัดการเซิร์ฟเวอร์เกมของ ZAP-Hosting:

1. เปิดเซิร์ฟเวอร์ Palworld ของคุณ
2. ไปที่ส่วน `Configs`
3. เปิดไฟล์ `PalWorldSettings.ini`



:::note ไฟล์สำหรับตัวคูณเกมเพลย์
การตั้งค่าความหิวและความอึดจะถูกเก็บไว้ใน `PalWorldSettings.ini` ค่าพวกนี้มักเป็นส่วนหนึ่งของสตริงตัวเลือกหลักที่ใช้โดยเซิร์ฟเวอร์เฉพาะ
:::

## เปลี่ยนค่าความหิวและความอึด

ภายใน `PalWorldSettings.ini` ให้ค้นหาส่วนการตั้งค่าเกมเพลย์ที่มีค่าตัวเลือกเซิร์ฟเวอร์ของคุณ คุณต้องเพิ่มหรือปรับคีย์การตั้งค่าต่อไปนี้

:::caution การสะกดที่สำคัญใน Palworld
Palworld ใช้การสะกดคำว่า `Decreace` ในรายการตั้งค่าเหล่านี้ ซึ่งเป็นความตั้งใจในรูปแบบการตั้งค่าเซิร์ฟเวอร์ ดังนั้นคุณต้องใช้คีย์ตามที่แสดงด้านล่างอย่างแม่นยำ
:::

### คีย์การตั้งค่าที่มีให้ใช้

| คีย์การตั้งค่า | คำอธิบาย | ค่าเริ่มต้น |
| --- | --- | --- |
| `PlayerStomachDecreaceRate` | ควบคุมอัตราการลดความหิวของผู้เล่น | `1.0` |
| `PlayerStaminaDecreaceRate` | ควบคุมอัตราการลดความอึดของผู้เล่น | `1.0` |
| `PalStomachDecreaceRate` | ควบคุมอัตราการลดความหิวของ Pal | `1.0` |
| `PalStaminaDecreaceRate` | ควบคุมอัตราการลดความอึดของ Pal | `1.0` |

### วิธีการทำงานของค่าเหล่านี้

ค่ายิ่งต่ำจะลดความเร็วในการใช้ความหิวหรือความอึด

| ค่า | ผลลัพธ์ |
| --- | --- |
| `1.0` | อัตราการลดค่าเริ่มต้น |
| `0.5` | อัตราการลดครึ่งหนึ่ง |
| `0.0` | ปิดการลดค่าโดยสิ้นเชิง |

:::tip เลือกการตั้งค่าที่สมดุล
ถ้าคุณต้องการประสบการณ์การเอาตัวรอดที่ผ่อนคลายขึ้นโดยไม่ลบกลไกนี้ออกทั้งหมด ค่า `0.5` เป็นจุดเริ่มต้นที่เหมาะสมสำหรับทั้งความหิวและความอึด
:::

## ตัวอย่างการตั้งค่า

เพิ่มหรือแก้ไขค่าต่อไปนี้ใน `PalWorldSettings.ini` ตามประสบการณ์เกมเพลย์ที่คุณต้องการ:

```ini
PlayerStomachDecreaceRate=0.5
PlayerStaminaDecreaceRate=0.5
PalStomachDecreaceRate=0.5
PalStaminaDecreaceRate=0.5
```

ตัวอย่างนี้จะลดอัตราการลดความหิวและความอึดลงครึ่งหนึ่งจากค่าเริ่มต้นสำหรับทั้งผู้เล่นและ Pals

ถ้าคุณต้องการปิดการลดความหิวและความอึดทั้งหมด ให้ใช้:

```ini
PlayerStomachDecreaceRate=0.0
PlayerStaminaDecreaceRate=0.0
PalStomachDecreaceRate=0.0
PalStaminaDecreaceRate=0.0
```

:::note การวางตำแหน่งการตั้งค่า
ขึ้นอยู่กับโครงสร้างของไฟล์ `PalWorldSettings.ini` ของคุณ ค่าเหล่านี้อาจต้องถูกรวมอยู่ในรายการตัวเลือกที่มีอยู่แล้ว แทนที่จะวางเป็นบรรทัดแยกต่างหาก หากไฟล์ของคุณมีรายการ `OptionSettings` ยาวอยู่แล้ว ให้แน่ใจว่าคุณรักษารูปแบบเดิมไว้และแก้ไขหรือเพิ่มเฉพาะคีย์ที่เกี่ยวข้องเท่านั้น
:::

## บันทึกและรีสตาร์ทเซิร์ฟเวอร์

หลังจากแก้ไขไฟล์:

1. บันทึกการเปลี่ยนแปลงใน `PalWorldSettings.ini`
2. รีสตาร์ทเซิร์ฟเวอร์ Palworld ของคุณจากระบบจัดการเซิร์ฟเวอร์เกมของ ZAP-Hosting

ต้องรีสตาร์ทเซิร์ฟเวอร์ก่อนที่การตั้งค่าความหิวและความอึดใหม่จะมีผล

:::caution ต้องรีสตาร์ทเซิร์ฟเวอร์
ถ้าคุณไม่รีสตาร์ทเซิร์ฟเวอร์ ค่าในการตั้งค่าใหม่จะไม่ถูกโหลดโดยเซิร์ฟเวอร์เกม
:::

## ตรวจสอบการเปลี่ยนแปลงในเกม

เมื่อเซิร์ฟเวอร์กลับมาออนไลน์แล้ว เข้าร่วมเซิร์ฟเวอร์ของคุณและทดสอบการตั้งค่าใหม่

### สิ่งที่ควรตรวจสอบ

- ความหิวของผู้เล่นลดช้าลงหรือไม่
- ความอึดของผู้เล่นคงทนขึ้นในระหว่างการเคลื่อนไหวและการกระทำหรือไม่
- ความหิวของ Pal ลดลงตามอัตราที่ตั้งไว้หรือไม่
- การใช้ความอึดของ Pal ตรงกับค่าที่คุณตั้งไว้หรือไม่

ถ้าค่าดูเหมือนไม่ถูกนำไปใช้ ให้เปิด `PalWorldSettings.ini` อีกครั้งและตรวจสอบว่า:

- คีย์การตั้งค่าสะกดถูกต้องตามที่แสดง
- ค่าเป็นตัวเลขทศนิยมที่ถูกต้อง เช่น `1.0`, `0.5` หรือ `0.0`
- การตั้งค่าถูกบันทึกอย่างถูกต้อง
- เซิร์ฟเวอร์ถูกรีสตาร์ทเต็มที่หลังจากแก้ไข

## Conclusion

ยินดีด้วย คุณได้เปลี่ยนอัตราการลดความหิวและความอึดบนเซิร์ฟเวอร์ Palworld ของคุณสำเร็จแล้ว สำหรับคำถามเพิ่มเติมหรือต้องการความช่วยเหลือ อย่าลังเลที่จะติดต่อทีมซัพพอร์ตของเรา ซึ่งพร้อมให้บริการทุกวันเพื่อช่วยเหลือคุณ! 🙂
