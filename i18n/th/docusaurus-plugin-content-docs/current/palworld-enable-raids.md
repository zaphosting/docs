## Introduction

การบุก (raids) ใน Palworld คือการโจมตีจากศัตรูผู้บุกรุกที่สามารถมุ่งเป้าไปยังฐานผู้เล่นบนเซิร์ฟเวอร์ของคุณ ในคู่มือนี้ คุณจะได้เรียนรู้วิธีเปิดหรือปิดการบุกโดยการแก้ไขไฟล์คอนฟิกที่ถูกต้องด้วยตนเองผ่านแผงควบคุมเซิร์ฟเวอร์เกมของ ZAP-Hosting

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่าคุณสามารถเข้าถึงเซิร์ฟเวอร์เกม Palworld ของคุณผ่านเว็บอินเทอร์เฟซของ ZAP-Hosting และมีสิทธิ์ในการแก้ไขไฟล์คอนฟิกของเซิร์ฟเวอร์

:::info การตั้งค่าด้วยตนเองจำเป็น
การตั้งค่านี้ต้องทำโดยการแก้ไขคอนฟิกเซิร์ฟเวอร์ Palworld ด้วยตนเองภายใต้เมนู **Configs** ในแผงควบคุมเซิร์ฟเวอร์เกมของคุณ หลังจากบันทึกการเปลี่ยนแปลงแล้ว คุณต้องรีสตาร์ทเซิร์ฟเวอร์เพื่อให้การตั้งค่าใหม่มีผล
:::

## Locate the Correct Configuration File

เพื่อเปิดหรือปิดการบุก คุณต้องแก้ไขไฟล์ `PalWorldSettings.ini`

ในแผงควบคุมเซิร์ฟเวอร์เกมของ ZAP-Hosting:

1. เปิดเซิร์ฟเวอร์เกม **Palworld** ของคุณ
2. ไปที่เมนู **Configs**
3. เปิดไฟล์ชื่อ `PalWorldSettings.ini`

ไฟล์นี้ประกอบด้วยค่าคอนฟิกหลักสำหรับการเล่นเกมของเซิร์ฟเวอร์ Palworld ของคุณ รวมถึงการตั้งค่าที่ควบคุมว่าการบุกจะถูกเปิดใช้งานหรือไม่

## Edit the Raid Setting

ในไฟล์ `PalWorldSettings.ini` ให้ค้นหาส่วน `OptionSettings` คีย์คอนฟิกที่เกี่ยวข้องคือ:

```ini
bEnableInvaderEnemy=True
```

การตั้งค่านี้ควบคุมว่าการบุกของศัตรูผู้บุกรุกจะเปิดใช้งานบนเซิร์ฟเวอร์หรือไม่

### Enable Raids

ถ้าคุณต้องการเปิดใช้งานการบุก ให้ตั้งค่าเป็น `True`:

```ini
bEnableInvaderEnemy=True
```

ด้วยค่านี้ การโจมตีของศัตรูผู้บุกรุกจะเกิดขึ้นเป็นระยะๆ ต่อฐานผู้เล่นในระหว่างการเล่นเกม

### Disable Raids

ถ้าคุณต้องการปิดการบุก ให้ตั้งค่าเป็น `False`:

```ini
bEnableInvaderEnemy=False
```

การตั้งค่านี้จะปิดการโจมตีของศัตรูผู้บุกรุกทั้งหมด ซึ่งจะช่วยให้ประสบการณ์การสร้างฐานเป็นไปอย่างสงบมากขึ้น และอาจช่วยลดภาระของเซิร์ฟเวอร์เล็กน้อย

## Configuration Reference

ใช้ตารางนี้เป็นข้อมูลอ้างอิงอย่างรวดเร็วสำหรับการตั้งค่าการบุก:

| ไฟล์คอนฟิก | คีย์คอนฟิก | ค่า | ผลลัพธ์ |
| --- | --- | --- | --- |
| `PalWorldSettings.ini` | `bEnableInvaderEnemy` | `True` | เปิดใช้งานการบุกและการโจมตีของศัตรูผู้บุกรุก |
| `PalWorldSettings.ini` | `bEnableInvaderEnemy` | `False` | ปิดการบุกและการโจมตีของศัตรูผู้บุกรุกทั้งหมด |

:::note พฤติกรรมเริ่มต้น
พฤติกรรมเริ่มต้นของเซิร์ฟเวอร์ Palworld โดยทั่วไปคือ `bEnableInvaderEnemy=True` ซึ่งหมายความว่าการบุกจะถูกเปิดใช้งาน เว้นแต่คุณจะเปลี่ยนแปลงการตั้งค่าเอง
:::

## Save and Apply the Changes

หลังจากแก้ไขค่าในไฟล์ `PalWorldSettings.ini` ให้บันทึกไฟล์ในเมนู **Configs** ของ ZAP-Hosting

จากนั้นคุณต้องรีสตาร์ทเซิร์ฟเวอร์ Palworld ของคุณเพื่อให้คอนฟิกที่อัปเดตถูกโหลด

### Restart the Server

ใช้ฟังก์ชันรีสตาร์ทในแผงควบคุมเซิร์ฟเวอร์เกมของ ZAP-Hosting หลังจากบันทึกไฟล์

:::caution ต้องรีสตาร์ทเซิร์ฟเวอร์
ถ้าคุณไม่รีสตาร์ทเซิร์ฟเวอร์ การตั้งค่าการบุกที่เปลี่ยนแปลงอาจไม่ถูกนำไปใช้ การแก้ไขไฟล์อย่างเดียวไม่เพียงพอ
:::

## Verify the Setting

หลังจากรีสตาร์ทเสร็จสิ้น การตั้งค่าการบุกใหม่ของคุณควรจะมีผล

- ถ้า `bEnableInvaderEnemy=True` การบุกจะถูกเปิดใช้งาน
- ถ้า `bEnableInvaderEnemy=False` การบุกจะถูกปิดใช้งาน

ถ้าการตั้งค่าไม่ถูกนำไปใช้ ให้เปิดไฟล์ `PalWorldSettings.ini` อีกครั้งและตรวจสอบว่าค่าถูกบันทึกอย่างถูกต้องโดยไม่มีข้อผิดพลาดด้านฟอร์แมต

:::tip สร้างฐานอย่างสงบ
การปิดการบุกเหมาะสำหรับผู้ที่ต้องการเน้นการสำรวจ การสร้างฐาน หรือเล่นแบบร่วมมือที่มีความกดดันน้อยโดยไม่มีการโจมตีศัตรูเป็นระยะ
:::
