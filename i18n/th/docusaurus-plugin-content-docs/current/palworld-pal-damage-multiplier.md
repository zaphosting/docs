## Introduction

Palworld ให้คุณปรับแต่งความเสียหายที่ Pals ของคุณสร้างและรับได้โดยการเปลี่ยนการตั้งค่าตัวคูณความเสียหายของเซิร์ฟเวอร์ ในคู่มือนี้ คุณจะได้เรียนรู้ว่าไฟล์การตั้งค่าไหนที่ต้องแก้ไขในแผงควบคุม ZAP-Hosting ค่าที่ต้องเปลี่ยน และวิธีใช้การตั้งค่าใหม่อย่างถูกต้อง

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่าคุณสามารถเข้าถึงเซิร์ฟเวอร์เกม Palworld ของคุณผ่านแผงควบคุมเซิร์ฟเวอร์เกมของ ZAP-Hosting ได้

:::info การตั้งค่าด้วยตนเองจำเป็น
การตั้งค่านี้ต้องทำโดยการแก้ไขไฟล์การตั้งค่า Palworld ด้วยตนเอง ไม่มีคำสั่งในเกมแยกต่างหากสำหรับการเปลี่ยนแปลงนี้
:::

## เปิดไฟล์การตั้งค่าที่ถูกต้อง

เพื่อเปลี่ยนตัวคูณความเสียหายของ Pal คุณต้องแก้ไขไฟล์ `PalWorldSettings.ini`

ในแผงควบคุมเซิร์ฟเวอร์เกมของ ZAP-Hosting ให้เปิดส่วน `Configs` และค้นหาไฟล์ `PalWorldSettings.ini` ไฟล์นี้เก็บค่าการตั้งค่าหลักของโลกและการเล่นเกมสำหรับเซิร์ฟเวอร์ Palworld ของคุณ

:::note ตำแหน่งไฟล์การตั้งค่า
ไฟล์ที่เกี่ยวข้องสำหรับคู่มือนี้คือ `PalWorldSettings.ini` ซึ่งสามารถเข้าถึงได้ผ่านแผงควบคุมเซิร์ฟเวอร์เกมของคุณในส่วน `Configs`
:::

## แก้ไขค่าตัวคูณความเสียหายของ Pal

ภายในไฟล์ `PalWorldSettings.ini` ให้ค้นหาส่วน `OptionSettings` การตั้งค่าตัวคูณความเสียหายของ Pal จะถูกเก็บเป็นคีย์การตั้งค่าภายในส่วนนี้

คุณต้องปรับค่าดังต่อไปนี้:

| คีย์การตั้งค่า | ค่าเริ่มต้น | จุดประสงค์ |
| --- | --- | --- |
| `PalDamageRateAttack` | `1.000000` | ควบคุมความเสียหายที่ Pals ของคุณสร้าง |
| `PalDamageRateDefense` | `1.000000` | ควบคุมความเสียหายที่ Pals ของคุณได้รับ |

### ตัวอย่างการตั้งค่า

ถ้าคีย์เหล่านี้มีอยู่แล้ว ให้เปลี่ยนค่าเป็นตัวคูณที่คุณต้องการ หากไม่มี ให้เพิ่มเข้าไปในส่วน `OptionSettings`

```ini
PalDamageRateAttack=1.500000
PalDamageRateDefense=0.800000
```

### ความหมายของค่า

ใช้พฤติกรรมต่อไปนี้เป็นแนวทางเมื่อเลือกค่าตัวคูณของคุณ:

| การเปลี่ยนค่า | ผลลัพธ์ |
| --- | --- |
| เพิ่มค่า `PalDamageRateAttack` | Pals ของคุณสร้างความเสียหายมากขึ้น |
| ลดค่า `PalDamageRateAttack` | Pals ของคุณสร้างความเสียหายน้อยลง |
| เพิ่มค่า `PalDamageRateDefense` | Pals ของคุณได้รับการป้องกันที่ไม่ดีขึ้นและรับความเสียหายตามตัวคูณที่เพิ่มขึ้น |
| ลดค่า `PalDamageRateDefense` | Pals ของคุณได้รับความเสียหายมากขึ้น |

:::caution ตรวจสอบค่าตัวคูณของคุณอย่างระมัดระวัง
การตั้งค่าเซิร์ฟเวอร์ Palworld ใช้ค่าตัวคูณเป็นตัวเลขทศนิยมเท่านั้น กรุณาใส่เฉพาะตัวเลขทศนิยมที่ถูกต้อง เช่น `0.500000`, `1.000000` หรือ `2.000000` การจัดรูปแบบที่ไม่ถูกต้องอาจทำให้เซิร์ฟเวอร์ไม่สามารถโหลดการตั้งค่าได้อย่างถูกต้อง
:::

## บันทึกการเปลี่ยนแปลง

หลังจากแก้ไขค่าในไฟล์ `PalWorldSettings.ini` ให้บันทึกไฟล์ในตัวแก้ไขการตั้งค่าของ ZAP-Hosting

ถ้าคุณกำลังปรับสมดุลสำหรับโหมด PvE หรือการเล่นร่วมกัน แนะนำให้เปลี่ยนตัวคูณทีละตัวก่อน เพื่อให้ง่ายต่อการทดสอบว่าความเสียหายที่สร้างหรือรับเปลี่ยนแปลงไปเท่าไร

:::tip เริ่มด้วยการปรับเล็กน้อย
การเพิ่มเล็กน้อย เช่น `1.200000` สำหรับ `PalDamageRateAttack` มักจะง่ายต่อการปรับสมดุลมากกว่าการเพิ่มแบบกระโดดใหญ่ เช่น `3.000000`
:::

## รีสตาร์ทเซิร์ฟเวอร์

เมื่อคุณบันทึกการตั้งค่าใหม่แล้ว ให้รีสตาร์ทเซิร์ฟเวอร์ Palworld ของคุณเพื่อให้การตั้งค่าตัวคูณความเสียหายใหม่ถูกโหลด

ไม่จำเป็นต้องใช้คำสั่งคอนโซลเพิ่มเติมหลังจากแก้ไขไฟล์ การรีสตาร์ทเซิร์ฟเวอร์เต็มรูปแบบก็เพียงพอที่จะใช้การเปลี่ยนแปลง

| การกระทำ | จำเป็นหรือไม่ |
| --- | --- |
| บันทึกไฟล์ `PalWorldSettings.ini` | ใช่ |
| รันคำสั่งเพิ่มเติม | ไม่ |
| รีสตาร์ทเซิร์ฟเวอร์ | ใช่ |

## ตรวจสอบการตั้งค่าความเสียหายใหม่

หลังจากเซิร์ฟเวอร์รีสตาร์ทแล้ว เข้าร่วมเซิร์ฟเวอร์ Palworld ของคุณและทดสอบการต่อสู้กับ Pals ของคุณ ตรวจสอบว่า:

- Pals ของคุณสร้างความเสียหายตามที่คาดไว้
- Pals ของคุณได้รับความเสียหายตามที่คาดไว้
- สมดุลการเล่นเกมยังเหมาะสมกับการตั้งค่าเซิร์ฟเวอร์ของคุณ

ถ้าผลลัพธ์แรงเกินไปหรือน้อยเกินไป ให้กลับไปที่ไฟล์ `PalWorldSettings.ini` ปรับค่าตัวคูณอีกครั้ง บันทึกไฟล์ และรีสตาร์ทเซิร์ฟเวอร์ใหม่อีกครั้ง

## Conclusion

ยินดีด้วย คุณได้เปลี่ยนตัวคูณความเสียหายของ Pal บนเซิร์ฟเวอร์ Palworld ของคุณเรียบร้อยแล้ว หากมีคำถามเพิ่มเติมหรือต้องการความช่วยเหลือ กรุณาติดต่อทีมซัพพอร์ตของเราได้เลย ทีมงานพร้อมให้บริการทุกวัน! 🙂
