## Introduction

Palworld ให้คุณควบคุมจำนวนไอเท็มที่ถูกทิ้งในโลกของคุณและระยะเวลาที่ไอเท็มเหล่านั้นจะอยู่ก่อนหายไป ในคู่มือนี้ คุณจะได้เรียนรู้วิธีแก้ไขไฟล์คอนฟิกที่ถูกต้องในแผงควบคุม ZAP-Hosting ปรับตั้งค่าไอเท็มที่ถูกทิ้ง และนำการเปลี่ยนแปลงไปใช้ได้อย่างปลอดภัย



## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่าคุณมีสิทธิ์เข้าถึงเซิร์ฟเวอร์เกม Palworld ของคุณในเว็บอินเทอร์เฟซ ZAP-Hosting และมีสิทธิ์แก้ไขไฟล์คอนฟิกของเซิร์ฟเวอร์

:::info การตั้งค่าด้วยตนเองจำเป็น
การตั้งค่านี้ต้องทำด้วยตนเองโดยการแก้ไขคอนฟิกของเซิร์ฟเวอร์ Palworld ไฟล์ที่ต้องแก้ไขสามารถเข้าถึงได้ในส่วนจัดการเซิร์ฟเวอร์เกมของคุณภายใต้เมนู `Configs`
:::

## Open the Palworld Configuration File

เพื่อเปลี่ยนขีดจำกัดไอเท็มที่ถูกทิ้ง คุณต้องแก้ไขไฟล์ `PalWorldSettings.ini`

ในส่วนจัดการเซิร์ฟเวอร์เกม ZAP-Hosting:

1. เปิดเซิร์ฟเวอร์ Palworld ของคุณ
2. ไปที่เมนู `Configs`
3. เปิดไฟล์ `PalWorldSettings.ini`

ไฟล์นี้เก็บค่าคอนฟิกหลักของเกมเพลย์สำหรับเซิร์ฟเวอร์ Palworld ของคุณ รวมถึงพฤติกรรมของไอเท็มที่ถูกทิ้ง

## Change the Dropped Item Settings

การตั้งค่าไอเท็มที่ถูกทิ้งถูกควบคุมผ่านคีย์ในไฟล์ `PalWorldSettings.ini` คุณต้องปรับค่าที่เกี่ยวข้องในบรรทัดหรือส่วนของการตั้งค่าที่ใช้งานอยู่ในไฟล์นี้

### Relevant Configuration Keys

ใช้คีย์คอนฟิกต่อไปนี้เพื่อควบคุมไอเท็มที่ถูกทิ้ง:

| Config key | Default value | Description |
| --- | --- | --- |
| `DropItemMaxNum` | `3000` | จำนวนสูงสุดของไอเท็มที่ถูกทิ้งที่สามารถมีอยู่ในโลกพร้อมกัน |
| `DropItemAliveMaxHours` | `1.0` | เวลาหน่วยชั่วโมงก่อนที่ไอเท็มที่ถูกทิ้งจะหายไปโดยอัตโนมัติ |

### Example Configuration

ขึ้นอยู่กับเนื้อหาไฟล์ปัจจุบันของคุณ ค่าพวกนี้มักจะอยู่ในส่วนของการตั้งค่า Palworld เช่น:

```ini
OptionSettings=(DropItemMaxNum=3000,DropItemAliveMaxHours=1.000000)
```

ถ้าคีย์เหล่านี้มีอยู่แล้วในบรรทัด `OptionSettings` ให้เปลี่ยนแค่ค่าตัวเลข เช่น:

```ini
OptionSettings=(DropItemMaxNum=2000,DropItemAliveMaxHours=0.500000)
```

ในตัวอย่างนี้:

- `DropItemMaxNum=2000` จำกัดโลกให้มีไอเท็มที่ถูกทิ้งได้สูงสุด `2000` ชิ้น
- `DropItemAliveMaxHours=0.500000` ทำให้ไอเท็มที่ถูกทิ้งหายไปหลังจาก `0.5` ชั่วโมง หรือ `30` นาที

:::note รูปแบบค่าที่ใช้
การตั้งค่าเซิร์ฟเวอร์ Palworld มักใช้ค่าทศนิยมที่มีเลขศูนย์ต่อท้ายหลายตำแหน่ง เช่น `1.000000` คุณควรรักษารูปแบบนี้ไว้ตามที่มีในไฟล์ของคุณ
:::

## Choose Suitable Values

ค่าที่เหมาะสมขึ้นอยู่กับจำนวนผู้เล่น กิจกรรมในเซิร์ฟเวอร์ และการสร้างไอเท็ม

### Recommended Use Cases

| Scenario | `DropItemMaxNum` | `DropItemAliveMaxHours` |
| --- | --- | --- |
| เซิร์ฟเวอร์ส่วนตัวขนาดเล็ก | `3000` | `1.000000` |
| เซิร์ฟเวอร์มัลติเพลเยอร์ที่มีผู้เล่นเยอะ | `2000` | `0.500000` |
| ตั้งค่าสำหรับประสิทธิภาพสูง | `1000` ถึง `1500` | `0.250000` ถึง `0.500000` |

### Performance Considerations

การตั้งค่าจำนวนไอเท็มที่ถูกทิ้งต่ำลงสามารถช่วยเพิ่มประสิทธิภาพเซิร์ฟเวอร์ โดยเฉพาะถ้า:

- มีผู้เล่นจำนวนมากออนไลน์พร้อมกัน
- โลกของคุณสร้างไอเท็มจำนวนมาก
- ผู้เล่นมักจะฟาร์ม สร้าง หรือทิ้งไอเท็มไว้บนพื้นบ่อยครั้ง

:::tip ปรับปรุงประสิทธิภาพด้วยการลดจำนวนไอเท็ม
ถ้าคุณพบอาการแลคหรือเซิร์ฟเวอร์ตอบสนองช้า การลดค่าจำนวนไอเท็มสูงสุดและเวลาหายไปของไอเท็มจะช่วยลดความรกในโลกและเพิ่มความเสถียร
:::

:::caution หลีกเลี่ยงการตั้งค่าต่ำเกินไป
ถ้าคุณตั้งค่าต่ำเกินไป ผู้เล่นอาจสังเกตเห็นว่าไอเท็มหายไปเร็วเกินไป หรือจำนวนไอเท็มที่ถูกทิ้งถึงขีดจำกัดเร็วเกินควร ควรทดสอบการเปลี่ยนแปลงอย่างระมัดระวังหลังปรับค่า
:::

## Save and Apply the Changes

หลังจากแก้ไขไฟล์ `PalWorldSettings.ini` ให้บันทึกไฟล์ในแผงควบคุม ZAP-Hosting

เมื่อบันทึกไฟล์แล้ว ให้รีสตาร์ทเซิร์ฟเวอร์ Palworld ของคุณเพื่อให้การตั้งค่าไอเท็มที่ถูกทิ้งใหม่ถูกโหลด

| Action | Required |
| --- | --- |
| บันทึกไฟล์ `PalWorldSettings.ini` | ใช่ |
| รีสตาร์ทเซิร์ฟเวอร์ | ใช่ |
| คำสั่งคอนโซลเพิ่มเติม | ไม่จำเป็น |

:::info ต้องรีสตาร์ทเซิร์ฟเวอร์
การเปลี่ยนแปลงในไฟล์ `PalWorldSettings.ini` จะไม่ถูกนำไปใช้จนกว่าคุณจะรีสตาร์ทเซิร์ฟเวอร์ Palworld
:::

## Verify the New Settings

หลังรีสตาร์ท ให้เข้าร่วมเซิร์ฟเวอร์และสังเกตพฤติกรรมของไอเท็มที่ถูกทิ้งในระหว่างเล่นเกมปกติ

คุณควรตรวจสอบว่า:

- จำนวนไอเท็มที่ถูกทิ้งถูกควบคุมตามที่ตั้งไว้หรือไม่
- ไอเท็มยังคงอยู่บนพื้นตามเวลาที่ตั้งไว้หรือไม่
- ประสิทธิภาพเซิร์ฟเวอร์ดีขึ้นหลังลดจำนวนหรือเวลาของไอเท็มหรือไม่

ถ้าจำเป็น ให้กลับไปแก้ไขไฟล์ `PalWorldSettings.ini` และปรับค่าต่อไป
