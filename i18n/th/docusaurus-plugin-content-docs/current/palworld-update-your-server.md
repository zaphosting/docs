## Introduction

การอัปเดตเซิร์ฟเวอร์ Palworld จำเป็นเพื่อให้เซิร์ฟเวอร์ของคุณเข้ากันได้กับเวอร์ชันเกม Palworld และการอัปเดตไคลเอนต์ล่าสุด ในคู่มือนี้ คุณจะได้เรียนรู้วิธีอัปเดตเซิร์ฟเวอร์ Palworld บน ZAP-Hosting ตรวจสอบการตั้งค่าที่เกี่ยวข้อง และวิธีแก้ไขหากการอัปเดตไม่สำเร็จ

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่าคุณสามารถเข้าถึงเซิร์ฟเวอร์เกม Palworld ของคุณผ่านเว็บอินเทอร์เฟซ ZAP-Hosting และมีสิทธิ์ในการรีสตาร์ทหรือรีติดตั้งเซิร์ฟเวอร์หากจำเป็น

:::info สิทธิ์การเข้าถึงเซิร์ฟเวอร์
คุณต้องมีสิทธิ์เข้าถึงการจัดการเซิร์ฟเวอร์เกม รวมถึง **Configs**, **Console** และการควบคุมพลังงานในแผงควบคุม ZAP-Hosting
:::

:::note เกี่ยวกับไฟล์คอนฟิก
สำหรับการอัปเดต Palworld โดยปกติจะไม่มีไฟล์คอนฟิกเกมที่คุณต้องแก้ไขเพื่อทำการติดตั้งเวอร์ชันเกมใหม่ กระบวนการอัปเดตจะถูกจัดการโดยการติดตั้งเซิร์ฟเวอร์เอง อย่างไรก็ตาม คุณควรตรวจสอบการตั้งค่าเซิร์ฟเวอร์ในแผงควบคุมหากคุณจัดการพฤติกรรมการอัปเดตด้วยตนเอง
:::

## วิธีการอัปเดตเซิร์ฟเวอร์ Palworld บน ZAP-Hosting

เซิร์ฟเวอร์เฉพาะ Palworld บนแพลตฟอร์มโฮสติ้งมักจะอัปเดตเมื่อการติดตั้งเซิร์ฟเวอร์ตรวจสอบเวอร์ชันใหม่ในระหว่างการเริ่มต้น จากข้อมูลอ้างอิงที่มีอยู่ เซิร์ฟเวอร์ ZAP-Hosting จะทำการตรวจสอบนี้โดยอัตโนมัติเมื่อเซิร์ฟเวอร์เริ่มต้นหรือรีสตาร์ท

หากเซิร์ฟเวอร์ของคุณตั้งค่าให้อัปเดตอัตโนมัติ คุณเพียงแค่ต้องรีสตาร์ทเซิร์ฟเวอร์หลังจากมีการปล่อย Palworld เวอร์ชันใหม่ หากการอัปเดตอัตโนมัติถูกปิดใช้งานในบริการของคุณ คุณต้องรีสตาร์ทเซิร์ฟเวอร์ด้วยตนเองหลังจากแต่ละแพตช์เพื่อให้การตรวจสอบอัปเดตทำงาน

:::caution ความพร้อมใช้งานของการอัปเดตอัตโนมัติ
ป้ายชื่อและความพร้อมใช้งานของการควบคุมการอัปเดตอัตโนมัติอาจแตกต่างกันไปตามอินเทอร์เฟซเซิร์ฟเวอร์เกมและการตั้งค่าผลิตภัณฑ์ของ ZAP-Hosting ในปัจจุบัน หากคุณไม่เห็นตัวเลือกสลับที่เกี่ยวข้องกับการอัปเดตในตั้งค่าเซิร์ฟเวอร์ อย่าสันนิษฐานว่าหายไปถาวร ตัวเลือกนี้อาจแตกต่างกันตามเวอร์ชันผลิตภัณฑ์หรืออาจถูกจัดการโดยอัตโนมัติในเบื้องหลัง
:::

## ตรวจสอบการตั้งค่าเซิร์ฟเวอร์ที่เกี่ยวข้อง

เริ่มต้นด้วยการเปิดเซิร์ฟเวอร์ Palworld ของคุณในเว็บอินเทอร์เฟซ ZAP-Hosting และตรวจสอบการตั้งค่าที่เกี่ยวข้องกับการอัปเดตและพฤติกรรมการเริ่มต้น

### เปิดการจัดการเซิร์ฟเวอร์ของคุณ

1. เข้าสู่ระบบเว็บอินเทอร์เฟซ ZAP-Hosting
2. เปิดเซิร์ฟเวอร์เกม **Palworld** ของคุณ
3. ตรวจสอบส่วนต่างๆ ที่มี เช่น **Configs**, **Console** และการควบคุมพลังงานเซิร์ฟเวอร์

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

### ตรวจสอบว่าต้องแก้ไขไฟล์คอนฟิกหรือไม่

สำหรับกระบวนการอัปเดต Palworld เอง ไม่มีไฟล์คอนฟิก Palworld ที่ได้รับการยืนยันว่าต้องแก้ไขเพื่อเปลี่ยนเวอร์ชันเกมด้วยตนเองในเซิร์ฟเวอร์มาตรฐาน ไฟล์คอนฟิกเกม Palworld ที่เกี่ยวข้องภายใต้ **Configs** มักใช้สำหรับการตั้งค่าเซิร์ฟเวอร์ เช่น กฎเกม ไม่ใช่สำหรับดาวน์โหลดเวอร์ชันเซิร์ฟเวอร์ใหม่

ไฟล์ตั้งค่าที่ใช้บ่อยของ Palworld คือ:

| ไฟล์ | จุดประสงค์ทั่วไป | ที่ตั้ง |
| --- | --- | --- |
| `PalWorldSettings.ini` | การตั้งค่าเกมเพลย์และพฤติกรรมเซิร์ฟเวอร์ | การจัดการเซิร์ฟเวอร์เกมในส่วน **Configs** |

:::note ไม่มีการระบุเวอร์ชันด้วยตนเอง
ไม่มีคีย์ใน `PalWorldSettings.ini` ที่ได้รับการยืนยันสำหรับบังคับให้อัปเดตเวอร์ชันเซิร์ฟเวอร์ Palworld ในการตั้งค่า ZAP-Hosting ปกติ หากเป้าหมายของคุณคือแค่การอัปเดตซอฟต์แวร์เซิร์ฟเวอร์ การแก้ไข `PalWorldSettings.ini` โดยปกติไม่จำเป็น
:::

## อัปเดตเซิร์ฟเวอร์

เมื่อคุณยืนยันสิทธิ์เข้าถึงเซิร์ฟเวอร์และตรวจสอบการตั้งค่าแล้ว คุณสามารถเริ่มกระบวนการอัปเดตได้

### รีสตาร์ทเซิร์ฟเวอร์เพื่อเรียกตรวจสอบอัปเดต

วิธีหลักคือการรีสตาร์ทเซิร์ฟเวอร์ บนเซิร์ฟเวอร์ Palworld ที่โฮสต์หลายแห่ง การเริ่มต้นจะเรียกการตรวจสอบอัปเดตเกมที่มีอยู่

1. หยุดหรือรีสตาร์ทเซิร์ฟเวอร์ Palworld ของคุณจากเว็บอินเทอร์เฟซ ZAP-Hosting
2. รอจนกว่าเซิร์ฟเวอร์จะปิดตัวลงอย่างสมบูรณ์
3. เริ่มเซิร์ฟเวอร์อีกครั้ง
4. รอหลายๆ นาทีเพื่อให้กระบวนการเริ่มต้นและอัปเดตเสร็จสมบูรณ์

หากบริการของคุณเปิดใช้งานการอัปเดตอัตโนมัติ การรีสตาร์ทนี้จะทำให้เซิร์ฟเวอร์ดาวน์โหลดและติดตั้งอัปเดต Palworld ล่าสุดโดยอัตโนมัติ

### หากปิดใช้งานการอัปเดตอัตโนมัติ

ถ้าบริการของคุณตั้งค่าไม่ให้อัปเดตอัตโนมัติ คุณต้องรีสตาร์ทเซิร์ฟเวอร์ด้วยตนเองหลังจากแต่ละแพตช์หรือเวอร์ชันใหม่ของ Palworld ถูกปล่อยออกมา

ใช้ขั้นตอนเดียวกันนี้:

1. หยุดเซิร์ฟเวอร์
2. เริ่มเซิร์ฟเวอร์อีกครั้ง
3. รอให้เซิร์ฟเวอร์เริ่มต้นเสร็จ

:::tip วิธีปฏิบัติที่ดีที่สุดหลังปล่อย Palworld ใหม่
หลังจากประกาศวันปล่อยหรือปล่อยแพตช์ Palworld ใหม่ ให้รีสตาร์ทเซิร์ฟเวอร์ในช่วงเวลาที่มีผู้เล่นน้อย เพื่อหลีกเลี่ยงปัญหาการเชื่อมต่อของผู้เล่นที่เกิดจากความไม่ตรงกันของเวอร์ชันไคลเอนต์และเซิร์ฟเวอร์
:::

## ตรวจสอบว่าอัปเดตถูกนำไปใช้แล้ว

หลังจากเซิร์ฟเวอร์เริ่มต้นอีกครั้ง คุณควรยืนยันว่าเวอร์ชันใหม่ถูกใช้งานแล้ว

### ตรวจสอบผลลัพธ์ใน Console

เปิด **Console** ในการจัดการเซิร์ฟเวอร์เกมของคุณและตรวจสอบบันทึกการเริ่มต้น ดูว่ามีสัญญาณว่าเซิร์ฟเวอร์เริ่มต้นปกติและไม่มีข้อผิดพลาดเกี่ยวกับการอัปเดตหรือการตรวจสอบไฟล์

เนื่องจากบรรทัดบันทึกอาจแตกต่างกันตามเวอร์ชันเซิร์ฟเวอร์ ให้เน้นที่เซิร์ฟเวอร์เริ่มต้นสำเร็จและรับการเชื่อมต่อจากไคลเอนต์ที่ใช้เวอร์ชันเกม Palworld ล่าสุด

### ใช้คำสั่ง `info`

ถ้า Console เซิร์ฟเวอร์ของคุณรองรับ ให้รันคำสั่งนี้:

```text
info
```

คำสั่งนี้ใช้ตรวจสอบข้อมูลเซิร์ฟเวอร์หลังเริ่มต้น

| คำสั่ง | จุดประสงค์ |
| --- | --- |
| `info` | แสดงข้อมูลเซิร์ฟเวอร์เพื่อตรวจสอบหลังอัปเดต |

:::note ความพร้อมใช้งานของคำสั่ง
การรองรับคำสั่งใน Console อาจแตกต่างกันตามการติดตั้งเซิร์ฟเวอร์ Palworld และวิธีที่โฮสต์เปิดเผยการเข้าถึง Console หาก `info` ไม่แสดงผลลัพธ์ที่เป็นประโยชน์ในสภาพแวดล้อมของคุณ ให้ใช้บันทึกการเริ่มต้นและทดสอบการเชื่อมต่อจากไคลเอนต์เกมที่อัปเดตแทน
:::

## แก้ไขปัญหาการอัปเดตล้มเหลว

ถ้ารีสตาร์ทแล้วเซิร์ฟเวอร์ไม่อัปเดต คุณควรใช้ตัวเลือกกู้คืนที่มีในแผงควบคุม ZAP-Hosting

### รีติดตั้งหรือยืนยันไฟล์เซิร์ฟเวอร์

ถ้าเซิร์ฟเวอร์ยังดูเหมือนใช้เวอร์ชันเก่าหลังรีสตาร์ท:

1. หยุดเซิร์ฟเวอร์อย่างสมบูรณ์
2. เปิดตัวเลือกรีติดตั้งหรือกู้คืนในแผงจัดการเซิร์ฟเวอร์เกม ZAP-Hosting ของคุณ
3. หากมี ให้ใช้ตัวเลือก **Verify integrity** หรือตรวจสอบไฟล์ที่คล้ายกัน
4. เริ่มเซิร์ฟเวอร์อีกครั้งหลังจากกระบวนการเสร็จสิ้น

กระบวนการนี้จะตรวจสอบหรือดาวน์โหลดไฟล์เซิร์ฟเวอร์ Palworld ใหม่ และช่วยแก้ไขปัญหาการอัปเดตที่ไม่สมบูรณ์หรือผิดพลาด

:::caution ระวังข้อมูลสำรอง
ก่อนใช้ฟังก์ชันที่เกี่ยวกับการรีติดตั้ง ให้แน่ใจว่าคุณเข้าใจว่าตัวเลือกที่เลือกมีผลกับไฟล์เกมเท่านั้นหรือรวมถึงข้อมูลโลกด้วย หากแผงควบคุมไม่อธิบายชัดเจน ให้สำรองข้อมูลก่อนหรือสอบถามฝ่ายสนับสนุนก่อนดำเนินการ
:::

### ยืนยันว่าเวอร์ชันไคลเอนต์และเซิร์ฟเวอร์ตรงกัน

บางครั้งเซิร์ฟเวอร์อัปเดตถูกต้องแล้ว แต่ผู้เล่นยังไม่สามารถเข้าร่วมได้เพราะไคลเอนต์เกมในเครื่องของพวกเขาเป็นเวอร์ชันต่างกัน

ตรวจสอบสิ่งต่อไปนี้:

| ตรวจสอบ | เหตุผล |
| --- | --- |
| เซิร์ฟเวอร์รีสตาร์ทหลังแพตช์ | การเริ่มต้นมักจะเรียกการอัปเดต |
| ติดตั้งไคลเอนต์เวอร์ชันล่าสุด | ผู้เล่นต้องใช้เวอร์ชันเกมเดียวกัน |
| ไม่มีข้อผิดพลาดใน Console | ข้อผิดพลาดอาจขัดขวางการอัปเดต |
| ตรวจสอบไฟล์เสร็จสมบูรณ์ | ไฟล์เสียหายอาจบล็อกการอัปเดต |

## สิ่งที่ต้องแก้ไขใน Configs

เนื่องจากคู่มือนี้ครอบคลุมกระบวนการด้วยตนเองและกล่าวถึง **Configs** จึงสำคัญที่ต้องชี้แจงขอบเขต:

- ไฟล์คอนฟิก Palworld ใน **Configs** ใช้สำหรับตั้งค่าเซิร์ฟเวอร์
- ไม่มีการยืนยันว่ามีคีย์ใน `PalWorldSettings.ini` ที่ดาวน์โหลดหรือใช้การอัปเดตซอฟต์แวร์เซิร์ฟเวอร์ด้วยตนเอง
- สำหรับการอัปเดตเวอร์ชันปกติ โดยทั่วไปคุณไม่ต้องเปลี่ยนค่าใดในไฟล์คอนฟิก
- การดำเนินการที่ต้องทำคือ **รีสตาร์ทเซิร์ฟเวอร์** ตามด้วย **ตรวจสอบไฟล์หรือรีติดตั้ง** เฉพาะเมื่อการอัปเดตล้มเหลวเท่านั้น

หาก ZAP-Hosting เปิดเผยตัวเลือกสลับอัปเดตเฉพาะหรือพารามิเตอร์เริ่มต้นในแผงควบคุมในอนาคต คุณควรใช้ป้ายชื่อที่แสดงในอินเทอร์เฟซของคุณแทนการเพิ่มคีย์ที่ไม่ได้รับการสนับสนุนในไฟล์คอนฟิก

:::danger หลีกเลี่ยงการเพิ่มคีย์คอนฟิกที่ไม่ได้รับการยืนยัน
อย่าเพิ่มคำสั่งอัปเดตแบบสุ่ม พารามิเตอร์ SteamCMD หรือคีย์ที่ไม่ได้รับการบันทึกใน `PalWorldSettings.ini` หรือไฟล์อื่นใน **Configs** เว้นแต่จะมีเอกสารชัดเจนสำหรับบริการ Palworld ของคุณบน ZAP-Hosting รายการที่ไม่ได้รับการสนับสนุนจะไม่อัปเดตเซิร์ฟเวอร์อย่างน่าเชื่อถือและอาจทำให้เกิดปัญหาการตั้งค่า
:::

## หลังการอัปเดต

เมื่อการอัปเดตเสร็จสมบูรณ์:

1. ตรวจสอบให้แน่ใจว่าเซิร์ฟเวอร์ทำงานปกติ
2. ตรวจสอบ Console ว่ามีข้อผิดพลาดหรือไม่
3. ทดสอบการเข้าร่วมเซิร์ฟเวอร์ด้วยไคลเอนต์ Palworld ที่อัปเดตแล้ว
4. รันคำสั่ง `info` ใน Console หากรองรับ

ตอนนี้เซิร์ฟเวอร์ของคุณควรพร้อมสำหรับผู้เล่นที่ใช้เวอร์ชันล่าสุดแล้ว

## Conclusion

ยินดีด้วย คุณได้อัปเดตเซิร์ฟเวอร์ Palworld ของคุณเรียบร้อยแล้ว สำหรับคำถามเพิ่มเติมหรือต้องการความช่วยเหลือ อย่าลังเลที่จะติดต่อทีมสนับสนุนของเรา ซึ่งพร้อมให้บริการทุกวันเพื่อช่วยเหลือคุณ! 🙂
