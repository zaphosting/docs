## Introduction

Palworld ใช้ *รหัสเทคโนโลยี* เพื่อระบุเทคโนโลยีที่ปลดล็อกได้และการตั้งค่าที่เกี่ยวข้องกับไอเท็มบางอย่าง ในคู่มือนี้ คุณจะได้เรียนรู้วิธีปิดการใช้งานเทคโนโลยีเฉพาะบนเซิร์ฟเวอร์ Palworld ของคุณที่ ZAP-Hosting โดยแก้ไขรายการคอนฟิกที่ถูกต้องด้วยตนเอง

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่าคุณสามารถเข้าถึงเซิร์ฟเวอร์เกม Palworld ของคุณในเว็บอินเทอร์เฟซของ ZAP-Hosting และมีสิทธิ์แก้ไขไฟล์คอนฟิกเซิร์ฟเวอร์

:::info สิทธิ์ที่ต้องใช้
คุณต้องมีสิทธิ์เข้าถึงการจัดการเซิร์ฟเวอร์ Palworld และส่วน `Configs` ในแผงควบคุม ZAP-Hosting เพื่อทำการตั้งค่านี้ให้เสร็จสมบูรณ์
:::

:::note แหล่งที่มาของรหัสเทคโนโลยี
รหัสเทคโนโลยีของ Palworld เป็นสตริงภายในที่เกมกำหนด เช่น `GrapplingGun` หรือ `SkillUnlock_JetDragon` ไม่มีรายการอย่างเป็นทางการในแผงควบคุม ZAP-Hosting ดังนั้นคุณต้องใช้แหล่งอ้างอิงภายนอกที่เชื่อถือได้สำหรับรหัสที่ถูกต้อง
:::

## ทำความเข้าใจรหัสเทคโนโลยี

รหัสเทคโนโลยีเป็นตัวระบุภายในที่ Palworld ใช้สำหรับเทคโนโลยีที่ปลดล็อกได้ แทนที่จะใช้ชื่อที่เห็นในเกม เซิร์ฟเวอร์จะต้องการสตริงรหัสที่ถูกต้องเป๊ะๆ

สำหรับการปิดการใช้งานเทคโนโลยี Palworld ใช้การตั้งค่า `DenyTechnologyList` ซึ่งรับค่ารายการรหัสเทคโนโลยีที่คั่นด้วยเครื่องหมายจุลภาค

### `DenyTechnologyList` ทำงานอย่างไร

เมื่อคุณเพิ่มรหัสเทคโนโลยีที่ถูกต้องลงใน `DenyTechnologyList` เทคโนโลยีเหล่านั้นจะถูกบล็อกบนเซิร์ฟเวอร์ของคุณ เหมาะสำหรับการจำกัดความก้าวหน้า ลบเครื่องมือเคลื่อนที่บางอย่าง หรือปรับแต่งกฎการเล่นสำหรับชุมชนของคุณ

### รูปแบบค่าที่รองรับ

ค่าต้องป้อนเป็นรายการรหัสเทคโนโลยีที่คั่นด้วยจุลภาคโดยไม่มีคำอธิบายเพิ่มเติม

| คีย์คอนฟิก | จุดประสงค์ | รูปแบบ | ตัวอย่าง |
|---|---|---|---|
| `DenyTechnologyList` | ปิดการใช้งานเทคโนโลยีที่เลือก | สตริงรหัสเทคโนโลยีคั่นด้วยจุลภาค | `GrapplingGun,GrapplingGun2,SkillUnlock_JetDragon` |

:::caution ต้องตรงกับรหัสเป๊ะ
รหัสเทคโนโลยีต้องตรงกับค่าภายในของเกมอย่างแม่นยำ หากสะกดผิดหรือไม่ถูกต้องสำหรับเวอร์ชัน Palworld ปัจจุบัน การตั้งค่าอาจไม่ทำงานตามที่คาดหวัง
:::

## เปิดไฟล์คอนฟิกที่ถูกต้อง

บน ZAP-Hosting การเปลี่ยนแปลงนี้ทำได้โดยการแก้ไขไฟล์คอนฟิก Palworld ด้วยตนเอง

### ไฟล์ที่ต้องแก้ไข

คุณต้องแก้ไขไฟล์นี้:

```ini
PalWorldSettings.ini
```

### วิธีหาไฟล์ในอินเทอร์เฟซ ZAP-Hosting

เปิดการจัดการเซิร์ฟเวอร์เกม Palworld ของคุณ จากนั้นไปที่:

```text
Configs
```

จากนั้นเปิดไฟล์ `PalWorldSettings.ini`

:::tip ตำแหน่งคอนฟิกใน ZAP-Hosting
ถ้าเซิร์ฟเวอร์ของคุณมีไฟล์แก้ไขได้หลายไฟล์ ให้แน่ใจว่าเลือก `PalWorldSettings.ini` เพราะไฟล์นี้ใช้สำหรับตั้งค่าเซิร์ฟเวอร์ที่เกี่ยวข้องกับการเล่นเกม เช่น `DenyTechnologyList`
:::

## แก้ไขการตั้งค่ารหัสเทคโนโลยี

เมื่อเปิด `PalWorldSettings.ini` แล้ว ให้ค้นหารายการตัวเลือกเซิร์ฟเวอร์และเพิ่มหรือแก้ไขรายการ `DenyTechnologyList`

### เพิ่มรหัสเทคโนโลยีใน `DenyTechnologyList`

ใช้รายการรหัสเทคโนโลยีที่คั่นด้วยจุลภาคสำหรับเทคโนโลยีที่คุณต้องการปิดการใช้งาน

ตัวอย่าง:

```ini
DenyTechnologyList="GrapplingGun,GrapplingGun2,SkillUnlock_JetDragon"
```

ตัวอย่างนี้ปิดการใช้งาน:

| รหัสเทคโนโลยี | ความหมาย |
|---|---|
| `GrapplingGun` | ปืนเกี่ยว |
| `GrapplingGun2` | ปืนเกี่ยวรุ่นสูงกว่า |
| `SkillUnlock_JetDragon` | ปลดล็อก JetDragon |

:::note รูปแบบเครื่องหมายคำพูด
ขึ้นอยู่กับโครงสร้างของรายการ `PalWorldSettings.ini` ที่มีอยู่ ค่าอาจอยู่ภายในบล็อกตัวเลือกขนาดใหญ่ ให้รักษารูปแบบไวยากรณ์ที่ใช้ในไฟล์ของคุณไว้และเปลี่ยนแค่ค่าของ `DenyTechnologyList` เท่านั้น
:::

### ตัวอย่างในบล็อกตัวเลือก

บนเซิร์ฟเวอร์ Palworld หลายแห่ง การตั้งค่าจะถูกเก็บไว้ในบรรทัด `OptionSettings` ขนาดใหญ่ ในกรณีนั้น รายการอาจมีลักษณะดังนี้:

```ini
OptionSettings=(Difficulty=None,DayTimeSpeedRate=1.000000,NightTimeSpeedRate=1.000000,DenyTechnologyList="GrapplingGun,GrapplingGun2,SkillUnlock_JetDragon")
```

ถ้า `DenyTechnologyList` ยังไม่มี ให้เพิ่มเข้าไปในบล็อก `OptionSettings=(...)` เดียวกันและคั่นด้วยจุลภาคจากรายการอื่น

:::caution รักษาไวยากรณ์เดิม
อย่าลบการตั้งค่าอื่นใน `OptionSettings` การขาดจุลภาค วงเล็บ หรือเครื่องหมายคำพูด อาจทำให้คอนฟิกโหลดไม่ถูกต้อง
:::

## เลือกรหัสเทคโนโลยีที่ถูกต้อง

คุณต้องใช้รหัสเทคโนโลยีภายในที่ถูกต้อง ไม่ใช่ชื่อที่แสดงในเกม

### ตัวอย่างรหัสเทคโนโลยี

ตัวอย่างรหัสเทคโนโลยีที่รู้จักใน Palworld ได้แก่:

| รหัสเทคโนโลยี | ความหมายตัวอย่าง |
|---|---|
| `AIcore` | แกน AI |
| `GrapplingGun` | ปืนเกี่ยว |
| `GrapplingGun2` | ปืนเกี่ยวรุ่นต่างๆ |
| `GrapplingGun3` | ปืนเกี่ยวรุ่นต่างๆ |
| `GrapplingGun4` | ปืนเกี่ยวรุ่นต่างๆ |
| `GrapplingGun5` | ปืนเกี่ยวรุ่นต่างๆ |
| `SkillUnlock_JetDragon` | ปลดล็อก JetDragon |
| `SkillUnlock_IceHorse` | ปลดล็อก Ice Horse |
| `PALBOX` | เทคโนโลยีที่เกี่ยวกับ Palbox |
| `RepairBench` | ม้านั่งซ่อม |

เนื่องจาก Palworld มีการอัปเดต รายการรหัสทั้งหมดอาจเปลี่ยนแปลงได้ตามเวลา หากต้องการรายการอ้างอิงที่กว้างขึ้น ให้ตรวจสอบรหัสกับแหล่งข้อมูลที่เชื่อถือได้และเป็นปัจจุบันก่อนใช้งาน

### การใช้รหัสในการตั้งค่าอื่น

รหัสเทคโนโลยีภายในอาจถูกใช้ในตัวเลือกคอนฟิก Palworld อื่นๆ ตัวอย่างที่รู้จักคือ:

| คีย์คอนฟิก | จุดประสงค์ |
|---|---|
| `AdditionalDropItemWhenPlayerKillingInPvPMode` | กำหนดไอเท็มดรอปพิเศษเมื่อฆ่าผู้เล่นในโหมด PvP |

:::info การตั้งค่า PvP ที่เกี่ยวข้อง
ถ้าคุณวางแผนใช้รหัสสำหรับปรับแต่งไอเท็มดรอปใน PvP ให้ตรวจสอบว่าประเภทของรหัสที่ `AdditionalDropItemWhenPlayerKillingInPvPMode` ต้องการตรงกับไอเท็มที่คุณจะใช้ คู่มือนี้เน้นเฉพาะ `DenyTechnologyList`
:::

## บันทึกและรีสตาร์ทเซิร์ฟเวอร์

หลังแก้ไขไฟล์แล้ว ให้บันทึกการเปลี่ยนแปลงในอินเทอร์เฟซ ZAP-Hosting

เพื่อให้คอนฟิกใหม่มีผล ให้รีสตาร์ทเซิร์ฟเวอร์ Palworld ของคุณ

### การดำเนินการที่ต้องทำหลังแก้ไข

| การดำเนินการ | จำเป็นหรือไม่ |
|---|---|
| บันทึกไฟล์ `PalWorldSettings.ini` | จำเป็น |
| รีสตาร์ทเซิร์ฟเวอร์ | จำเป็น |
| รันคำสั่งคอนโซลเพิ่มเติม | ไม่มีคำสั่งยืนยันว่าจำเป็น |

ต้องรีสตาร์ทเพราะ Palworld จะอ่านการตั้งค่าเซิร์ฟเวอร์ตอนเริ่มต้น หากไม่รีสตาร์ท การจำกัดเทคโนโลยีใหม่อาจไม่ทำงาน

:::tip ทดสอบหลังรีสตาร์ท
หลังเซิร์ฟเวอร์รีสตาร์ทแล้ว เข้าร่วมเซิร์ฟเวอร์และตรวจสอบว่าเทคโนโลยีที่เลือกถูกปิดใช้งานตามที่ตั้งใจไว้ ช่วยยืนยันว่ารหัสและไวยากรณ์ถูกต้อง
:::

## การแก้ไขปัญหา

ถ้าเทคโนโลยียังใช้งานได้หลังรีสตาร์ท ให้ตรวจสอบจุดต่อไปนี้

### ตรวจสอบการสะกดรหัส

ตรวจสอบให้แน่ใจว่ารหัสเทคโนโลยีแต่ละตัวเขียนถูกต้องตามที่ต้องการ รวมถึงตัวพิมพ์ใหญ่พิมพ์เล็ก

### ตรวจสอบไวยากรณ์คอนฟิก

ถ้าแก้ไขบล็อก `OptionSettings=(...)` ให้ตรวจสอบว่า:

- แต่ละการตั้งค่าคั่นด้วยจุลภาค
- เครื่องหมายคำพูดเปิด-ปิดถูกต้อง
- วงเล็บครบถ้วน
- `DenyTechnologyList` อยู่ในบล็อกการตั้งค่าที่ถูกต้อง

### ยืนยันว่าเซิร์ฟเวอร์รีสตาร์ทสำเร็จ

ถ้าเซิร์ฟเวอร์ไม่รีสตาร์ทอย่างถูกต้อง คอนฟิกที่อัปเดตอาจไม่ได้โหลด

:::danger ความเสี่ยงจากคอนฟิกไม่ถูกต้อง
ไฟล์ `PalWorldSettings.ini` ที่ฟอร์แมตผิดอาจทำให้การตั้งค่าโหลดไม่สำเร็จ หากเกิดเหตุการณ์นี้ ให้คืนค่าไฟล์เวอร์ชันก่อนหน้าที่ใช้งานได้และทำการเปลี่ยนแปลงใหม่อย่างระมัดระวัง
:::

## Conclusion

ยินดีด้วย คุณได้ปิดการใช้งานเทคโนโลยีเฉพาะบนเซิร์ฟเวอร์ Palworld ของคุณโดยใช้รหัสเทคโนโลยีเรียบร้อยแล้ว สำหรับคำถามเพิ่มเติมหรือต้องการความช่วยเหลือ อย่าลังเลที่จะติดต่อทีมซัพพอร์ตของเรา ซึ่งพร้อมให้บริการทุกวันเพื่อช่วยเหลือคุณ! 🙂
