## Introduction

Palworld ใช้ *รหัสเทคโนโลยี* เพื่อระบุเทคโนโลยีที่ปลดล็อกได้และการตั้งค่าบางอย่างที่เกี่ยวข้องกับไอเท็มในคอนฟิกเซิร์ฟเวอร์ ในคู่มือนี้ คุณจะได้เรียนรู้วิธีปิดการใช้งานเทคโนโลยีเฉพาะโดยแก้ไขการตั้งค่า `DenyTechnologyList` ในคอนฟิกเซิร์ฟเวอร์ Palworld ของคุณบน ZAP-Hosting



## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่าคุณมีสิทธิ์เข้าถึงเซิร์ฟเวอร์เกม Palworld ของคุณในเว็บอินเทอร์เฟซ ZAP-Hosting และมีสิทธิ์แก้ไขไฟล์คอนฟิก

:::info การเข้าถึงการตั้งค่า
คุณต้องมีสิทธิ์เข้าถึงการจัดการเซิร์ฟเวอร์เกมและส่วน `Configs` เพื่อแก้ไขไฟล์ `PalWorldSettings.ini`
:::

:::note แหล่งที่มาของรหัสเทคโนโลยี
รหัสเทคโนโลยีของ Palworld เป็นค่าที่เป็นสตริง เช่น `GrapplingGun`, `GrapplingGun2` หรือ `SkillUnlock_JetDragon` รายการอ้างอิงจากแหล่งภายนอกล่าสุดดูได้ที่นี่: [Game Host Bros - Palworld Technology IDs](https://www.gamehostbros.com/guides/games/palworld/technology-ids)

เนื่องจากการอัปเดตของ Palworld อาจเปลี่ยนแปลงเทคโนโลยีที่มีอยู่ คุณควรตรวจสอบให้แน่ใจว่ารหัสที่คุณจะใช้ยังคงมีอยู่ในเวอร์ชันเกมปัจจุบันเสมอ
:::

## ทำความเข้าใจรหัสเทคโนโลยี

รหัสเทคโนโลยีเป็นตัวระบุภายในที่ Palworld ใช้สำหรับรายการเทคโนโลยีที่ปลดล็อกได้ บนเซิร์ฟเวอร์เฉพาะ รหัสเหล่านี้สามารถใช้ในตัวเลือกคอนฟิกเฉพาะเพื่อควบคุมพฤติกรรมการเล่นเกม

การตั้งค่าที่เกี่ยวข้องมากที่สุดสำหรับหัวข้อนี้คือ `DenyTechnologyList` ซึ่งช่วยให้คุณบล็อกเทคโนโลยีที่เลือกไม่ให้ปลดล็อกหรือใช้งานบนเซิร์ฟเวอร์ของคุณ

### การใช้งานคอนฟิกที่รองรับ

ตารางต่อไปนี้แสดงคีย์คอนฟิกที่เกี่ยวข้องซึ่งครอบคลุมในคู่มือนี้:

| คีย์คอนฟิก | จุดประสงค์ | รูปแบบค่า |
| --- | --- | --- |
| `DenyTechnologyList` | ปิดการใช้งานเทคโนโลยีเฉพาะบนเซิร์ฟเวอร์ | รายการรหัสเทคโนโลยีแบบคั่นด้วยเครื่องหมายจุลภาค |

### ตัวอย่างรหัสเทคโนโลยี

รหัสต่อไปนี้เป็นตัวอย่างที่มักถูกอ้างอิง:

| รหัสเทคโนโลยี | ความหมายตัวอย่าง |
| --- | --- |
| `GrapplingGun` | ปืนเกี่ยว Grappling Gun |
| `GrapplingGun2` | ปืนเกี่ยวระดับสูงขึ้น |
| `SkillUnlock_JetDragon` | ปลดล็อกที่เกี่ยวกับ Jetragon |
| `SkillUnlock_IceHorse` | ปลดล็อกที่เกี่ยวกับ Frostallion |
| `PALBOX` | เทคโนโลยีที่เกี่ยวกับ Palbox |
| `RepairBench` | ม้านั่งซ่อมบำรุง |
| `AIcore` | แกน AI |

:::caution ใช้ค่ารหัสที่ถูกต้องเท่านั้น
รหัสเทคโนโลยีเป็นค่าที่แยกแยะตัวพิมพ์ใหญ่-เล็ก หากคุณป้อนรหัสผิด Palworld อาจไม่สนใจและเทคโนโลยีนั้นจะไม่ถูกปิดใช้งานตามที่ตั้งใจไว้
:::

## เปิดไฟล์คอนฟิก Palworld

เพื่อกำหนดค่ารหัสเทคโนโลยีบนเซิร์ฟเวอร์ ZAP-Hosting ของคุณ คุณต้องแก้ไขไฟล์ตั้งค่า Palworld ที่ถูกต้องด้วยตนเอง

### ค้นหาไฟล์ในอินเทอร์เฟซ ZAP-Hosting

1. เข้าสู่ระบบเว็บอินเทอร์เฟซ ZAP-Hosting
2. เปิดเซิร์ฟเวอร์เกม **Palworld** ของคุณ
3. ไปที่ **Configs** ในการจัดการเซิร์ฟเวอร์เกม
4. เปิดไฟล์ `PalWorldSettings.ini`

นี่คือไฟล์คอนฟิกที่เก็บและแก้ไขการตั้งค่า `DenyTechnologyList`



### ค้นหาการตั้งค่าที่เกี่ยวข้อง

ในไฟล์ `PalWorldSettings.ini` ให้มองหาบล็อกตัวเลือกเซิร์ฟเวอร์ที่มีการตั้งค่า Palworld ของคุณ

คุณต้องค้นหาหรือเพิ่มรายการ `DenyTechnologyList`

:::tip ค้นหาไฟล์อย่างรวดเร็ว
ใช้ฟังก์ชันค้นหาในเบราว์เซอร์ของคุณโดยกด `CTRL` + `F` แล้วค้นหา `DenyTechnologyList` เพื่อหาการตั้งค่านี้ได้เร็วขึ้น
:::

## กำหนดค่า `DenyTechnologyList`

ตอนนี้คุณสามารถกำหนดได้ว่าเทคโนโลยีใดควรถูกบล็อกบนเซิร์ฟเวอร์ของคุณ

### รูปแบบค่า

`DenyTechnologyList` ใช้รายการรหัสเทคโนโลยีที่คั่นด้วยเครื่องหมายจุลภาค

ตัวอย่างรูปแบบ:

```ini
DenyTechnologyList=GrapplingGun,GrapplingGun2,SkillUnlock_JetDragon
```

แต่ละรายการต้องเป็นรหัสเทคโนโลยี Palworld ที่ถูกต้อง ห้ามเพิ่มคำอธิบาย ช่องว่างในรหัส หรืออักขระที่ไม่รองรับ

### เพิ่มหรือแก้ไขการตั้งค่า

ถ้ามีการตั้งค่านี้อยู่แล้ว ให้แทนที่ค่าปัจจุบันด้วยรายการที่คุณต้องการ

ถ้ายังไม่มี ให้เพิ่มเข้าไปในส่วนการตั้งค่าเซิร์ฟเวอร์ที่เหมาะสมในไฟล์ `PalWorldSettings.ini`

ตัวอย่าง:

```ini
DenyTechnologyList=GrapplingGun,GrapplingGun2,GrapplingGun3,SkillUnlock_JetDragon,PALBOX,RepairBench
```

ตัวอย่างนี้ปิดการใช้งานเทคโนโลยีหลายรายการตามรหัส

### ตัวอย่างอ้างอิงการตั้งค่า

| รายการตัวอย่าง | ผลลัพธ์ |
| --- | --- |
| `DenyTechnologyList=GrapplingGun` | ปิดการใช้งานเทคโนโลยีปืนเกี่ยว Grappling Gun พื้นฐานเท่านั้น |
| `DenyTechnologyList=GrapplingGun,GrapplingGun2` | ปิดการใช้งานเทคโนโลยีปืนเกี่ยวหลายระดับ |
| `DenyTechnologyList=SkillUnlock_JetDragon,SkillUnlock_IceHorse` | ปิดการใช้งานเทคโนโลยีปลดล็อกพิเศษที่เลือก |

:::note การใช้งานรหัสไอเท็มที่เกี่ยวข้อง
การตั้งค่าไอเท็มบางอย่างของ Palworld ก็ใช้ค่ารหัสเช่นกัน เช่น รายการอ้างอิงภายนอกระบุว่า `AdditionalDropItemWhenPlayerKillingInPvPMode` สามารถใช้รหัส Palworld สำหรับไอเท็มดรอปในโหมด PvP ได้ แต่คู่มือนี้เน้นเฉพาะที่ `DenyTechnologyList`
:::

## บันทึกและใช้การเปลี่ยนแปลง

หลังจากแก้ไขคอนฟิกแล้ว คุณต้องบันทึกไฟล์และรีสตาร์ทเซิร์ฟเวอร์เพื่อให้ Palworld โหลดการตั้งค่าใหม่

### บันทึกไฟล์

หลังจากแก้ไขไฟล์ `PalWorldSettings.ini` เสร็จ:

1. บันทึกการเปลี่ยนแปลงในตัวแก้ไข `Configs`
2. ตรวจสอบรายการอีกครั้งเพื่อยืนยันว่ารหัสสะกดถูกต้อง

### รีสตาร์ทเซิร์ฟเวอร์

เมื่อบันทึกไฟล์แล้ว ให้รีสตาร์ทเซิร์ฟเวอร์ Palworld ของคุณจากการจัดการเซิร์ฟเวอร์เกม ZAP-Hosting

การรีสตาร์ทนี้จำเป็นเพราะการเปลี่ยนแปลงคอนฟิกใน `PalWorldSettings.ini` จะไม่ถูกนำไปใช้จนกว่าเซิร์ฟเวอร์จะเริ่มใหม่พร้อมไฟล์ที่อัปเดต

:::info จำเป็นต้องรีสตาร์ทเซิร์ฟเวอร์
ต้องรีสตาร์ทเซิร์ฟเวอร์หลังจากเปลี่ยนแปลง `DenyTechnologyList` โดยทั่วไปไม่ต้องใช้คำสั่งในเกมเพิ่มเติมเมื่อใช้วิธีแก้ไขไฟล์คอนฟิกนี้
:::

## ตรวจสอบว่าเทคโนโลยีถูกปิดใช้งานแล้ว

หลังรีสตาร์ท คุณควรยืนยันว่าการตั้งค่าทำงานตามที่คาดไว้

### สิ่งที่ต้องตรวจสอบ

คุณสามารถตรวจสอบผลลัพธ์โดยดูว่าเทคโนโลยีที่เลือกยังใช้งานได้ในเกมหรือไม่

ใช้รายการตรวจสอบนี้:

| ตรวจสอบ | ผลลัพธ์ที่คาดหวัง |
| --- | --- |
| เซิร์ฟเวอร์รีสตาร์ทสำเร็จ | เซิร์ฟเวอร์กลับมาออนไลน์ตามปกติ |
| บันทึกไฟล์ `PalWorldSettings.ini` ถูกต้อง | รายการ `DenyTechnologyList` ยังอยู่ในไฟล์ |
| ทดสอบเทคโนโลยีที่ปิดใช้งานในเกม | เทคโนโลยีที่เลือกไม่สามารถใช้งานได้ตามที่คาดไว้ |

### หากการตั้งค่าไม่ทำงาน

ถ้าเทคโนโลยียังใช้งานได้ ให้ตรวจสอบสิ่งต่อไปนี้:

| ปัญหาที่เป็นไปได้ | สิ่งที่ต้องตรวจสอบ |
| --- | --- |
| รหัสไม่ถูกต้อง | ยืนยันว่ารหัสเทคโนโลยีตรงกับเวอร์ชันเกมปัจจุบันอย่างแม่นยำ |
| ปัญหารูปแบบ | ตรวจสอบให้แน่ใจว่ารายการคั่นด้วยจุลภาคและเขียนเป็นสตริงรหัสล้วนๆ |
| ไฟล์ไม่ได้บันทึก | เปิดไฟล์ `PalWorldSettings.ini` อีกครั้งและยืนยันว่าค่ารายการยังอยู่ |
| เซิร์ฟเวอร์ไม่ได้รีสตาร์ท | รีสตาร์ทเซิร์ฟเวอร์อีกครั้งหลังบันทึกการเปลี่ยนแปลง |

:::caution การอัปเดตเกมอาจเปลี่ยนรหัส
Palworld มีการอัปเดตอย่างต่อเนื่องและข้อมูลเทคโนโลยีอาจเปลี่ยนแปลง หากรหัสที่เคยใช้ได้ไม่ทำงานอีก ให้ตรวจสอบกับแหล่งอ้างอิงที่เชื่อถือได้ก่อนแก้ไขปัญหาเพิ่มเติม
:::

## Conclusion

ยินดีด้วย คุณได้ปิดการใช้งานเทคโนโลยีเฉพาะบนเซิร์ฟเวอร์ Palworld ของคุณโดยใช้รหัสเทคโนโลยีเรียบร้อยแล้ว สำหรับคำถามหรือความช่วยเหลือเพิ่มเติม อย่าลังเลที่จะติดต่อทีมซัพพอร์ตของเรา ซึ่งพร้อมให้บริการทุกวันเพื่อช่วยเหลือคุณ! 🙂
