## Introduction

Palworld เก็บโลกที่คุณเล่นอยู่ในข้อมูลเซฟของเซิร์ฟเวอร์ แทนที่จะเก็บในค่าการตั้งค่าโลก ในคู่มือนี้ คุณจะได้เรียนรู้วิธีรีเซ็ตโลกเซิร์ฟเวอร์เกม Palworld บน ZAP-Hosting โดยการลบโฟลเดอร์เซฟที่มีอยู่ เพื่อให้เซิร์ฟเวอร์สร้างโลกใหม่เมื่อเริ่มต้นครั้งถัดไป

:::danger การลบข้อมูลถาวร
การรีเซ็ตโลก Palworld ของคุณจะลบโลกปัจจุบันอย่างถาวร รวมถึงความก้าวหน้าของผู้เล่น โครงสร้าง Pals และข้อมูลเซฟอื่นๆ ที่เก็บไว้ในโลกนั้น
:::



## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่าคุณสามารถเข้าถึงการจัดการเซิร์ฟเวอร์เกม Palworld ของคุณได้ และเซิร์ฟเวอร์อยู่ในสถานะออฟไลน์ก่อนที่จะลบไฟล์เซฟใดๆ

:::tip สร้างสำรองข้อมูลก่อน
ถ้าคุณอาจต้องการโลกปัจจุบันอีกครั้งในอนาคต ให้สร้างสำรองข้อมูลก่อนดำเนินการต่อ หากมีฟีเจอร์สำรองข้อมูลสำหรับผลิตภัณฑ์ของคุณ คุณสามารถใช้ฟีเจอร์สำรองข้อมูลเซิร์ฟเวอร์ หรือดาวน์โหลดโฟลเดอร์เซฟด้วยตนเองก่อนลบได้
:::

## เข้าใจวิธีการรีเซ็ตโลก Palworld

การรีเซ็ตโลก Palworld โดยทั่วไปไม่จำเป็นต้องเปลี่ยนค่าการเล่นในไฟล์คอนฟิก แต่โลกที่ใช้งานจะถูกเก็บไว้ในไดเรกทอรีเซฟของเซิร์ฟเวอร์

ตามโครงสร้างเซิร์ฟเวอร์เฉพาะ Palworld ที่เปิดเผยในปัจจุบัน โฟลเดอร์เซฟโลกมักจะอยู่ที่เส้นทางนี้:

```text
Pal/Saved/SaveGames/0/
```

ภายในไดเรกทอรีนี้ คุณจะพบโฟลเดอร์ที่มีชื่อเป็นเลขฐานสิบหกสุ่มยาว เช่น:

```text
84B5E2264EC387DEDB43179D666031A1
```

โฟลเดอร์นี้เก็บข้อมูลเซฟโลกปัจจุบัน เมื่อคุณลบโฟลเดอร์นี้และเริ่มเซิร์ฟเวอร์ใหม่ Palworld จะสร้างโลกใหม่ให้อัตโนมัติ

:::note ไม่ต้องแก้ค่าคอนฟิก
สำหรับการรีเซ็ตโลกมาตรฐาน ไม่จำเป็นต้องเพิ่มค่าคอนฟิก คำสั่งคอนโซล หรือพารามิเตอร์สตาร์ทอัพเพิ่มเติม การรีเซ็ตทำได้โดยการลบข้อมูลเซฟที่มีอยู่เท่านั้น
:::

## หยุดเซิร์ฟเวอร์

ก่อนลบไฟล์โลก ให้หยุดเซิร์ฟเวอร์ Palworld ของคุณจากการจัดการเซิร์ฟเวอร์เกม ZAP-Hosting

การลบข้อมูลเซฟขณะเซิร์ฟเวอร์กำลังทำงานอาจทำให้ไฟล์เสียหายหรือข้อมูลโลกถูกลบไม่สมบูรณ์

:::caution เซิร์ฟเวอร์ต้องออฟไลน์
ตรวจสอบให้แน่ใจว่าเซิร์ฟเวอร์หยุดทำงานอย่างสมบูรณ์ก่อนดำเนินการต่อ หากเซิร์ฟเวอร์ยังทำงานอยู่ อาจสร้างหรือล็อกไฟล์ในขณะที่คุณกำลังแก้ไข
:::

## เปิดไดเรกทอรีเซฟ

ในแผงจัดการเซิร์ฟเวอร์ Palworld ของ ZAP-Hosting ให้เปิดส่วนจัดการไฟล์และไปที่เส้นทางนี้:

```text
Pal/Saved/SaveGames/0/
```

ขึ้นอยู่กับรูปแบบผลิตภัณฑ์ของคุณ คุณอาจเข้าถึงได้ผ่านตัวจัดการไฟล์หรือส่วนเข้าถึงไฟล์ในเว็บอินเทอร์เฟซ



### อ้างอิงเส้นทาง

| รายการ | ค่า |
| --- | --- |
| เส้นทางเซฟฐาน | `Pal/Saved/SaveGames/0/` |
| ชื่อโฟลเดอร์โลก | โฟลเดอร์เลขฐานสิบหกสุ่ม |
| ตัวอย่างโฟลเดอร์ | `84B5E2264EC387DEDB43179D666031A1` |
| การดำเนินการที่ต้องทำ | ลบโฟลเดอร์โลก |

## ลบข้อมูลเซฟโลกปัจจุบัน

ในโฟลเดอร์ `Pal/Saved/SaveGames/0/` ให้หาชื่อโฟลเดอร์เลขฐานสิบหกสุ่มนั้นและลบโฟลเดอร์นั้นออกทั้งหมด

### สิ่งที่ต้องลบ

| ประเภทโฟลเดอร์ | การดำเนินการที่ต้องทำ |
| --- | --- |
| โฟลเดอร์เซฟโลกปัจจุบันใน `Pal/Saved/SaveGames/0/` | ลบออก |
| ไฟล์ `PalworldSettings.ini` หรือไฟล์คอนฟิกอื่นๆ | ไม่ต้องแก้ไขสำหรับการรีเซ็ตนี้ เว้นแต่คุณต้องการเปลี่ยนการตั้งค่าเซิร์ฟเวอร์ด้วย |

ถ้ามีโฟลเดอร์เลขฐานสิบหกเพียงโฟลเดอร์เดียวใน `Pal/Saved/SaveGames/0/` นั่นมักจะเป็นเซฟโลกที่ใช้งานอยู่ หากมีหลายโฟลเดอร์และคุณไม่แน่ใจว่าโฟลเดอร์ไหนถูกใช้ อย่าคาดเดา ในกรณีนั้นให้ตรวจสอบไฟล์เซิร์ฟเวอร์ปัจจุบันอย่างละเอียดหรือสอบถามฝ่ายสนับสนุนก่อนลบใดๆ

:::info ชี้แจงส่วนคอนฟิก
แม้ว่าการตั้งค่า Palworld หลายอย่างจะจัดการผ่านส่วน **Configs** ได้ แต่การรีเซ็ตโลกเองโดยทั่วไปไม่เสร็จสมบูรณ์ด้วยการแก้ไขไฟล์คอนฟิก การดำเนินการที่ต้องทำคือการลบโฟลเดอร์เซฟโลกจากไฟล์เซิร์ฟเวอร์
:::

## เริ่มเซิร์ฟเวอร์ใหม่อีกครั้ง

หลังจากลบโฟลเดอร์เซฟแล้ว ให้เริ่มเซิร์ฟเวอร์ Palworld ของคุณอีกครั้ง

เมื่อเริ่มต้น เซิร์ฟเวอร์จะสร้างโลกใหม่ให้อัตโนมัติ เพราะไม่มีเซฟโลกเก่าในตำแหน่งเซฟที่คาดไว้

### คำสั่งหรือการเปลี่ยนแปลงเพิ่มเติม

| งาน | จำเป็นหรือไม่ |
| --- | --- |
| แก้ไขไฟล์คอนฟิก | ไม่จำเป็น |
| รันคำสั่งในเกม | ไม่จำเป็น |
| รันคำสั่งคอนโซล | ไม่จำเป็น |
| รีสตาร์ทหรือเริ่มเซิร์ฟเวอร์หลังลบ | จำเป็น |

:::tip การเริ่มต้นครั้งแรกอาจใช้เวลานานขึ้น
การเริ่มต้นครั้งแรกหลังลบเซฟโลกอาจใช้เวลานานกว่าปกติเล็กน้อย เพราะ Palworld ต้องสร้างโลกใหม่
:::

## ตรวจสอบการรีเซ็ต

เมื่อเซิร์ฟเวอร์ออนไลน์อีกครั้ง ให้เชื่อมต่อและยืนยันว่าโลกใหม่ถูกสร้างขึ้นแล้ว

โดยปกติคุณจะตรวจสอบได้จาก:

- สถานะสปอนใหม่
- ไม่มีโครงสร้างที่ผู้เล่นสร้างไว้ก่อนหน้า
- ไม่มีความก้าวหน้าก่อนหน้า
- มีโฟลเดอร์เซฟใหม่ใน `Pal/Saved/SaveGames/0/`

ถ้าโลกเก่ายังแสดงอยู่ ให้หยุดเซิร์ฟเวอร์อีกครั้งและตรวจสอบว่าโฟลเดอร์เซฟเลขฐานสิบหกที่ถูกต้องถูกลบไปแล้ว
