## Introduction

Palworld เก็บข้อมูลโลก ความก้าวหน้าผู้เล่น และการตั้งค่าเซิร์ฟเวอร์บนเซิร์ฟเวอร์เกม ในคู่มือนี้ คุณจะได้เรียนรู้วิธีรีเซ็ตเซิร์ฟเวอร์ Palworld ของคุณบน ZAP-Hosting อย่างเต็มรูปแบบและเริ่มต้นใหม่ด้วยการติดตั้งค่าเริ่มต้นใหม่

:::danger เตือนการลบข้อมูลทั้งหมด
การรีเซ็ตเต็มรูปแบบจะลบข้อมูลเซฟ การเปลี่ยนแปลงการตั้งค่า และไฟล์เซิร์ฟเวอร์อื่น ๆ ที่เก็บไว้ในการติดตั้งปัจจุบันอย่างถาวร ควรใช้วิธีนี้เฉพาะเมื่อเป็นทางเลือกสุดท้ายเท่านั้น
:::



## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่าคุณสามารถเข้าถึงเซิร์ฟเวอร์เกม Palworld ของคุณในเว็บอินเทอร์เฟซ ZAP-Hosting และคุณไม่ต้องการข้อมูลโลกปัจจุบันอีกต่อไป

:::info สำรองข้อมูลสำคัญก่อน
หากคุณต้องการเก็บสำเนาของโลกหรือการตั้งค่าปัจจุบัน ให้สร้างสำรองข้อมูลก่อนดำเนินการต่อ เมื่อรีเซ็ตเสร็จสิ้น ข้อมูลที่ถูกลบจะไม่สามารถกู้คืนได้ตามปกติ
:::

## เข้าใจว่าการรีเซ็ตเซิร์ฟเวอร์ Palworld ทำอะไรบ้าง

การรีเซ็ต Palworld แบบเต็มรูปแบบไม่เหมือนกับการเปลี่ยนแปลงการตั้งค่าเพียงอย่างเดียวในไฟล์คอนฟิก แต่เป็นการติดตั้งเซิร์ฟเวอร์ใหม่ทั้งหมดและลบข้อมูลเซิร์ฟเวอร์ปัจจุบันออก

กระบวนการรีเซ็ตโดยทั่วไปจะลบข้อมูลดังนี้:

| ประเภทข้อมูล | ถูกลบระหว่างรีเซ็ต |
| --- | --- |
| ข้อมูลเซฟโลก | ใช่ |
| ความก้าวหน้าผู้เล่น | ใช่ |
| การเปลี่ยนแปลงการตั้งค่าเซิร์ฟเวอร์ | ใช่ |
| ม็อดหรือไฟล์กำหนดเองที่ติดตั้ง | ใช่ |
| ไฟล์เกมเริ่มต้น | ติดตั้งใหม่โดยอัตโนมัติ |

หลังรีเซ็ต เซิร์ฟเวอร์ของคุณจะเริ่มต้นด้วยการติดตั้งใหม่และการตั้งค่าเริ่มต้น

## ตรวจสอบตำแหน่งการตั้งค่าก่อน

สำหรับการเปลี่ยนแปลงการตั้งค่า Palworld ปกติ คุณสามารถเข้าถึงไฟล์ที่เกี่ยวข้องได้ในแผงจัดการเซิร์ฟเวอร์เกมของคุณภายใต้เมนู `Configs` การตั้งค่าหลักของ Palworld มักจะเก็บไว้ในไฟล์นี้:

| ไฟล์ | จุดประสงค์ |
| --- | --- |
| `PalWorldSettings.ini` | ไฟล์คอนฟิกหลักของเซิร์ฟเวอร์ Palworld |

ในอินเทอร์เฟซ ZAP-Hosting คุณมักจะเข้าถึงได้ผ่านแผงจัดการเซิร์ฟเวอร์ Palworld ของคุณในเมนู `Configs`

:::note การรีเซ็ตไม่ต้องแก้ไขคอนฟิกด้วยตนเอง
การรีเซ็ตเซิร์ฟเวอร์เต็มรูปแบบไม่จำเป็นต้องแก้ไขไฟล์ `PalWorldSettings.ini` ด้วยตนเอง ไฟล์นี้ใช้สำหรับการเปลี่ยนแปลงการตั้งค่าปกติ แต่การรีเซ็ตเต็มรูปแบบจะทำโดยการติดตั้งใหม่หรือฟอร์แมตเซิร์ฟเวอร์เพื่อสร้างไฟล์ทั้งหมดใหม่ด้วยค่าเริ่มต้น
:::

ถ้าคุณต้องการเปลี่ยนแปลงการตั้งค่าเกมเพลย์เท่านั้น แนะนำให้แก้ไขไฟล์คอนฟิกใน `Configs` แทนการรีเซ็ตเต็มรูปแบบ

## หยุดเซิร์ฟเวอร์

ก่อนเริ่มรีเซ็ต คุณต้องหยุดเซิร์ฟเวอร์ Palworld อย่างสมบูรณ์

1. เข้าสู่ระบบเว็บอินเทอร์เฟซ ZAP-Hosting
2. เปิดเซิร์ฟเวอร์เกม Palworld ของคุณ
3. หยุดเซิร์ฟเวอร์โดยใช้ตัวควบคุมในแผงจัดการเซิร์ฟเวอร์
4. รอจนสถานะเซิร์ฟเวอร์แสดงว่าออฟไลน์แล้ว

:::caution ห้ามรีเซ็ตขณะเซิร์ฟเวอร์กำลังทำงาน
ถ้าคุณเริ่มรีเซ็ตขณะที่เซิร์ฟเวอร์ยังทำงานอยู่ ไฟล์อาจไม่ถูกลบอย่างสมบูรณ์และข้อมูลเซฟอาจเกิดความไม่สอดคล้องกันได้
:::

## ติดตั้งใหม่และรีเซ็ตเซิร์ฟเวอร์

การรีเซ็ตเต็มรูปแบบใน Palworld ทำได้โดยการติดตั้งเซิร์ฟเวอร์ใหม่พร้อมตัวเลือกฟอร์แมตหรือรีเซ็ตในอินเทอร์เฟซ ZAP

### เปิดฟังก์ชันติดตั้งใหม่

ในแผงจัดการเซิร์ฟเวอร์ Palworld ของคุณ ให้ค้นหาฟังก์ชันติดตั้งใหม่หรือรีเซ็ตในส่วนจัดการเซิร์ฟเวอร์

เนื่องจากคำเรียกในอินเทอร์เฟซอาจแตกต่างกันตามเวอร์ชัน แต่อย่างไรก็ตาม ฟังก์ชันนี้มักอยู่ในส่วนจัดการเซิร์ฟเวอร์ที่มีตัวเลือกติดตั้งใหม่หรือฟอร์แมต



### เริ่มรีเซ็ตเต็มรูปแบบ

ใช้ตัวเลือกติดตั้งใหม่ที่ทำการฟอร์แมตหรือรีเซ็ตข้อมูลเซิร์ฟเวอร์ทั้งหมด

ในขั้นตอนนี้ ให้ยืนยันการดำเนินการหากแผงถามเพื่อยืนยัน

:::danger การดำเนินการนี้จะลบข้อมูลเซิร์ฟเวอร์ทั้งหมด
การติดตั้งใหม่หรือฟอร์แมตเต็มรูปแบบจะลบข้อมูลเซฟ การตั้งค่า และไฟล์เซิร์ฟเวอร์กำหนดเองทั้งหมด โปรดดำเนินการต่อเฉพาะเมื่อแน่ใจว่าต้องการรีเซ็ตทุกอย่างจริง ๆ
:::

### รอจนการติดตั้งเสร็จสิ้น

หลังยืนยันรีเซ็ต ให้รอจนกระบวนการติดตั้งใหม่เสร็จสมบูรณ์ ขึ้นอยู่กับสถานะแผงและขนาดเซิร์ฟเวอร์ อาจใช้เวลาสักครู่

ห้ามขัดจังหวะกระบวนการขณะติดตั้งเซิร์ฟเวอร์ใหม่

## เริ่มเซิร์ฟเวอร์ Palworld ใหม่

เมื่อการติดตั้งใหม่เสร็จสิ้น ให้เริ่มเซิร์ฟเวอร์ Palworld อีกครั้งจากแผงจัดการเซิร์ฟเวอร์

หลังเริ่มต้น:

- จะสร้างข้อมูลเซฟโลกใหม่
- ใช้การตั้งค่าเซิร์ฟเวอร์เริ่มต้น
- ความก้าวหน้าผู้เล่นและโลกก่อนหน้านี้จะไม่อยู่แล้ว

ถ้าจำเป็น คุณสามารถกลับไปที่ `Configs` และปรับแต่งการตั้งค่า Palworld ใน `PalWorldSettings.ini` ได้อีกครั้ง

## ตรวจสอบผลลัพธ์การรีเซ็ต

หลังเซิร์ฟเวอร์เริ่มทำงาน ให้เชื่อมต่อและตรวจสอบว่ารีเซ็ตสำเร็จหรือไม่

คุณควรตรวจสอบดังนี้:

| ตรวจสอบ | ผลลัพธ์ที่คาดหวัง |
| --- | --- |
| สถานะโลก | โลกใหม่สดใส |
| ข้อมูลผู้เล่น | ไม่มีความก้าวหน้าก่อนหน้า |
| การตั้งค่าเซิร์ฟเวอร์ | ค่าเริ่มต้น ยกเว้นเปลี่ยนแปลงใหม่ |
| ไฟล์กำหนดเองหรือม็อด | ถูกลบ ยกเว้นติดตั้งใหม่เอง |

ถ้าโลกเก่ายังแสดงอยู่ ให้หยุดเซิร์ฟเวอร์และตรวจสอบว่ากระบวนการติดตั้งใหม่เสร็จสมบูรณ์ในแผง ZAP หรือไม่ หากแผงไม่ได้ทำการฟอร์แมตเต็มรูปแบบ คุณอาจต้องทำซ้ำขั้นตอนอย่างระมัดระวัง

## ตั้งค่าการเซิร์ฟเวอร์ใหม่หลังรีเซ็ต

หลังรีเซ็ตสำเร็จ เซิร์ฟเวอร์ Palworld ของคุณจะใช้ค่าคอนฟิกเริ่มต้น หากต้องการปรับแต่งเซิร์ฟเวอร์อีกครั้ง ให้เปิดส่วน `Configs` ในแผงจัดการเซิร์ฟเวอร์เกมและแก้ไข `PalWorldSettings.ini`

งานทั่วไปหลังรีเซ็ตอาจรวมถึง:

- เปลี่ยนชื่อเซิร์ฟเวอร์
- ตั้งรหัสผ่าน
- ปรับระดับความยากหรือค่าการเล่นเกม
- นำการเปลี่ยนแปลงคอนฟิกกำหนดเองกลับมาใช้ใหม่
- ติดตั้งม็อดหรือไฟล์เสริมที่รองรับใหม่หากจำเป็น

:::tip ใช้การตั้งค่าอย่างระมัดระวัง
ถ้าการตั้งค่าก่อนหน้านี้ทำให้เกิดปัญหา อย่าคัดลอกการตั้งค่าทั้งหมดกลับมาในทันที ให้ใช้เฉพาะการตั้งค่าที่จำเป็นจริง ๆ เพื่อช่วยระบุการเปลี่ยนแปลงที่ก่อปัญหาได้ง่ายขึ้น
:::

## อ้างอิงการตั้งค่า

ตารางต่อไปนี้สรุปไฟล์ที่เกี่ยวข้องและพฤติกรรมการรีเซ็ต:

| รายการ | รายละเอียด |
| --- | --- |
| ไฟล์คอนฟิกหลัก | `PalWorldSettings.ini` |
| ตำแหน่งแก้ไขคอนฟิกใน ZAP | `Configs` ในแผงจัดการเซิร์ฟเวอร์เกม |
| ต้องแก้ไขคอนฟิกด้วยตนเองเพื่อรีเซ็ตเต็มรูปแบบหรือไม่ | ไม่ต้อง |
| การดำเนินการที่ต้องทำเพื่อรีเซ็ตเต็มรูปแบบ | ติดตั้งใหม่หรือฟอร์แมต/รีเซ็ตเซิร์ฟเวอร์ |
| ต้องรีสตาร์ทหลังติดตั้งใหม่หรือไม่ | ใช่ เริ่มเซิร์ฟเวอร์ใหม่หลังติดตั้ง |
| คำสั่งเพิ่มเติมที่ต้องใช้ | ไม่มีข้อมูลยืนยัน |

:::note ชื่อเมนูในอินเทอร์เฟซอาจแตกต่างกัน
คำเรียกตัวเลือกติดตั้งใหม่หรือฟอร์แมตอาจแตกต่างกันตามเวอร์ชันเว็บอินเทอร์เฟซ ZAP หากคุณหาเมนูรีเซ็ตไม่เจอ ให้ติดต่อฝ่ายสนับสนุนก่อนลองลบไฟล์ด้วยวิธีอื่น
:::
