## Introduction

Palworld ให้คุณปรับอัตราการจับ Pal บนเซิร์ฟเวอร์ของคุณผ่านการตั้งค่าโลกหลัก ในคู่มือนี้ คุณจะได้เรียนรู้ว่าจะหาไฟล์คอนฟิกที่ถูกต้องในอินเทอร์เฟซ ZAP-Hosting ได้ที่ไหน ค่าที่ต้องเปลี่ยน และวิธีใช้ค่าอัตราการจับใหม่



## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่าคุณสามารถเข้าถึงเซิร์ฟเวอร์เกม Palworld ของคุณผ่านเว็บอินเทอร์เฟซ ZAP-Hosting และเซิร์ฟเวอร์ได้ถูกตั้งค่าและกำลังทำงานอยู่

:::info การเข้าถึงไฟล์คอนฟิก
สำหรับเซิร์ฟเวอร์ Palworld บน ZAP-Hosting การตั้งค่าที่เกี่ยวข้องสามารถแก้ไขได้ผ่านการจัดการเซิร์ฟเวอร์เกมในเมนู `Configs`
:::

## ค้นหาไฟล์คอนฟิก Palworld

เพื่อเปลี่ยนอัตราการจับ Pal คุณต้องแก้ไขไฟล์ `PalWorldSettings.ini`

### เปิดส่วน Configs

เริ่มต้นด้วยการล็อกอินเข้าเว็บอินเทอร์เฟซ ZAP-Hosting และเปิดเซิร์ฟเวอร์เกม Palworld ของคุณ ในการจัดการเซิร์ฟเวอร์เกม ให้ไปที่เมนู `Configs`

ที่นั่น ให้มองหาไฟล์ชื่อ:

```ini
PalWorldSettings.ini
```

### ระบุการตั้งค่าที่ถูกต้อง

ในไฟล์ `PalWorldSettings.ini` Palworld จะเก็บการตั้งค่าเกมเพลย์หลายอย่างไว้ในส่วน `OptionSettings` การตั้งค่าที่เกี่ยวข้องกับการจับ Pal คือ:

```ini
PalCaptureRate=[your_value]
```

ค่าปกติจะเป็น:

```ini
PalCaptureRate=1.000000
```

ค่ายิ่งสูงจะทำให้จับ Pal ง่ายขึ้น ในขณะที่ค่ายิ่งต่ำจะทำให้จับยากขึ้น

## แก้ไขอัตราการจับ Pal

เมื่อคุณเปิดไฟล์ที่ถูกต้องแล้ว คุณสามารถปรับอัตราการจับให้เหมาะกับสมดุลเกมที่คุณต้องการได้

### เปลี่ยนค่าคอนฟิก

ค้นหาบรรทัด `PalCaptureRate` ในไฟล์ `PalWorldSettings.ini` แล้วแทนที่ค่าด้วยตัวคูณที่คุณต้องการ

ตัวอย่างเช่น:

```ini
PalCaptureRate=2.000000
```

ซึ่งจะทำให้อัตราการจับเพิ่มขึ้นเป็นสองเท่าจากค่าเริ่มต้น

### ตัวอย่างค่า

ใช้ตารางนี้เป็นแนวทางทั่วไป:

| ค่า | ผลลัพธ์ |
| --- | --- |
| `1.000000` | อัตราการจับ Pal เริ่มต้น |
| `1.500000` | จับง่ายขึ้นเล็กน้อย |
| `2.000000` | จับง่ายขึ้นอย่างเห็นได้ชัด |
| `3.000000` | จับง่ายมาก |

:::tip การตั้งค่าที่สมดุล
ถ้าคุณต้องการจับง่ายขึ้นโดยไม่รู้สึกว่าจับได้แน่นอน ค่าระหว่าง `1.500000` ถึง `2.000000` มักเป็นจุดเริ่มต้นที่เหมาะสม
:::

## บันทึกและใช้การเปลี่ยนแปลง

หลังจากแก้ไขค่า `PalCaptureRate` ให้บันทึกการเปลี่ยนแปลงในตัวแก้ไขคอนฟิกของ ZAP-Hosting

### รีสตาร์ทเซิร์ฟเวอร์

Palworld จะไม่ใช้การตั้งค่านี้แบบสดๆ หลังบันทึกไฟล์แล้ว คุณต้องรีสตาร์ทเซิร์ฟเวอร์เกมจากการจัดการเซิร์ฟเวอร์ของ ZAP-Hosting เพื่อให้โหลดอัตราการจับใหม่

:::caution ต้องรีสตาร์ทเซิร์ฟเวอร์
ถ้าคุณไม่รีสตาร์ทเซิร์ฟเวอร์หลังแก้ไข `PalWorldSettings.ini` อัตราการจับใหม่จะไม่ถูกนำไปใช้
:::

## อ้างอิงการตั้งค่า

ตารางนี้สรุปการตั้งค่าที่ใช้สำหรับการเปลี่ยนแปลงนี้:

| ไฟล์ | คีย์คอนฟิก | ค่าเริ่มต้น | จุดประสงค์ | ต้องรีสตาร์ท |
| --- | --- | --- | --- | --- |
| `PalWorldSettings.ini` | `PalCaptureRate` | `1.000000` | ควบคุมตัวคูณอัตราการจับ Pal | ใช่ |

## การแก้ไขปัญหา

ถ้าอัตราการจับใหม่ดูเหมือนไม่ทำงาน ให้ตรวจสอบจุดต่อไปนี้

### ตรวจสอบรูปแบบการตั้งค่า

ตรวจสอบให้แน่ใจว่าบรรทัดเขียนถูกต้องและใช้ค่าตัวเลข เช่น:

```ini
PalCaptureRate=2.000000
```

หลีกเลี่ยงการเพิ่มตัวอักษรพิเศษหรือเปลี่ยนแปลงรายการอื่นในไฟล์

### ยืนยันว่าไฟล์ถูกบันทึก

หลังแก้ไข ให้ตรวจสอบว่าการเปลี่ยนแปลงถูกบันทึกจริงใน `PalWorldSettings.ini` ผ่านเมนู `Configs`

### รีสตาร์ทอีกครั้งถ้าจำเป็น

ถ้าเซิร์ฟเวอร์ไม่ได้รีสตาร์ทอย่างถูกต้องหลังเปลี่ยนแปลง ให้รีสตาร์ทอีกครั้งจากการจัดการเซิร์ฟเวอร์

:::note การตั้งค่าเกมเพลย์ฝั่งเซิร์ฟเวอร์
`PalCaptureRate` เป็นการตั้งค่าเกมเพลย์ฝั่งเซิร์ฟเวอร์ ดังนั้นผู้เล่นจะเห็นอัตราใหม่หลังเซิร์ฟเวอร์โหลดคอนฟิกที่อัปเดตแล้วเท่านั้น
:::

## Conclusion

ยินดีด้วย คุณได้เปลี่ยนอัตราการจับ Pal บนเซิร์ฟเวอร์ Palworld ของคุณเรียบร้อยแล้ว สำหรับคำถามหรือความช่วยเหลือเพิ่มเติม อย่าลังเลที่จะติดต่อทีมซัพพอร์ตของเรา ซึ่งพร้อมให้บริการทุกวันเพื่อช่วยเหลือคุณ! 🙂
