## Introduction

Palworld ให้คุณควบคุมการใช้ fast travel ของผู้เล่นบนเซิร์ฟเวอร์ผ่านการตั้งค่าเซิร์ฟเวอร์หลัก ในคู่มือนี้ คุณจะได้เรียนรู้วิธีแก้ไขไฟล์ config ที่ถูกต้องในแผงควบคุม ZAP-Hosting ปรับแต่งการตั้งค่า fast travel และนำการเปลี่ยนแปลงไปใช้ให้ถูกต้อง



## Preparation

ก่อนเริ่มต้น ให้แน่ใจว่าคุณสามารถเข้าถึงเซิร์ฟเวอร์เกม Palworld ของคุณในเว็บอินเทอร์เฟซ ZAP-Hosting และมีสิทธิ์แก้ไขไฟล์การตั้งค่า

:::info ต้องแก้ไข config ด้วยตนเอง
การตั้งค่านี้ต้องทำโดยการแก้ไขไฟล์ config ของเซิร์ฟเวอร์ Palworld ด้วยตนเอง คุณสามารถเข้าถึงไฟล์ที่ต้องการได้ผ่านการจัดการเซิร์ฟเวอร์เกมในส่วน `Configs`
:::

## Locate the Configuration File

เพื่อเปลี่ยนพฤติกรรม fast travel คุณต้องแก้ไขไฟล์ `PalWorldSettings.ini`

ในแผงควบคุมเซิร์ฟเวอร์เกม ZAP-Hosting:

1. เปิดเซิร์ฟเวอร์ Palworld ของคุณ
2. ไปที่เมนู `Configs`
3. เปิดไฟล์ `PalWorldSettings.ini`

ไฟล์นี้เก็บการตั้งค่าเกมเพลย์ของเซิร์ฟเวอร์ รวมถึงตัวเลือก fast travel

:::note ตำแหน่งไฟล์ config
ขึ้นอยู่กับรูปแบบแผงควบคุมปัจจุบัน ไฟล์นี้จะถูกจัดการผ่านส่วน `Configs` ในการจัดการเซิร์ฟเวอร์ของคุณ หากอินเทอร์เฟซไม่แสดงเส้นทางไฟล์ที่ชัดเจน คุณยังสามารถแก้ไขค่าใน `PalWorldSettings.ini` ได้โดยตรงอย่างปลอดภัย
:::

## Understand the Fast Travel Settings

Palworld มีคีย์ config ที่เกี่ยวข้องกับพฤติกรรม fast travel สองตัว

| คีย์ config | ประเภทค่า | ค่าเริ่มต้น | ฟังก์ชัน |
| --- | --- | --- | --- |
| `bEnableFastTravel` | `True` / `False` | `True` | เปิดหรือปิด fast travel ทั้งหมด |
| `bEnableFastTravelOnlyBaseCamp` | `True` / `False` | `False` | จำกัด fast travel ให้ผู้เล่นเดินทางได้เฉพาะระหว่างฐานเท่านั้น |

ค่านี้เป็นส่วนหนึ่งของสตริงตัวเลือกเซิร์ฟเวอร์ในไฟล์ `PalWorldSettings.ini`

:::tip เลือกการตั้งค่าที่เหมาะสม
ถ้าคุณต้องการประสบการณ์การเดินทางที่สมจริงและเน้นการสำรวจมากขึ้น คุณสามารถปิด fast travel ทั้งหมดได้ หากต้องการให้ผู้เล่นยังเดินทางได้แต่จำกัดการเคลื่อนที่อย่างอิสระ fast travel เฉพาะฐานจะเป็นตัวเลือกที่ดีกว่า
:::

## Edit the Fast Travel Values

เปิดไฟล์ `PalWorldSettings.ini` แล้วค้นหาส่วน `OptionSettings=` ใน Palworld การตั้งค่าเซิร์ฟเวอร์หลายอย่างจะถูกเก็บเป็นค่าที่คั่นด้วยเครื่องหมายจุลภาคในส่วนนี้

### เปิดใช้งาน Fast Travel ปกติ

เพื่ออนุญาต fast travel แบบปกติ ให้แน่ใจว่ามีค่านี้อยู่:

```ini
bEnableFastTravel=True
```

ถ้าคุณต้องการให้ผู้เล่นใช้ fast travel ทุกตัวเลือกปกติ ให้ตั้งค่านี้ด้วย:

```ini
bEnableFastTravelOnlyBaseCamp=False
```

### ปิดใช้งาน Fast Travel ทั้งหมด

ถ้าต้องการปิด fast travel ทั้งหมด ให้ตั้งค่าเป็น:

```ini
bEnableFastTravel=False
```

เมื่อปิดใช้งาน ผู้เล่นจะต้องเดินทางด้วยตนเองทั่วโลกเกม

### จำกัด Fast Travel เฉพาะฐานเท่านั้น

ถ้าต้องการให้ fast travel ใช้ได้เฉพาะระหว่างฐาน ให้ใช้การตั้งค่านี้:

```ini
bEnableFastTravel=True,bEnableFastTravelOnlyBaseCamp=True
```

การตั้งค่านี้เหมาะสำหรับเซิร์ฟเวอร์ที่เน้น PvP เพราะยังอนุญาตให้เดินทางได้จำกัดโดยไม่ให้ผู้เล่นเคลื่อนที่อย่างอิสระเต็มที่

:::caution อย่าลบไวยากรณ์เดิม
อย่าลบค่าที่มีอยู่ในบรรทัด `OptionSettings=` เว้นแต่คุณตั้งใจจะเปลี่ยนแปลงทั้งหมด Palworld เก็บการตั้งค่าหลายอย่างในบรรทัดเดียวที่คั่นด้วยจุลภาค การแก้ไขผิดรูปแบบอาจทำให้การตั้งค่าไม่ถูกโหลด
:::

## Example Configuration

ตัวอย่างด้านล่างแสดงส่วนที่เกี่ยวข้องของ config ในไฟล์ `PalWorldSettings.ini`:

```ini
OptionSettings=(Difficulty=None,DayTimeSpeedRate=1.000000,NightTimeSpeedRate=1.000000,bEnableFastTravel=True,bEnableFastTravelOnlyBaseCamp=True)
```

แทนที่ค่าการตั้งค่า fast travel ใน config ของคุณตามการตั้งค่าที่ต้องการใช้

:::note การตั้งค่าเซิร์ฟเวอร์ที่มีอยู่
บรรทัด `OptionSettings=` ของคุณมักจะมีค่ามากกว่าตัวอย่างนี้ คุณแค่ต้องปรับ `bEnableFastTravel` และ `bEnableFastTravelOnlyBaseCamp` โดยรักษาค่าที่เหลือไว้เหมือนเดิม
:::

## Recommended Configurations

คุณสามารถใช้ชุดค่าต่อไปนี้ตามประเภทเซิร์ฟเวอร์ที่ต้องการรัน:

| สไตล์เซิร์ฟเวอร์ | `bEnableFastTravel` | `bEnableFastTravelOnlyBaseCamp` | ผลลัพธ์ |
| --- | --- | --- | --- |
| เกมเพลย์ปกติ | `True` | `False` | เปิด fast travel เต็มรูปแบบ |
| เน้นสำรวจ | `False` | `False` | ปิด fast travel ทั้งหมด |
| PvP หรือจำกัดการเดินทาง | `True` | `True` | fast travel เฉพาะระหว่างฐาน |

## Apply the Changes

หลังจากบันทึกการเปลี่ยนแปลงใน `PalWorldSettings.ini` คุณต้องรีสตาร์ทเซิร์ฟเวอร์เพื่อให้การตั้งค่าใหม่ถูกโหลด

### รีสตาร์ทเซิร์ฟเวอร์

ใช้ฟังก์ชันรีสตาร์ทในแผงควบคุมเซิร์ฟเวอร์เกม ZAP-Hosting หลังจากบันทึกไฟล์

โดยปกติไม่ต้องใช้คำสั่งในเกมหรือคอนโซลเพิ่มเติม การตั้งค่า fast travel ใหม่จะถูกนำไปใช้เมื่อเซิร์ฟเวอร์เริ่มทำงานอีกครั้ง

:::info ต้องรีสตาร์ทเซิร์ฟเวอร์
การเปลี่ยนแปลงใน `PalWorldSettings.ini` จะไม่ถูกนำไปใช้จนกว่าเซิร์ฟเวอร์ Palworld จะถูกรีสตาร์ท
:::

## Verify the Result

เมื่อเซิร์ฟเวอร์ออนไลน์อีกครั้ง ให้เข้าร่วมเซิร์ฟเวอร์และทดสอบพฤติกรรม fast travel ในเกม

ตรวจสอบให้แน่ใจว่า:

- fast travel แบบเต็มทำงานถ้าเปิดใช้งาน
- ไม่มีตัวเลือก fast travel ถ้าปิดใช้งาน
- fast travel ระหว่างฐานเท่านั้นทำงานถ้าคุณเปิดใช้งานแบบเฉพาะฐาน

:::tip แก้ไขปัญหาพฤติกรรมผิดปกติ
ถ้าการตั้งค่าไม่ถูกนำไปใช้ ให้เปิดไฟล์ `PalWorldSettings.ini` อีกครั้งและตรวจสอบข้อผิดพลาดรูปแบบในบรรทัด `OptionSettings=` โดยเฉพาะจุลภาคที่หายไป คีย์ซ้ำ หรือค่าที่ไม่ถูกต้องเช่น `True` / `False`
:::

ยินดีด้วย คุณได้เปิดใช้งานหรือกำหนดค่า fast travel บนเซิร์ฟเวอร์ Palworld ของคุณเรียบร้อยแล้ว สำหรับคำถามเพิ่มเติมหรือต้องการความช่วยเหลือ กรุณาติดต่อทีมซัพพอร์ตของเราได้เลย ซึ่งพร้อมให้บริการทุกวันเพื่อช่วยเหลือคุณ! 🙂
