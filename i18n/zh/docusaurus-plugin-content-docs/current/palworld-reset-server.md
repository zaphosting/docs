## 介绍

Palworld 会将你的世界、玩家进度和服务器设置存储在游戏服务器上。本指南将教你如何在 ZAP-Hosting 上完全重置你的 Palworld 服务器，并从全新的默认安装开始。

:::danger 完全删除数据警告
完全重置会永久删除你现有的存档数据、配置更改以及当前安装中的所有其他服务器文件。请仅在万不得已时使用此操作。
:::

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

## 准备工作

开始之前，请确保你可以访问 ZAP-Hosting 面板中的 Palworld 游戏服务器，并且你不再需要当前的世界数据。

:::info 先备份重要数据
如果你想保留当前世界或配置的副本，请先创建备份。重置完成后，删除的数据通常无法恢复。
:::

## 了解 Palworld 服务器重置的作用

完全重置 Palworld 服务器不同于仅更改配置文件中的单个设置。它会重新安装整个服务器并删除当前服务器数据。

重置过程通常会删除以下内容：

| 数据类型 | 重置时是否删除 |
| --- | --- |
| 世界存档数据 | 是 |
| 玩家进度 | 是 |
| 服务器配置更改 | 是 |
| 已安装的模组或自定义文件 | 是 |
| 默认游戏文件 | 会自动重新安装 |

重置后，服务器将以全新安装和默认设置启动。

## 先检查配置文件位置

对于普通的 Palworld 配置更改，你可以在游戏服务器管理的 `Configs` 中访问相关文件。主要的 Palworld 设置通常存储在以下文件中：

| 文件 | 用途 |
| --- | --- |
| `PalWorldSettings.ini` | 主要的 Palworld 服务器配置文件 |

在 ZAP-Hosting 面板中，通常可以通过 Palworld 服务器管理的 `Configs` 访问此文件。

:::note 重置不需要手动编辑配置
完全重置服务器不需要你手动编辑 `PalWorldSettings.ini`。该文件用于普通设置更改，完整重置是通过重新安装或格式化服务器实现的，所有文件都会以默认值重新创建。
:::

如果你只是想更改游戏玩法设置，而不是删除整个服务器，应该在 `Configs` 中编辑配置文件，而不是执行完整重置。

## 停止服务器

开始重置前，你需要完全停止 Palworld 服务器。

1. 登录 ZAP-Hosting 面板。
2. 打开你的 Palworld 游戏服务器。
3. 使用服务器管理控制停止服务器。
4. 等待服务器状态显示已离线。

:::caution 不要在服务器运行时重置
如果在服务器仍在运行时开始重置，文件可能无法被干净删除，存档数据可能会出现不一致。
:::

## 重新安装并重置服务器

Palworld 的完全重置是通过 ZAP 面板中的重新安装功能，配合格式化或重置选项完成的。

### 打开重新安装功能

在你的 Palworld 服务器管理中，查找服务器管理区域的重新安装或重置功能。

由于面板版本不同，界面标签可能略有差异。在 ZAP-Hosting 上，这个功能通常位于服务器管理区域，提供重新安装或格式化操作。

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

### 开始完全重置

使用提供的重新安装选项，执行服务器数据的完全格式化或重置。

如果面板要求确认操作，请在此步骤确认。

:::danger 此操作会清除所有服务器数据
完全重新安装或格式化重置会删除存档、配置和自定义服务器文件。只有在确定要重置所有内容时才继续。
:::

### 等待安装完成

确认重置后，等待重新安装过程完成。根据面板状态和服务器大小，可能需要几分钟。

请勿在服务器重新安装过程中中断操作。

## 启动全新的 Palworld 服务器

重新安装完成后，从服务器管理中再次启动 Palworld 服务器。

启动后：

- 会创建一个新的世界存档
- 使用默认服务器设置
- 之前的玩家和世界进度将不再存在

如有需要，你现在可以返回 `Configs`，再次调整 `PalWorldSettings.ini` 中的 Palworld 设置。

## 验证重置结果

服务器启动后，连接服务器确认重置是否成功。

你应检查以下内容：

| 检查项 | 预期结果 |
| --- | --- |
| 世界状态 | 全新世界 |
| 玩家数据 | 无之前进度 |
| 服务器设置 | 默认值，除非再次更改 |
| 自定义文件或模组 | 已删除，除非手动重新安装 |

如果旧世界仍然存在，请停止服务器，检查 ZAP 面板中重新安装过程是否成功完成。如果面板未执行完整格式化重置，可能需要重新仔细执行该过程。

## 重置后重新配置服务器设置

成功重置后，Palworld 服务器将使用默认配置值。如果你想再次自定义服务器，请打开游戏服务器管理中的 `Configs`，编辑 `PalWorldSettings.ini`。

重置后常见的操作包括：

- 更改服务器名称
- 设置密码
- 调整难度或游戏玩法参数
- 重新应用自定义配置更改
- 如有需要，重新安装支持的模组或附加文件

:::tip 谨慎重新应用设置
如果之前的配置导致问题，避免立即全部复制旧设置。只重新应用你真正需要的设置，这样更容易发现问题所在。
:::

下表总结了相关文件和重置行为：

| 项目 | 详情 |
| --- | --- |
| 主要配置文件 | `PalWorldSettings.ini` |

:::
