## 介绍

Palworld 主机角色转移允许你将单人或合作主机的角色迁移到专用服务器存档中。在本指南中，你将准备所需的存档文件，使用支持的迁移工具，并将更新后的角色数据上传回服务器。

:::danger 实验性角色转移警告
此操作被视为实验性，涉及手动修改存档数据。Palworld 的更新可能会更改存档结构，导致工具或迁移步骤无法正常工作。
:::

## 准备工作

开始之前，请确保你可以访问你的 Palworld 游戏服务器和一台可以运行所需存档迁移工具的本地 Windows 系统。

### 需求

你需要以下内容：

| 需求 | 目的 |
| --- | --- |
| 访问你的 ZAP-Hosting Palworld 服务器 | 用于下载和上传所需的存档文件 |
| 本地备份位置 | 用于保存原始存档数据的安全副本 |
| [Palworld Save Tools](https://github.com/deafdudecomputers/PalWorldSaveTools) | 用于执行主机角色迁移 |
| 新创建的服务器角色 | 主机角色数据将迁移到此专用服务器角色上 |

:::caution 先创建备份
在更改任何存档文件之前，请下载并保存当前服务器存档的完整备份。如果转移失败或导致角色数据损坏，你需要原始文件来恢复服务器。
:::

### 关于配置文件的重要说明

此转移**不**是通过编辑 `Configs` 目录下的 Palworld 配置文件完成的。根据当前可用的工具文档和社区指导，主机角色转移是通过替换存档数据文件来完成的。

相关文件位于你的服务器存档目录中，而非普通游戏配置文件如 `PalWorldSettings.ini`。

## 了解使用的文件

开始转移前，你应确认涉及的文件。

### 转移所需的存档文件

主机角色迁移使用以下存档数据：

| 文件或文件夹 | 位置 | 作用 |
| --- | --- | --- |
| `Level.sav` | `Pal/Saved/SaveGames/0/[your_savefolder_id]/Level.sav` | 包含世界级别的存档数据，供迁移工具使用 |
| `Players/` | `Pal/Saved/SaveGames/0/[your_savefolder_id]/Players/` | 包含玩家存档文件，包括新创建的专用服务器角色 |
| `00000001.sav` | 来自上传的单人或合作存档的 `Players/` 内 | 通常代表合作存档中的原始主机角色 |

`[your_savefolder_id]` 是你的 Palworld 世界存档使用的长文件夹名，每个存档不同。

### 在 ZAP 面板中找到文件位置

你可以通过游戏服务器管理文件管理器访问所需存档文件。

路径：

```text
Pal/Saved/SaveGames/0/[your_savefolder_id]/
```

该文件夹内应至少包含：

- `Level.sav`
- `LevelMeta.sav`
- `Players/`



## 准备专用服务器角色

在迁移主机角色之前，专用服务器必须已有为你的账号新生成的玩家存档。

### 在服务器上创建新角色

正常加入你的 Palworld 专用服务器并创建一个新角色。然后游戏至角色至少达到等级 `2`。

此步骤必需，因为迁移工具需要一个现有的专用服务器角色文件作为迁移目标。

### 强制或等待存档

创建新角色后，你需要确保服务器已将新玩家数据写入磁盘。

你可以：

- 等待自动存档间隔，通常约为 `4` 分钟，或
- 在服务器控制台运行 `save` 命令

| 命令 | 运行位置 | 作用 |
| --- | --- | --- |
| `save` | 服务器控制台 | 强制服务器将当前世界和玩家数据写入磁盘 |

:::info 存档命令要求
如果使用 `save` 命令，请在停止服务器前运行。这有助于确保新专用服务器角色文件存在于 `Players/` 文件夹中。
:::

### 停止服务器

存档完成后，从服务器管理面板停止 Palworld 服务器。

请勿在服务器运行时继续操作，因为活动的存档写入可能会覆盖或与即将替换的文件冲突。

## 下载所需存档数据

新角色存在于专用服务器后，你可以下载迁移所需的文件。

### 打开存档目录

在 ZAP-Hosting 文件管理器中，进入：

```text
Pal/Saved/SaveGames/0/[your_savefolder_id]/
```

### 下载文件

将以下项目下载到本地电脑：

| 项目 | 是否必需 |
| --- | --- |
| `Level.sav` | 是 |
| `Players/` 文件夹 | 是 |

将两者存放在同一本地工作目录，以便迁移工具正确处理。

:::tip 文件保持在一起
将 `Level.sav` 和 `Players/` 文件夹放在同一本地文件夹中。这符合 Palworld Save Tools 预期的工作流程。
:::

## 迁移主机角色

下载存档数据后，即可执行主机角色转移。

### 启动 Palworld Save Tools

下载并解压 [Palworld Save Tools](https://github.com/deafdudecomputers/PalWorldSaveTools)，然后打开 `PalworldSaveTools.exe`。

在程序中选择：

```text
Fix Host Save
```



### 选择正确的文件

在迁移工具中：

1. 选择你下载的 `Level.sav`
2. 左侧选择框选择 `00000001.sav`
3. 右侧选择框选择你在专用服务器上创建的新角色
4. 点击 `Migrate` 开始迁移

| 工具字段 | 选择值 |
| --- | --- |
| `Path to Level.sav` | 你下载的 `Level.sav` |
| 左侧角色字段 | `00000001.sav` |
| 右侧角色字段 | 你新创建的专用服务器角色 |
| 操作 | `Migrate` |

### 迁移过程说明

迁移过程将原单人或合作存档中的主机角色数据重新分配到你之前创建的专用服务器角色条目。

这就是为什么你必须先加入服务器并生成新的玩家存档，然后才能使用该工具。

:::caution 核实目标角色
确保右侧选择正确的新服务器角色。选择错误的目标可能会覆盖其他玩家的存档数据。
:::

## 上传更新后的存档文件

迁移成功完成后，你需要将修改后的文件上传回服务器。

### 替换现有存档数据

返回 ZAP-Hosting 文件管理器中相同的服务器目录：

```text
Pal/Saved/SaveGames/0/[your_savefolder_id]/
```

上传并替换：

- 更新后的 `Level.sav`
- 更新后的 `Players/` 文件夹

如果文件管理器提示覆盖现有文件，请确认替换。

### 配置文件更改

针对本次主机角色转移，目前没有已验证的需求去编辑 Palworld 配置文件如 `PalWorldSettings.ini`。

| 项目 | 主机转移是否必需 |
| --- | --- |
| 编辑 `PalWorldSettings.ini` | 否 |
| 编辑 `Configs` 下文件 | 无已验证需求 |
| 替换 `Level.sav` | 是 |
| 替换 `Players/` | 是 |

:::note 无需额外配置项
根据当前可用的工具文档和迁移说明，转移本身不需要额外的配置项或手动 `.ini` 修改。
:::

## 启动服务器并测试角色

上传更新文件后，重新启动你的 Palworld 服务器。

### 重新加入服务器

使用创建新专用服务器角色的同一账号连接服务器。如果迁移成功，你现在应该加载转移后的主机角色，而非临时新角色。

### 检查重要角色数据

加入后，确认以下数据正确显示：

- 角色等级
- 背包物品
- 伙伴
- 基地所有权
- 进度数据

如果有任何缺失或错误，请立即停止服务器并恢复备份后再尝试。

:::danger 数据错误时恢复备份
如果迁移后角色、背包或世界所有权数据异常，请勿继续游戏。先恢复原始的 `Level.sav` 和 `Players/` 备份，以避免保存更多不想要的更改。
:::
