## 介绍

Palworld 将你的活动世界存储在服务器的存档数据中，而不是可配置的世界设置里。在本指南中，你将学习如何通过删除现有存档文件夹，在 ZAP-Hosting 上重置你的 Palworld 游戏服务器世界，使服务器在下一次启动时生成一个新世界。

:::danger 永久删除数据
重置你的 Palworld 世界会永久删除当前世界，包括玩家进度、建筑、Pals 以及存储在该世界中的其他保存数据。
:::

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

## 准备工作

开始之前，请确保你可以访问你的 Palworld 游戏服务器管理面板，并且服务器当前处于离线状态，才能删除任何存档文件。

:::tip 先创建备份
如果你以后可能还需要当前世界，请先创建备份。若你的产品支持备份功能，可以使用服务器备份功能，或者手动下载存档文件夹后再删除。
:::

## 了解 Palworld 世界重置的工作原理

Palworld 世界重置通常不需要修改配置文件中的游戏玩法数值。活动世界存储在服务器的存档目录中。

根据目前公开的 Palworld 专用服务器结构，世界存档通常位于以下路径：

```text
Pal/Saved/SaveGames/0/
```

在该目录下，通常会有一个长的随机十六进制名称的文件夹，例如：

```text
84B5E2264EC387DEDB43179D666031A1
```

该文件夹包含当前的世界存档。删除它并重新启动服务器后，Palworld 会自动创建一个新世界。

:::note 无需配置项
标准的世界重置通常不需要额外的配置条目、控制台命令或启动参数。重置通过删除现有存档数据完成。
:::

## 停止服务器

在删除世界文件之前，请通过 ZAP-Hosting 游戏服务器管理面板停止你的 Palworld 服务器。

在服务器运行时删除存档数据可能导致文件损坏或世界数据未完全删除。

:::caution 服务器必须离线
确保服务器完全停止后再继续操作。如果服务器仍在运行，可能会在你编辑文件时重新创建或锁定文件。
:::

## 打开存档目录

在你的 ZAP-Hosting Palworld 服务器管理面板中，打开文件管理区域，导航到以下路径：

```text
Pal/Saved/SaveGames/0/
```

根据你的产品布局，你可能通过文件管理器或网页界面中的类似文件访问部分进入此路径。

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

### 路径参考

| 项目 | 值 |
| --- | --- |
| 基础存档路径 | `Pal/Saved/SaveGames/0/` |
| 世界文件夹名称 | 随机十六进制文件夹 |
| 示例文件夹 | `84B5E2264EC387DEDB43179D666031A1` |
| 需要操作 | 删除该世界文件夹 |

## 删除当前世界存档

在 `Pal/Saved/SaveGames/0/` 目录下，找到那个随机十六进制名称的文件夹，完整删除它。

### 你需要删除的内容

| 文件夹类型 | 需要操作 |
| --- | --- |
| `Pal/Saved/SaveGames/0/` 内的当前世界存档文件夹 | 删除 |
| `PalworldSettings.ini` 或其他配置文件 | 除非你也想更改服务器设置，否则本次重置不需要编辑 |

如果 `Pal/Saved/SaveGames/0/` 中只有一个十六进制文件夹，通常它就是当前活动的世界存档。如果有多个文件夹且你不确定哪个在用，请不要猜测。此时请仔细检查当前服务器文件，或联系支持后再删除。

:::info 配置区说明
虽然许多 Palworld 设置可以通过 **Configs** 区域管理，但世界重置本身通常不是通过编辑配置文件完成的。所需操作是从服务器文件中删除世界存档文件夹。
:::

## 重新启动服务器

删除存档文件夹后，重新启动你的 Palworld 服务器。

启动时，服务器应自动生成一个新世界，因为预期的存档位置没有之前的世界存档。

### 额外命令或更改

| 任务 | 是否需要 |
| --- | --- |
| 编辑配置文件 | 否 |
| 运行游戏内命令 | 否 |
| 运行控制台命令 | 否 |
| 删除后重启或启动服务器 | 是 |

:::tip 首次启动可能较慢
删除世界存档后的首次启动可能比平时稍慢，因为 Palworld 需要生成一个新世界。
:::

## 验证重置

服务器重新上线后，连接服务器并确认已创建新世界。

通常可以通过以下方式验证：

- 新的出生状态
- 没有之前玩家建造的建筑
- 没有之前的进度
- `Pal/Saved/SaveGames/0/` 中生成了新的存档文件夹

如果旧世界仍然存在，请再次停止服务器，确认已删除正确的十六进制存档文件夹。
