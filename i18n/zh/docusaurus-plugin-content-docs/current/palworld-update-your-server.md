## 介绍

Palworld 服务器更新是保持服务器与最新 Palworld 游戏版本和客户端更新兼容所必需的。在本指南中，你将学习如何在 ZAP-Hosting 上更新你的 Palworld 服务器，在哪里检查相关设置，以及如果更新未正确应用该怎么办。

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

## 准备工作

开始之前，请确保你可以访问 ZAP-Hosting 网页界面中的 Palworld 游戏服务器，并且拥有重启或重新安装服务器的权限（如有需要）。

:::info 服务器访问要求
你需要访问游戏服务器管理，包括 ZAP-Hosting 面板中的 **配置文件（Configs）**、**控制台（Console）** 和电源控制。
:::

:::note 关于配置文件
对于 Palworld 更新，通常不需要编辑任何游戏玩法配置文件来安装新游戏版本。更新过程通常由服务器安装程序自动处理。如果你手动管理更新行为，仍应检查面板中的服务器设置。
:::

## ZAP-Hosting 上 Palworld 服务器更新的工作原理

托管平台上的 Palworld 专用服务器通常在服务器启动时检查是否有新版本可用。根据目前可用的参考信息，ZAP-Hosting 服务器通常会在服务器启动或重启时自动执行此检查。

如果你的服务器已配置为自动更新，通常只需在 Palworld 发布新版本后重启服务器即可。如果服务设置中禁用了自动更新，则每次补丁发布后都需要手动重启服务器以触发更新检查。

:::caution 自动更新功能说明
自动更新控制的具体标签和可用性可能因当前 ZAP-Hosting 游戏服务器界面和产品设置而异。如果你在服务器设置中未看到与更新相关的开关，不要认为它永久缺失；该选项可能因产品版本不同而有所差异，或可能在后台自动处理。
:::

## 检查相关服务器设置

首先，在 ZAP-Hosting 网页界面打开你的 Palworld 服务器，查看与更新和启动行为相关的可用设置。

### 打开服务器管理界面

1. 登录 ZAP-Hosting 网页界面。
2. 打开你的 **Palworld** 游戏服务器。
3. 查看诸如 **配置文件（Configs）**、**控制台（Console）** 和服务器电源控制等可用部分。

![](https://screensaver01.zap-hosting.com/index.php/s/SCREENSHOT_PLACEHOLDER/preview)

### 确认是否需要编辑配置文件

对于 Palworld 更新过程本身，标准服务器操作中没有确认的配置文件条目可以手动更改游戏版本。**配置文件（Configs）** 下的相关 Palworld 游戏玩法配置文件通常用于服务器设置，如游戏规则，而非下载新服务器版本。

常用的 Palworld 设置文件为：

| 文件 | 典型用途 | 位置 |
| --- | --- | --- |
| `PalWorldSettings.ini` | 游戏玩法和服务器行为设置 | 游戏服务器管理中的 **配置文件（Configs）** |

:::note 无需手动版本条目
在标准 ZAP-Hosting 设置中，没有经过验证的 `PalWorldSettings.ini` 键可用于强制指定 Palworld 服务器版本更新。如果你的目标只是更新服务器软件，通常不需要编辑 `PalWorldSettings.ini`。
:::

## 更新服务器

确认你有服务器访问权限并检查了可用设置后，即可触发更新过程。

### 重启服务器以触发更新检查

主要方法是重启服务器。许多托管的 Palworld 服务器在启动时会触发检查可用游戏更新。

1. 在 ZAP-Hosting 网页界面停止或重启你的 Palworld 服务器。
2. 等待服务器完全关闭。
3. 再次启动服务器。
4. 允许几分钟时间完成启动和更新过程。

如果你的服务启用了 ZAP-Hosting 自动更新功能，此重启应触发服务器下载并应用最新的 Palworld 更新。

### 如果禁用了自动更新

如果你的服务配置为不自动更新，则每次 Palworld 补丁或版本更新发布后，都需要手动重启服务器。

操作步骤相同：

1. 停止服务器。
2. 再次启动服务器。
3. 等待服务器完成启动。

:::tip Palworld 发布后最佳实践
在 Palworld 新版本发布或补丁部署后，建议在玩家活跃度较低的时间段重启服务器。这有助于避免因客户端和服务器版本不匹配导致的玩家连接问题。
:::

## 验证更新是否应用成功

服务器重新启动后，应确认新版本已激活。

### 检查控制台输出

打开游戏服务器管理中的 **控制台（Console）**，查看启动日志。查找服务器是否正常完成启动，且未遇到更新或文件验证错误的迹象。

由于具体日志内容会因服务器版本不同而异，重点关注服务器是否成功启动并接受来自最新 Palworld 游戏版本客户端的连接。

### 使用 `info` 命令

如果服务器控制台支持，运行以下命令：

```text
info
```

该命令可用于启动后检查服务器信息。

| 命令 | 作用 |
| --- | --- |
| `info` | 显示服务器信息以验证更新情况 |

:::note 命令支持说明
控制台命令支持情况取决于当前 Palworld 专用服务器实现及主机提供的控制台访问方式。如果 `info` 命令在你的环境中无效，请改用启动日志和使用已更新游戏客户端进行连接测试。
:::

## 更新失败的故障排除

如果重启未能更新服务器，应使用 ZAP-Hosting 面板中的恢复选项。

### 重新安装或验证服务器文件

如果服务器重启后仍显示旧版本：

1. 完全停止服务器。
2. 在 ZAP-Hosting 游戏服务器管理中打开重新安装或恢复选项。
3. 如果有，使用 **验证完整性** 或类似的文件检查功能。
4. 过程完成后重新启动服务器。

此过程会重新检查或重新下载 Palworld 服务器文件，能解决不完整或失败的更新问题。

:::caution 保存数据注意事项
使用重新安装相关功能前，请确认所选选项是否仅影响游戏文件或也会影响世界数据。如果面板未明确说明，建议先备份数据或联系支持后再操作。
:::

### 确认客户端与服务器版本匹配

有时服务器已正确更新，但玩家仍无法加入，因为本地游戏客户端版本不同。

请检查以下内容：

| 检查项 | 重要原因 |
| --- | --- |
| 补丁发布后服务器已重启 | 启动通常触发更新 |
| 已安装最新客户端更新 | 玩家需使用相同游戏版本 |
| 控制台无启动错误 | 错误可能阻止更新完成 |
| 已完成文件验证 | 损坏文件可能阻止更新 |

## 配置文件中需要编辑的内容

本指南专注于手动更新流程，并提及了 **配置文件（Configs）**，因此需要明确范围：

- Palworld 配置文件用于服务器设置。
- `PalWorldSettings.ini` 中没有经过验证的条目可手动下载或应用服务器软件更新。
- 正常版本更新通常**不需要**修改配置文件中的任何值。
- 所需操作通常是**重启服务器**，如果更新失败，再进行**文件验证或重新安装**。

如果 ZAP-Hosting 未来在面板中提供专门的更新开关或启动参数，应使用界面中显示的准确标签，而非在配置文件中添加未支持的条目。

:::danger 切勿添加未经验证的配置键
除非明确文档说明，否则不要在 `PalWorldSettings.ini` 或 **配置文件（Configs）** 下的其他文件中粘贴随机的更新命令、SteamCMD 参数或未记录的键。未经支持的条目不会可靠更新服务器，且可能导致配置问题。
:::

## 更新完成后

更新成功应用后：

1. 确保服务器正常运行。
2. 检查控制台是否有错误。
3. 使用已更新的 Palworld 客户端测试加入服务器。
4. 如果支持，运行控制台命令 `info`。

此时，你的服务器应已准备好迎接使用最新版本的玩家。
