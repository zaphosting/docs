## Introduction

يتيح لك Palworld التحكم في الحد الأقصى لعدد القواعد التي يمكن لكل نقابة وضعها على سيرفرك. في هذا الدليل، ستتعلم كيفية تعديل ملف الإعدادات الصحيح يدويًا في واجهة الويب الخاصة بـ ZAP-Hosting، وتغيير إعداد `BaseCampMaxNumInGuild`، وتطبيق التغيير عن طريق إعادة تشغيل السيرفر.



## Preparation

قبل أن تبدأ، تأكد من أن لديك وصول إلى سيرفر ألعاب Palworld الخاص بك في واجهة الويب لـ ZAP-Hosting.

:::info Required Access
تحتاج إلى وصول لإدارة سيرفر Palworld الخاص بك وقسم `Configs` لتحرير ملفات الإعدادات.
:::

## Locate the configuration file

لتغيير إعداد الحد الأقصى لقواعد النقابات، تحتاج إلى تعديل ملف `PalWorldSettings.ini`.

في واجهة الويب الخاصة بـ ZAP-Hosting، افتح إدارة سيرفر ألعاب Palworld الخاص بك وانتقل إلى:

`Configs` → `PalWorldSettings.ini`

يحتوي هذا الملف على القيم الرئيسية لإعدادات اللعب لسيرفر Palworld الخاص بك، بما في ذلك حدود النقابات والقواعد.

## Edit the max guild bases value

داخل ملف `PalWorldSettings.ini`، ابحث عن قسم `OptionSettings`. الإعداد الذي تحتاج إلى تغييره هو:

`BaseCampMaxNumInGuild=[your_value]`

استبدل `[your_value]` بعدد القواعد التي تريد السماح لكل نقابة بوضعها.

### Example configuration

إذا كنت تريد السماح بما يصل إلى `6` قواعد لكل نقابة، يجب أن يكون الإدخال كالتالي:

```ini
BaseCampMaxNumInGuild=6
```

إذا كان الإعداد موجودًا بالفعل، غيّر قيمته فقط. إذا كان مفقودًا، أضفه داخل قائمة معلمات `OptionSettings` الموجودة في الملف.

:::note Default and vanilla maximum
تشير المعلومات المرجعية الحالية إلى أن القيمة الافتراضية هي `4`، والحد الأقصى العادي في النسخة الأصلية هو `10`. القيم التي تزيد عن `10` عادةً غير مدعومة في سيرفر Palworld غير معدل.
:::

### Value reference

| Config key | Description | Default value | Vanilla maximum |
| --- | --- | --- | --- |
| `BaseCampMaxNumInGuild` | الحد الأقصى لعدد القواعد المسموح بها لكل نقابة | `4` | `10` |

:::caution Use valid values
اضبط `BaseCampMaxNumInGuild` فقط على قيمة معقولة ومدعومة. القيم التي تزيد عن `10` عادةً تتطلب تعديل على جانب السيرفر وقد لا تعمل بشكل صحيح على سيرفر Palworld القياسي.
:::

## Save the configuration

بعد تغيير القيمة، احفظ ملف `PalWorldSettings.ini` في محرر الإعدادات الخاص بـ ZAP-Hosting.

هذا يخزن إعداد الحد الأقصى الجديد للنقابات، لكنه لن يُطبق حتى يتم إعادة تشغيل السيرفر.

## Restart the server

بمجرد حفظ الملف، أعد تشغيل سيرفر Palworld الخاص بك من واجهة إدارة السيرفر.

إعادة التشغيل ضرورية لأن Palworld يقرأ إعدادات `PalWorldSettings.ini` أثناء بدء تشغيل السيرفر. بدون إعادة تشغيل، عادةً لن يتم تطبيق حد قواعد النقابات الجديد.

### What you need to do afterward

عادةً لا تحتاج إلى أوامر إضافية في الكونسول بعد تعديل `BaseCampMaxNumInGuild`. بعد إعادة التشغيل، يجب أن تكون القيمة الجديدة فعالة تلقائيًا.

| Action | Required |
| --- | --- |
| حفظ `PalWorldSettings.ini` | نعم |
| إعادة تشغيل السيرفر | نعم |
| تشغيل أوامر إضافية | لا |

:::tip Test the new limit
بعد إعادة التشغيل، انضم إلى السيرفر وجرب حد وضع القواعد مع نقابة لتتأكد من تطبيق الإعداد الجديد كما هو متوقع.
:::

## Troubleshooting

إذا لم يتغير إعداد الحد الأقصى لقواعد النقابات، تحقق من النقاط التالية.

### Verify the config entry

تأكد من كتابة `BaseCampMaxNumInGuild` بشكل صحيح واستخدام قيمة رقمية، مثل:

```ini
BaseCampMaxNumInGuild=8
```

خطأ مطبعي في اسم المفتاح أو قيمة غير صالحة يمكن أن تمنع الإعداد من العمل.

### Confirm the file was saved

تحقق من أن التغييرات التي أجريتها تم حفظها في `Configs` → `PalWorldSettings.ini` قبل إعادة تشغيل السيرفر.

### Restart the server fully

يجب إعادة تشغيل السيرفر بالكامل بعد تغيير هذا الإعداد. إذا قمت فقط بحفظ الملف دون إعادة تشغيل، قد يستمر استخدام القيمة القديمة.

### Stay within the vanilla limit

إذا ضبطت قيمة أعلى من `10`، قد يتجاهلها السيرفر أو يتصرف بشكل غير متوقع ما لم تكن تستخدم تعديلات متوافقة. إذا كنت تدير سيرفرًا قياسيًا، احتفظ بالقيمة عند `10` أو أقل.

## Conclusion

تهانينا، لقد قمت بتغيير الحد الأقصى لعدد قواعد النقابات على سيرفر Palworld الخاص بك بنجاح. لأي أسئلة أو مساعدة إضافية، لا تتردد في التواصل مع فريق الدعم لدينا، المتوفر يوميًا لمساعدتك! 🙂
