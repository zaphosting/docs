## Introductie

RedM Upvotes/Burst Upvotes geven je de kans om de ranking van je eigen server of een andere server op de serverlijst te boosten. Hoe meer upvote-punten een server verzamelt, hoe hoger die in de rankings komt te staan.

## Upvotes vs Burst Upvotes

RedM Upvotes en RedM Burst Upvotes zijn beide manieren om de zichtbaarheid en populariteit van een RedM-server te vergroten. RedM Upvotes zijn doorlopende stemmen die over een langere periode worden ingezet voor langdurige zichtbaarheid in de server rankings. RedM Burst Upvotes zijn juist voor korte acties, waarbij veel stemmen in een korte tijd worden ingezet om de server snel omhoog te krijgen in de rankings.


## Upvotes Kopen

RedM Upvotes worden niet meer via de ZAP-Hosting shop verkocht. Je kunt Upvotes en Burst Upvotes rechtstreeks en officieel kopen via het [Cfx.re Portal](https://portal.cfx.re/subscriptions/upvotes). Voor de exacte stappen, bekijk de eigen handleiding van Cfx.re: [How to buy Upvotes for FiveM/RedM servers](https://support.cfx.re/hc/en-us/articles/18675194571420).

:::info Productnaam
De upvotes zijn oorspronkelijk gemaakt voor FiveM en heten daarom nog steeds **FiveM Upvotes**. Maar je kunt ze ook gewoon gebruiken voor **RedM**. 
:::

## Upvotes Toewijzen

Zodra de upvotes zichtbaar zijn in de interface, kun je ze via de RedM client toewijzen. Klik hiervoor op het Upvotes-icoon in de serverlijst bij de server die jij wilt boosten. 
Als bevestiging verschijnt er een pop-up die aangeeft dat de upvotes succesvol zijn toegewezen.

![](https://screensaver01.zap-hosting.com/index.php/s/zD7b9awkCDW7bcx/download)


## Upvotes Resetten

Als de Upvotes aan een andere server moeten worden toegewezen of er een fout is opgetreden bij het toewijzen ervan, kun je ze rechtstreeks resetten in het [Cfx.re Portal](https://portal.cfx.re/subscriptions/upvotes). Het resetten van de Upvotes duurt enkele minuten voordat het door Cfx.re is verwerkt.

:::danger Cooldown bij reset
Cfx.re hanteert een Upvote **cooldown**. Je kunt upvotes dus maar één keer per dag toewijzen aan een server naar keuze. Na toewijzing moet je **24 uur** wachten voordat je ze weer kunt toewijzen. 
:::
