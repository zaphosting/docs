## Introductie

FiveM Upvotes/Burst Upvotes geven je de kans om de ranking van je eigen server of een andere server op de serverlijst te boosten. Hoe meer upvote-punten een server verzamelt, hoe hoger die in de rankings komt te staan.

## Upvotes vs Burst Upvotes

FiveM Upvotes en FiveM Burst Upvotes zijn beide manieren om de zichtbaarheid en populariteit van een FiveM-server te vergroten. FiveM Upvotes zijn doorlopende stemmen die over een langere periode worden ingezet voor langdurige zichtbaarheid in de server rankings. FiveM Burst Upvotes zijn daarentegen bedoeld voor korte acties, waarbij veel stemmen in korte tijd worden ingezet om de server snel omhoog te krijgen in de rankings.


## Upvotes Kopen

FiveM Upvotes worden niet meer via de ZAP-Hosting shop verkocht. Je kunt Upvotes en Burst Upvotes rechtstreeks en officieel kopen via het [Cfx.re Portal](https://portal.cfx.re/subscriptions/upvotes). Voor de exacte stappen, bekijk de eigen handleiding van Cfx.re: [How to buy Upvotes for FiveM/RedM servers](https://support.cfx.re/hc/en-us/articles/18675194571420).

## Upvotes Toewijzen

Zodra de upvotes zichtbaar zijn in de interface, kun je ze via de FiveM client toewijzen. Klik hiervoor op het Upvotes-icoon in de serverlijst bij de server van jouw keuze. 
Als bevestiging verschijnt er een pop-up die aangeeft dat de upvotes succesvol zijn toegewezen.

![](https://screensaver01.zap-hosting.com/index.php/s/onkKXJGpWoGYWa2/download)


## Upvotes Resetten

Als de Upvotes aan een andere server moeten worden toegewezen of er een fout is opgetreden bij het toewijzen ervan, kun je ze rechtstreeks resetten in het [Cfx.re Portal](https://portal.cfx.re/subscriptions/upvotes). Het resetten van de Upvotes duurt enkele minuten voordat het door Cfx.re is verwerkt.

:::danger Cooldown periode reset
Cfx.re hanteert een Upvote **cooldown-periode**. Het toewijzen van upvotes kan dus maar één keer per dag voor een server naar keuze. Na het toewijzen moet je **24 uur** wachten voordat je ze weer kunt toewijzen. 
:::

## Conclusie

Je hebt je upvotes succesvol ontvangen en weet nu hoe je ze beheert. Voor vragen of hulp kun je altijd contact opnemen met onze support, die dagelijks voor je klaarstaat! 🙂
