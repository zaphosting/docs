## Upvotes vs Burst Upvotes

RedM Upvotes e RedM Burst Upvotes sono entrambi modi per aumentare visibilità e popolarità di un server RedM. Gli Upvotes sono voti continui usati su un periodo più lungo per garantire visibilità stabile nel ranking. I Burst Upvotes invece sono voti concentrati in poco tempo per far salire rapidamente il server nella classifica in modo temporaneo.


## Acquista Upvotes

Le RedM Upvotes non sono più vendute tramite lo shop ZAP-Hosting. Puoi acquistare Upvotes e Burst Upvotes direttamente e ufficialmente tramite il [Portale Cfx.re](https://portal.cfx.re/subscriptions/upvotes). Per i passaggi esatti, consulta la guida ufficiale di Cfx.re: [How to buy Upvotes for FiveM/RedM servers](https://support.cfx.re/hc/en-us/articles/18675194571420).

:::info Nome prodotto
Gli upvotes sono stati creati originariamente per FiveM e per questo si chiamano ancora **FiveM Upvotes**. Però si possono usare anche per **RedM**.
:::

## Assegna gli Upvotes

Appena gli upvotes sono visibili nell’interfaccia, puoi assegnarli tramite il client RedM. Clicca sull’icona Upvotes nella lista server per il server che vuoi potenziare. 
Dovrebbe aprirsi un pop-up che conferma l’assegnazione avvenuta con successo.

![](https://screensaver01.zap-hosting.com/index.php/s/zD7b9awkCDW7bcx/download)


## Resetta gli Upvotes

Se gli Upvotes devono essere riassegnati a un altro server o se si è verificato un errore durante l'assegnazione, possono essere ripristinati direttamente nel [Portale Cfx.re](https://portal.cfx.re/subscriptions/upvotes). Il ripristino degli Upvotes richiederà alcuni minuti prima di essere recepito da Cfx.re.

:::danger Cooldown per il reset
Cfx.re impone un **cooldown** per gli Upvotes. Puoi assegnarli solo una volta al giorno per un server a tua scelta. Dopo l’assegnazione devi aspettare **24 ore** prima di poterli riassegnare.
:::
