## Introduzione

Gli Upvotes/Burst Upvotes per FiveM ti danno la possibilità di spingere il posizionamento del tuo server o di un altro server nella lista server. Più punti upvote accumula un server, più in alto salirà nella classifica.

## Upvotes vs Burst Upvotes

FiveM Upvotes e FiveM Burst Upvotes sono entrambi modi per aumentare visibilità e popolarità di un server FiveM. Gli Upvotes sono voti continui usati su un periodo più lungo per garantire visibilità duratura nella classifica. I Burst Upvotes invece sono voti concentrati in poco tempo, pensati per far salire rapidamente il server in classifica in modo veloce e temporaneo.


## Acquista Upvotes

Le FiveM Upvotes non sono più vendute tramite lo shop ZAP-Hosting. Puoi acquistare Upvotes e Burst Upvotes direttamente e ufficialmente tramite il [Portale Cfx.re](https://portal.cfx.re/subscriptions/upvotes). Per i passaggi esatti, consulta la guida ufficiale di Cfx.re: [How to buy Upvotes for FiveM/RedM servers](https://support.cfx.re/hc/en-us/articles/18675194571420).

## Assegna gli Upvotes

Appena gli upvotes sono visibili nell’interfaccia, puoi assegnarli tramite il client FiveM. Clicca sull’icona Upvotes nella lista server per il server che vuoi potenziare. 
Dovrebbe aprirsi un pop-up che conferma l’assegnazione avvenuta con successo.

![](https://screensaver01.zap-hosting.com/index.php/s/onkKXJGpWoGYWa2/download)


## Resetta gli Upvotes

Se gli Upvotes devono essere riassegnati a un altro server o se si è verificato un errore durante l'assegnazione, possono essere ripristinati direttamente nel [Portale Cfx.re](https://portal.cfx.re/subscriptions/upvotes). Il ripristino degli Upvotes richiederà alcuni minuti prima di essere recepito da Cfx.re.

:::danger Cooldown per il reset
Cfx.re applica un periodo di **cooldown** per gli Upvotes. Puoi assegnare gli upvotes solo una volta al giorno per un server a tua scelta. Dopo l’assegnazione devi aspettare **24 ore** prima di poterli riassegnare.
:::
